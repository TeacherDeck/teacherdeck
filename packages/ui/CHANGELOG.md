# 변경 기록

## 0.6.1

- 작은 캡처 영역에서도 도구 모음의 기본 조작을 유지하는 최소 폭 토큰을 추가했어요.

## 0.6.0

- 원본 퀵캡처처럼 색상 창에서 테두리색을 고르는 ColorPicker를 추가했어요.
- 좁거나 확대된 화면에서 선택·숫자 입력 상자가 옆 영역을 가리지 않게 수정했어요.
- 제목·본문의 브라우저 기본 여백을 제거해 공통 간격 토큰대로 배치해요.
- 단일 투명 캡처 창의 작은 도구줄과 마우스 조작 영역 토큰을 추가했어요.

## 0.5.0

- Canvas·Image·Thumb 패턴의 ImageCropPreview: 드래그 선택·이동·모서리 크기 조절과 방향키 조작을 제공해요.

- 대체 설명과 크기, 맞춤 방식을 지정하는 공통 Image 미리보기 컨트롤을 추가했어요. 지연 로딩과 비동기 디코딩으로 많은 썸네일을 표시해요.

## 0.4.1

- 긴 화면에서 마우스 휠 입력이 중간 컨테이너에 막히는 문제를 수정했어요. 가로 넘침을 막으면서 세로 스크롤은 문서가 처리해요.

## 0.4.0

- 여러 줄 TextBox의 기본 표시 행 수를 `rows`로 지정할 수 있어요.
- SettingsExpander 머리글 전체를 키보드로 조작할 수 있는 버튼으로 제공하고, 머리글의 별도 컨트롤은 독립적으로 조작해요.

## 0.3.0

- TextBox의 키보드·IME 조합 이벤트와 입력 요소 참조를 공개해 화자 전환 후 포커스 복귀와 조합 중 Enter 처리를 지원해요.
- 읽기 전용 결과를 선택하고 복사할 수 있도록 `readOnly`를 제공해요.

## 0.2.0

- WinUI 이름의 공통 컨트롤과 시스템 폰트를 적용했어요.
