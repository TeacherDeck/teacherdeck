# 변경 기록

사용자에게 보이는 변경은 버전을 올리고 여기에 적어요(MOD-013, VER-004). `requires`를 올리면 "필요 앱 버전"도 적어요.

## 0.2.0

- 설정에 등록한 공통 명부에서 학급·수업을 연결하고, 필요할 때 현재 작업으로 불러와요.
- 직접 입력과 임시 작업을 유지하며, 같은 재학 식별자의 기존 횟수·조건과 확정 이력을 보존해요.
- 공통 연결은 TeacherDeck 0.3.0 이상에서 사용할 수 있고 이전 앱에서는 직접 입력을 유지해요.

## 0.1.0

- 임시 명단·기존 횟수·직접 지정·이번 제외로 발표자를 뽑아요.
- 실제 발표 완료만 집계하고 되돌리기·새 라운드·당시 이름 기록을 제공해요.
- 로컬 자동 저장과 새 폴더 기록 파일 저장·가져오기, 화면 복제용 학생 보기를 제공해요.
- 명단1,000명·완료 기록10,000건을 지원하고 반복 기록 압축·세대별 청크로 기록을 보존해요.
- 최초 명단은1라운드부터 시작하며 손상 자료는 확인 후 정상 파일·새 작업으로 복구해요.
- 대명단 조건은50명씩 표시하고 번호·이름으로 찾을 수 있어요.
