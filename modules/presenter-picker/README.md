# 발표자 뽑기

이번 작업 명단에서 번호·이름·기존횟수를 붙여넣고 적용한다. 번호+이름이 같은 학생은 작업 안에서 식별자를 유지하고, 명단을 바꿔도 완료 기록의 당시 이름·번호를 보존한다. 전체 공통 명부 연결은 별도 공유 권한 승인과 구현 후 추가한다.

자동 선정은 총 완료횟수가 가장 적은 이번 대상에서 뽑는다. 교사의 직접 지정이 균등보다 우선하며 이번 제외·완료·건너뛴 학생은 선정하지 않는다. 뽑기·재추첨·미리보기·새 라운드는 집계하지 않고 발표 완료만1회 기록한다. 마지막 완료는 되돌릴 수 있다. 새 라운드는 횟수·이번 제외를 유지하고 건너뛰기·라운드 완료 상태를 다시 시작한다.

변경은 storage에 저장된 뒤 화면에 적용한다. 저장 실패 시 이전 기록을 유지한다. 손상된 저장값을 불러오지 못하면 변경을 잠가 기존 값을 보호한다. 이 경우에도 확인을 거친 정상 기록 파일 가져오기·새 작업으로 복구할 수 있고, 복구 저장 실패 시 잠금을 유지한다. 완료 기록은 최대10,000건, 명단1,000명이다. 기록 파일 저장은 기존 fs의 새 결과 폴더를 사용하고 원본 파일을 덮어쓰지 않는다. 새 작업·기록 가져오기는 기존 작업을 바꾸기 전에 확인한다. 파일은 이 도구의 JSON 기록이며 time_alert 전체 백업 형식이 아니다.

학생 보기는 발표자의 번호·이름·작업 이름만 전체화면으로 보여준다. 횟수·제외·교사 정보는 표시하지 않는다. 화면 복제에 사용할 수 있다. 별도 확장 창·학생 기기 접속은 제공하지 않는다.

검증: 순수 선정/완료/되돌리기·명단 교체·입력 검증 테스트와 SDK mock storage 테스트. 통합 담당자는 실제 창·키보드·글자 배율·DPI·테마·파일 저장/가져오기와 `pnpm verify`를 확인한다.

저장 형식은 도구 내부에서만 사용하는 문자열 사전·정수 튜플과 세대별 청크이다. 완료 이력·횟수를 줄이지 않고 보존하며, 청크당240KiB 미만·한 작업 압축 자료2MiB·모듈 전체5MiB 한도 안에서 최종 참조를 전환한다. 예전 단일 JSON 저장값도 읽는다. 한도를 넘는 자료는 자르지 않고 기존 작업을 유지하며 안내한다.

100명이 넘는 학생 조건 목록은50명씩 표시하고 번호·이름으로 찾는다. 페이지와 검색은 명단·횟수·제외 조건을 바꾸지 않는다. 100명까지는 기존 전체 목록을 표시한다.
