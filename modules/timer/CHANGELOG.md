# 변경 기록

## 0.3.0

- 남은 시간을 누르면 `00 : 00 : 00` 칸에 시간·분·초를 바로 바꿀 수 있어요. 숫자를 입력하거나, 휴대폰 타이머처럼 위아래 숫자를 끌거나 눌러서 고르거나, 마우스 휠이나 ↑/↓ 키를 써요. Enter로 적용, Esc로 취소해요.
- 프리셋과 분 입력 칸 대신, 최근에 시작한 시간 5개를 버튼으로 보여 줘요. 예전에 저장한 프리셋은 더 이상 보이지 않아요.
- 시간이 끝나면 숫자가 통통 튀고 카드 테두리에서 빛 고리가 퍼지며, 차임이 세 번 울려요. 소리는 "끝날 때 소리"에서 끌 수 있어요. 시스템에서 애니메이션 줄이기를 켜면 움직이지 않아요.

## 0.2.2

- 발표 숫자 크기와 줄 높이를 화면에 맞춰 버튼 겹침과 숫자 잘림을 줄였어요.
- 버튼·입력 필드의 기본 키 동작을 존중하고 길게 누른 단축키 반복을 무시해요.
- 시스템 시각 보정에 영향받지 않는 경과 시간을 사용하고, 절전 뒤 첫 갱신에 지난 시간을 반영해요.

## 0.2.1

- 공통 UI의 제목·본문 여백과 좁은 화면 입력 폭 수정을 반영했어요.

사용자에게 보이는 변경은 버전을 올리고 여기에 적어요(MOD-013, VER-004). `requires`를 올리면 "필요 앱 버전"도 적어요.

## 0.2.0

- 화면을 Windows 11 모양에 맞췄어요(카드 테두리, 글꼴, 숫자 입력 머리글).
- 오류를 화면 위 알림 막대로 보여 주고, 닫을 수 있어요.
