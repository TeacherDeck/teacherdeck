# 변경 기록

## 0.1.3

- 수동 네트워크 변경 실패 후 실제 IP·DNS를 다시 조회하고 일부 설정이 바뀌었을 가능성을 안내해요. 재조회도 실패하면 이전 상태를 현재 값으로 표시하지 않아요.
- 호스트도 변경 실패 후 실제 상태를 기록하고, 성공하지 않은 전환을 수동 우선 성공으로 기록하지 않아요.
- 시간표 경계를 지나면 현재 판단 미리보기를 갱신하고 Wi-Fi 이름의 연속 공백을 판단과 같은 방식으로 비교해요.

## 0.1.2

- 도구 기능을 구분할 수 있는 공통 규격 아이콘으로 정리했어요.

사용자에게 보이는 변경은 버전을 올리고 여기에 적어요(MOD-013, VER-004). `requires`를 올리면 "필요 앱 버전"도 적어요.

## 0.1.1

- 외부 DNS 자동 설정과 내부 마스크·게이트웨이를 적용 뒤 확인하고, 관측되지 않은 값을 이미 적용됐다고 판단하지 않아요.
- 겹친 자동 트리거를 대기시킨 뒤 최신 시간·설정으로 다시 판단해요.

## 0.1.0

- 내부망 IPv4·DNS와 외부망 DHCP 프로필을 저장하고 수동 전환해요.
- 원본 시간표·Wi-Fi·수동 우선 구간을 유지하고 부팅 등 여섯 자동 트리거 상태를 확인해요.
- 현재 연결과 수동 전환·즉시 검사 버튼을 설정 위에 배치하고 작은 창에서 줄바꿈해요.
