# 변경 기록

## 0.3.2

- 처리한 파일이 원본보다 커져도 선택한 크기·형식을 유지하고 촬영 정보를 제거한 결과를 저장해요. 원본을 복사해 리사이즈가 취소되는 동작을 없앴어요.

## 0.3.1

- 기본 저장 형식을 각 원본의 JPG·JPEG·PNG·WebP 형식으로 바꾸고 `.jpg`·`.jpeg` 확장자를 유지해요. 이전 설정의 품질·크기를 유지하며 자동 WebP 변환은 해제해요.
- 저장 형식을 직접 선택할 수 있어요. 다른 형식으로 변환하면 용량이 커져도 선택한 형식을 유지하고, JPG의 투명한 부분은 흰 배경으로 저장해요.
- 이 PC에서 선택한 형식으로 저장할 수 없으면 다른 형식으로 바꾸지 않고 재선택을 안내해요.

## 0.3.0

- 파일을 끌어 놓으면 입력된 파일 이름과 읽기·처리 상태를 바로 보여줘요. 저장 위치를 묻는 탐색창은 자동으로 열지 않아요.
- 기본은 각 원본 파일과 같은 폴더에 새 결과 파일을 저장해요. 저장 폴더를 따로 고르거나 원본 폴더로 돌아갈 수 있고, 결과 하위폴더를 자동으로 만들지 않아요.
- `fs ^1.4.0`의 원본·폴더 핸들을 사용하며 기존 파일은 덮어쓰지 않아요.

## 0.2.1

- 도구 기능을 구분할 수 있는 공통 규격 아이콘으로 정리했어요.

## 0.2.0

- 파일 추가·드롭 직후 기본 자동 압축을 시작하고 처음 한 번 저장 폴더를 선택해요.
- 폴더 선택·압축 중 추가한 파일도 대기열에 보존하며 같은 파일은 중복 처리하지 않아요.
- 취소 후 성공 결과·실패·대기를 유지하고 미처리와 실패만 따로 재시도해요.

## 0.1.2

- 파일 처리 진행률을 실제 완료 비율로 표시해요.

- 파일 선택과 끌어 놓기가 같은 파일 추가·자동 압축 흐름을 사용해요.
- 새 파일 추가와 선택 취소에서 기존 결과·실패 목록·결과 폴더를 유지해요.
- 대기 파일과 완료 결과를 구분하고, 취소 후에는 미처리 파일을 이어서 압축해요. 각 결과의 저장 위치를 열 수 있어요.

## 0.1.1

- 공통 UI의 제목·본문 여백과 좁은 화면 입력 폭 수정을 반영했어요.

## 0.1.0

- 여러 JPG·PNG·WebP를 선택하거나 끌어 놓아 새 폴더에 일괄 압축해요.
- 품질과 최대 크기를 저장하고 Worker에서 EXIF 회전을 반영해 처리해요.
- 투명도를 유지하고 용량이 줄지 않으면 원본을 복사해요.
- 진행률, 취소, 개별 실패와 결과 폴더 열기를 지원해요.
- 원본 복사 확장자는 파일명이 아닌 실제 이미지 바이트로 결정해요.
