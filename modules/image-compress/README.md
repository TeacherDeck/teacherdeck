# 이미지 용량 줄이기

JPG·PNG·WebP 여러 개를 선택하거나 끌어 놓고, 저장 폴더를 선택한 뒤 **압축하여 저장**을 눌러 주세요. 선택한 폴더 아래 새 결과 폴더를 만들어요. 이름이 겹치면 호스트가 다른 이름을 붙여요. 원본 파일은 변경하지 않아요.

기본값은 품질 82%, 긴 변 1600px예요. 작은 이미지는 확대하지 않고 투명도를 유지하는 WebP로 저장해요. 압축 결과가 원본보다 작지 않으면 원본을 그대로 복사해요. 압축 결과에서는 EXIF 등 촬영 정보가 제거되지만 원본 복사에는 남아요. EXIF 회전은 브라우저 디코더가 적용해요.

64MB·4800만 화소 이하의 정지 이미지만 처리해요. APNG, 움직이는 WebP, GIF, HEIC, BMP는 지원하지 않아요. 한 파일이 실패해도 나머지를 계속 처리해요. 취소하면 현재 Worker와 파일 전송을 중단하고 이미 저장한 결과를 보존해요. 화면에서 각 결과의 용량과 원본 복사 여부를 확인하고 결과 폴더를 열 수 있어요.

모든 처리와 저장은 PC 안에서 이루어져요. fs 1.1 핸들 기반 읽기·새 폴더 쓰기와 storage 설정 저장을 사용해요. 한 번에 한 이미지를 Worker에서 처리해 메모리 사용을 제한해요.

검증: 순수 이미지 크기·헤더·출력 선택 테스트와 SDK mock host 설정·일괄 처리·부분 실패·취소 테스트가 있어요. Worker의 실제 EXIF 회전·알파 출력은 브라우저 QA에서 별도로 확인해요.
저사양 PC에서 과도한 디코딩 메모리 사용을 방지하기 위해 64MiB/4800만 화소 상한을 둬요. Worker는 파일당 90초를 넘으면 종료해요. 실패한 파일만 재시도할 수 있어요. 실행 버튼은 입력 바로 아래에 두고 상세 설정을 접어 두며 긴 목록은 내부에서 스크롤해요. 저장 폴더를 한 번 고른 뒤 파일 추가 시 바로 압축을 켜면 파일 선택과 끌어 놓기로 추가한 파일을 모두 바로 처리해요.

새 파일을 추가하거나 파일 선택 창을 취소해도 이전 성공·실패 결과와 저장 폴더를 유지해요. 대기 파일 수를 따로 표시하고 **압축하여 저장**은 아직 처리하지 않은 파일을 처리해요. **실패한 파일 재시도**는 실패 목록만 처리하고 성공한 파일을 다시 처리하지 않아요. 취소 후 미처리 파일은 대기 목록에 남아 이어서 실행할 수 있어요. 각 결과의 **저장 위치 열기**는 해당 배치의 결과 폴더를 열어요. **목록 비우기**를 누르면 새 작업을 시작해요.
