# 변경 기록

사용자에게 보이는 변경은 버전을 올리고 여기에 적어요(MOD-013, VER-004). `requires`를 올리면 "필요 앱 버전"도 적어요.

## 0.1.0

- 여러 PDF를 추가하면 글자·문서 구조를 유지하는 압축을 바로 시작해요. 저장 폴더는 처음 한 번만 골라요.
- 기본 압축은 지원하는 RGB JPEG와 객체 저장 구조를 줄이며, 특수 이미지·서명 문서를 보존해요.
- DPI·JPEG 품질에 따른 이미지 PDF 전환은 고급 설정으로 구분해요.
- 압축 전후 용량, 원본 복사, 실패 상태와 실패만 재시도를 지원해요.
- 더 커진 출력은 원본 바이트를 복사하고 용량 감소 없음으로 표시해요.
- 원본 보호, 취소 후 완료 결과 유지, 이미지 문서 방식의 페이지 수·크기 재검증을 적용했어요.
