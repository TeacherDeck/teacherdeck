# 변경 기록

## 0.2.0

- 파일을 끌어 놓으면 입력한 파일과 추가 상태를 바로 보여 주며, 자동 처리에 파일·폴더 선택창을 열지 않아요.
- 별도 지정이 없으면 각 원본과 같은 폴더에 새 파일로 저장하고, 다른 폴더를 지정하면 그 폴더에 직접 저장해요. 자동 결과 하위 폴더를 만들지 않아요.
- 기존 파일은 덮어쓰지 않으며, 같은 이름은 별도 이름으로 저장해요.
- 필요 앱 버전: 0.8.0 (fs 1.4).

## 0.1.4

- PDF 스트림의 선언 길이와 파싱된 길이가 다르거나 길이를 확인할 수 없으면 원본을 복사해 본문 손상을 막아요.
- 저장된 설정이 늦게 도착해도 사용자가 바꾼 압축 방식·DPI·품질을 유지해요.
- 압축 전 이미지 크기 검사도 Worker에서 실행하고, 취소하거나 90초가 지나면 검사 Worker를 종료해요.

## 0.1.3

- 도구 기능을 구분할 수 있는 공통 규격 아이콘으로 정리했어요.

사용자에게 보이는 변경은 버전을 올리고 여기에 적어요(MOD-013, VER-004). `requires`를 올리면 "필요 앱 버전"도 적어요.

## 0.1.2

- 압축이 끝나자마자 PDF를 다시 끌어 놓아도 선택한 저장 폴더를 재사용해요.
- 다음 저장 폴더를 고르는 동안 추가 처리를 시작하지 않고, 선택을 취소하면 기존 폴더와 미처리 목록을 유지해요.

## 0.1.1

- PDF 렌더링 자산과 글꼴 네 파일의 해시를 확인하고 원문 라이선스·원천 목록을 도구에 동봉해요.

## 0.1.0

- 여러 PDF를 추가하면 글자·문서 구조를 유지하는 압축을 바로 시작해요. 저장 폴더는 처음 한 번만 골라요.
- 기본 압축은 지원하는 RGB JPEG와 객체 저장 구조를 줄이며, 특수 이미지·서명 문서를 보존해요.
- DPI·JPEG 품질에 따른 이미지 PDF 전환은 고급 설정으로 구분해요.
- 압축 전후 용량, 원본 복사, 실패 상태와 실패만 재시도를 지원해요.
- 더 커진 출력은 원본 바이트를 복사하고 용량 감소 없음으로 표시해요.
- 원본 보호, 취소 후 완료 결과 유지, 이미지 문서 방식의 페이지 수·크기 재검증을 적용했어요.
