# 변경 기록

## 0.1.0

- 기존 이미지 자르기를 보존하고 고급 이미지 편집을 별도 모듈로 추가했어요.
- 레이어·회전/원근·RGB 색보정·편집 가능한 글자/도형·브러시/지우개와 수동 마스크 누끼를 연결했어요.
- 기본 8-bit RGB PSD 읽기/쓰기, 편집 가능한 글자 속성, 전체 합성 이미지와 제한된 호환 안내를 추가했어요.
- 보정 전 픽셀과 글자/도형/마스크를 보존하는 `.deckimage` 작업 저장, PNG/JPG 출력과 새 파일 저장을 추가했어요.
- 왼쪽 아이콘 도구 막대·상단 도구 옵션·중앙 문서/캔버스·오른쪽 속성/색보정/레이어 패널과 편집 단축키를 추가했어요.
- 패널 전환 시 미적용 입력, 비활성 다시 실행, 글자 설정 재열기와 브러시 획 중 버튼 상태를 보호해요.
