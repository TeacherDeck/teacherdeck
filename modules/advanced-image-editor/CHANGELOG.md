# 변경 기록

## 0.2.1

- 내보내기 형식을 바꾸지 않으면 원본 이미지의 JPG/JPEG·PNG·WebP 형식과 접미어를 유지해요. 직접 고른 형식을 우선하며 새 작업·PSD·작업 파일의 자동 출력은 PNG예요.
- WebP 이미지 내보내기를 추가했어요. 선택한 형식으로 인코딩되지 않으면 잘못된 확장자의 파일을 저장하지 않고 안내해요.

## 0.2.0

- 파일을 끌어 놓으면 입력된 파일 이름과 읽기·처리 상태를 바로 보여줘요. 저장 위치를 묻는 탐색창은 자동으로 열지 않아요.
- 기본은 각 원본 파일과 같은 폴더에 새 결과 파일을 저장해요. 저장 폴더를 따로 고르거나 원본 폴더로 돌아갈 수 있고, 결과 하위폴더를 자동으로 만들지 않아요.
- `fs ^1.4.0`의 원본·폴더 핸들을 사용하며 기존 파일은 덮어쓰지 않아요. 새 작업처럼 원본 파일이 없는 경우에는 처음 저장할 폴더를 선택해요.

## 0.1.0

- 기존 이미지 자르기를 보존하고 고급 이미지 편집을 별도 모듈로 추가했어요.
- 레이어·회전/원근·RGB 색보정·편집 가능한 글자/도형·브러시/지우개와 수동 마스크 누끼를 연결했어요.
- 기본 8-bit RGB PSD 읽기/쓰기, 편집 가능한 글자 속성, 전체 합성 이미지와 제한된 호환 안내를 추가했어요.
- 보정 전 픽셀과 글자/도형/마스크를 보존하는 `.deckimage` 작업 저장, PNG/JPG 출력과 새 파일 저장을 추가했어요.
- 왼쪽 아이콘 도구 막대·상단 도구 옵션·중앙 문서/캔버스·오른쪽 속성/색보정/레이어 패널과 편집 단축키를 추가했어요.
- 패널 전환 시 미적용 입력, 비활성 다시 실행, 글자 설정 재열기와 브러시 획 중 버튼 상태를 보호해요.
