# 고급 이미지 편집

파일을 놓으면 파일 이름과 읽기 상태를 즉시 표시하고 파일 탐색창을 자동으로 열지 않아요. 별도 지정이 없으면 각 원본 파일과 같은 폴더에 새 파일을 저장하며 하위폴더를 만들지 않아요. 다른 폴더에 저장할 때는 **저장 폴더 선택**, 기본 위치로 되돌릴 때는 **원본 폴더에 저장**을 사용해요.

사진 보정, 레이어 합성, 글자·화살표·사각형 표시, 브러시·지우개와 수동 누끼를 다루는 TeacherDeck 모듈이에요. 기존 **이미지 자르기**는 별도 도구로 유지해요.

TeacherDeck **0.8.0 이상**에서 사용할 수 있어요. 파일 입출력은 `fs ^1.4.0`, 미저장 작업의 닫기·전환 보호는 `window ^1.2`가 필요해요.

## 화면과 단축키

[Photoshop 작업 화면](https://helpx.adobe.com/ca/photoshop/desktop/get-started/learn-the-basics/workspace-overview.html)의 도구 막대·현재 도구 옵션·문서 창·설정 패널 배치를 참고했어요. 왼쪽 아이콘으로 도구를 고르고 위에서 빠른 옵션을 바꿔요. 오른쪽의 **속성·색 보정·도구 설정**을 전환해 편집하고 아래 레이어 목록에서 대상을 선택해요. 전경색과 캔버스 확대·축소도 바로 바꿀 수 있어요.

버튼은 기존 Fluent 아이콘을 사용해요. 마우스를 올리거나 키보드로 포커스하면 이름과 단축키를 보여줘요. 이름·선택 상태·비활성 상태는 접근성 정보에도 제공해요. 글자·색보정의 미적용 입력은 패널을 바꿔도 유지돼요. 큰 브러시 획을 처리하는 동안 편집·저장 버튼을 잠그고, 획이 끝나면 다시 열어요.

| 단축키                   | 동작                                                  |
| ------------------------ | ----------------------------------------------------- |
| V / C / M / L / W        | 이동 / 자르기 / 사각형 선택 / 다각형 선택 / 색상 선택 |
| B / E / I / H            | 브러시 / 지우개 / 스포이트 / 손 도구                  |
| T                        | 선택한 글자 편집 또는 새 글자 추가                    |
| Ctrl+N / Ctrl+O / Ctrl+S | 새 작업 / 파일 열기 / 작업 저장                       |
| Ctrl+Z / Ctrl+Shift+Z    | 실행 취소 / 다시 실행                                 |
| Ctrl+0 / Ctrl+1          | 화면 맞춤 / 100% 보기                                 |
| 방향키 / Shift+방향키    | 이동 도구에서 레이어 1px / 10px 이동                  |

글자 입력·한글 조합 중에는 도구 단축키가 작동하지 않아요. 입력란에서 Ctrl+S로 저장할 수 있어요. 이번 아이콘 화면 변경은 사용자 요청에 따라 코드·DOM 자동 시험으로 검증했고, 화면을 직접 조작하는 재검수는 하지 않았어요.

## 파일과 작업 보존

- PNG·JPG·정지 WebP를 열고 사진을 레이어로 추가해요. Chromium의 EXIF 방향 처리를 사용해요. GIF·APNG·움직이는 WebP는 지원하지 않아요.
- **작업 저장**은 `.deckimage` 파일이에요. 보정 전 기준 픽셀, 독립 마스크, 위치·크기·회전, 보정값, 글자·도형 속성을 저장해 다시 수정할 수 있어요. 화면에 보이는 픽셀을 저장한 뒤 보정값을 재적용하지 않아요. 실행 취소 이력과 임시 선택 영역은 저장하지 않아요.
- **PSD 내보내기**는 다른 편집기와 교환하는 기능이에요. PNG·JPG·WebP는 최종 이미지 출력이에요. 이 내보내기만으로 작업 전체를 저장했다고 표시하지 않아요.
- 내보내기 형식은 기본적으로 원본 이미지의 JPG/JPEG·PNG·WebP를 따라가며 `.jpg`와 `.jpeg` 접미어도 유지해요. 형식을 직접 선택하면 그 설정을 사용하고, **원본 형식**으로 되돌리면 현재 원본을 다시 따라가요. 새 작업·PSD·`.deckimage`를 열었을 때의 자동 출력은 PNG예요. 레이어로 추가한 이미지는 출력 형식을 바꾸지 않아요. JPG의 투명 부분은 흰색으로 저장해요. 선택한 형식을 지원하지 않는 환경에서는 파일을 저장하지 않고 다른 형식을 고르도록 안내해요.
- 결과는 원본 이미지·PSD·작업 파일과 같은 폴더에 새 파일로 저장해요. 레이어로 추가한 이미지 때문에 현재 작업의 저장 위치는 바뀌지 않아요. **저장 폴더 선택**을 누르면 고른 폴더에 직접 저장하고 **원본 폴더에 저장**으로 되돌려요. 새 작업처럼 원본이 없으면 처음 저장할 때 폴더를 골라요. 이름이 겹치면 번호를 붙여요. 원본 파일을 덮어쓰거나 지우지 않아요.
- 모든 파일 읽기·쓰기는 `fs ^1.4.0` SDK와 불투명 핸들로 처리해요. 외부 업로드, 이미지 URL 열기, 웹 저장소와 원격 글꼴 다운로드는 없어요.

원본 이미지의 형식은 파일 내용으로 확인해요. 파일명 확장자가 실제 형식과 다르면 실제 형식에 맞는 확장자로 내보내요.
이름에 점이 여러 개 있어도 그대로 유지해요. 글자 내용은 레이어마다 20,000자까지 편집·저장하며, 한도를 넘겨 붙여 넣으면 기존 내용을 유지하고 안내해요.

## PSD 지원 범위

8-bit RGB PSD의 기본 픽셀 레이어를 대상으로 이름·순서·위치·표시·불투명도와 일반/곱하기/스크린 혼합을 가져와요. 검증한 활성 래스터 마스크는 픽셀과 독립적으로 가져와요. 글자는 단일 스타일의 가로쓰기 여러 줄을 지원해요. 기존 글자와 새 글자 모두 내용·글꼴·크기·색·굵게·기울임·정렬을 수정할 수 있어요.

PSD 출력은 글자 속성, 각 레이어의 표시용 픽셀과 갱신된 전체 합성 이미지를 함께 저장해요. 화살표·사각형은 PSD에서 개별 픽셀 레이어로 저장해요. 글자·도형 원래 속성을 계속 수정하려면 작업 파일도 저장하세요.

픽셀 레이어의 크기·회전은 PSD 출력 시 픽셀로 반영해요. 투명도와 마스크를 함께 보간해 현재 보이는 외형을 유지하고 마스크도 독립적으로 저장해요. 이 과정에서 일부 경계의 숨긴 색상을 다시 드러낸 모습은 원본과 달라질 수 있어요. 보정 전 픽셀·원래 마스크·변형 속성을 그대로 보존하려면 `.deckimage`도 저장하세요.

복잡한 글자 서식은 미리보기와 사용자 선택을 거쳐 단일 스타일로 바꿔요. 사용할 수 없는 글꼴은 사용자가 대체 글꼴을 골라요. 레이어 효과·조정 레이어·스마트 객체·클리핑·복잡한 그룹·벡터/비활성 마스크를 조용히 무시하지 않아요. 지원하지 않는 파일은 저장된 전체 합성 이미지로 열기를 선택할 수 있어요. 이 경우 기존 글자와 레이어는 개별 수정할 수 없어요. 합성 이미지도 없으면 열 수 없어요. 단순한 pass-through 그룹은 폴더 구조를 펼쳐 자식 레이어를 유지할 수 있어요.

PSB·CMYK/Lab·16/32-bit·Photoshop 전체 서식과 효과 왕복은 지원하지 않아요. 합성 데이터 기반 코덱 시험과 실제 브라우저 시험의 결과를 구분하며, Photoshop에서 직접 확인하지 않은 결과를 Photoshop 호환 검증 완료로 표시하지 않아요.

독립 검증에서는 이 모듈이 만든 합성 PSD를 다시 열어 한국어 여러 줄 글자를 수정한 뒤 저장하고, 개발용 `psd-tools 1.11.1`로 읽었어요. 기본 픽셀 레이어의 투명도·독립 마스크와 글자 레이어의 `type` 인식·수정된 문자열을 확인했어요. 같은 PSD 라이브러리의 재읽기 시험과 구분해요. 실제 Photoshop에서의 글자 재편집·글꼴 배치까지 확인한 결과는 아니에요. 검증 도구는 제품에 포함하지 않아요.

## 자원과 처리

한 문서, 최대 16개 레이어, 문서 24MP·한 변 10,000px를 출발점 한도로 두고 **합계 메모리 256MiB**와 이력 64MiB를 별도로 검사해요. 크기 한도만으로 모든 레이어를 동시에 사용할 수 있다는 뜻은 아니에요. 원본 입력 64MiB, 작업 파일 metadata 256KiB, 압축 해제·픽셀·마스크·출력 임시 버퍼의 합계를 할당 전에 확인해요. 새 문서를 열거나 편집할 때 작업 파일 저장 공간도 예약해요. 저장할 여유가 없는 새 문서는 기존 작업을 바꾸지 않고 거절하며, 편집 이력은 메모리 한도 안에서 오래된 순으로 정리해요. PSD와 최종 이미지 출력은 별도의 합성 메모리가 필요해 큰 작업에서 제한될 수 있어요.

작업 파일은 기존 `.deckimage` 형식을 유지하며 64KiB씩 ZIP으로 압축해요. 이미지 출력은 합성 픽셀과 캔버스를 중복 복사하지 않아요. 4000×3000 이미지 한 레이어의 작업 저장·재열기와 래스터 합성 경로를 합성 데이터로 검사해요. Canvas의 실제 PNG·JPG·WebP 인코딩 결과와 Photoshop 호환 검사는 별도 실기 확인이 필요해요.

PSD/ZIP 파싱과 인코딩, 일반 이미지 디코딩/출력은 Worker에서 처리해요. 취소하면 Worker를 종료해요. 작업 파일은 압축 해제 크기와 엔트리 수·이름·CRC를 검사하고 실제 파일 경로로 추출하지 않아요. PSD의 zlib 채널은 크기가 제한된 스트리밍 검사 후 디코딩해요. 작업 종료 시 비트맵·Canvas·Worker와 SDK 출력 세션을 정리해요.

## 재사용 원천

TeacherDeck 이미지 자르기의 정지 이미지 헤더 검사, SDK 청크 읽기와 새 출력 세션 동작을 독립 파일로 계승했어요. 기존 모듈 내부를 import하지 않아요. 원래 TeacherDeck 저자 표기를 유지해요.

- [Klecks](https://github.com/bitbof/klecks/tree/7b1d4744b648de6133b0d45073af4efd2f998148): flood-fill 선택, 글자 그리기, 변경 타일 계산을 선별 이식한 MIT 원천이에요. 브러시·지우개와 편집 가능한 글자·도형 속성, 독립 마스크는 이 모듈에서 구현·연결해요.
- [ag-psd 31.0.3](https://github.com/Agamnentzar/ag-psd/tree/04d927df87130ad6d765bc63d51ade0a98d66c14): MIT PSD 코덱이에요. 저장소의 샘플 이미지·브러시 자산은 반입하지 않아요.
- [fflate 0.8.3](https://github.com/101arrowz/fflate): MIT 작업 파일 ZIP 코덱이에요.

MIT 고지와 전이 의존성 고지는 배포 고지에 보존해요. 합성 파일만 테스트에 사용해요. 구현 기준은 [기능 명세](../../docs/proposals/advanced-image-editor.md)예요.
