# 변경 기록

## 0.1.0

- 나이스 사진명렬표 XLSX·ZIP XLS의 사진을 원본 바이트 그대로 꺼내요.
- 학년·반·번호·이름 셀을 기준으로 정확한 사진을 연결하고, 추측·미확인 사진과 사진 없는 학생을 보존해요.
- 사진 미리보기·안전한 파일명 편집·전체 사진 저장·취소·실패 파일 다시 읽기를 지원해요.
- 여러 시트·공유 문자열·인라인 문자열·관계 경로를 읽고 ZIP·XML·메모리 한도를 검사해요.
- 필요한 앱 기능: fs 1.1 이상.
- 한도 초과 문서는 따로 거부하고 뒤의 작은 문서는 계속 읽어요. 명시적 취소는 일반 쓰기 실패와 구분해요.
