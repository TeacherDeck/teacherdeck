# 변경 기록

## 0.2.1

- TimeAlert 양식처럼 ZIP 최상위 기준으로 시트·사진을 연결한 XLSX도 읽어요.

- PDF 렌더링 자산과 글꼴 네 파일의 해시를 확인하고 원문 라이선스·원천 목록을 도구에 동봉해요.

## 0.2.0

- PDF 사진 출석부 입력을 추가했어요. 원작 NEIS의 200 DPI 렌더, 상자 탐지, 사진 아래 학생 정보 연결, 테두리·아래 여백 제거 흐름을 적용했어요.
- 회전된 문서의 주된 글자 방향을 보정하고, 머리글이 모호하거나 같은 학번이 반복되면 사진을 미확인으로 보존해요.
- 이름 재료 형식과 PDF 상하좌우 추가 여백·다시 적용을 제공해요. XLSX 사진의 원본 바이트 저장은 유지해요.
- 다른 시트의 그림 관계를 첫 시트의 학생에게 연결하던 오류를 고쳤어요.
- PDF 이름의 성명·이름 라벨을 분리하고, 여백 재적용이 실패하면 이전 사진과 수동 이름을 유지해요.
- PDF 지원에는 동봉 PDF 자산 라이선스 예외 검토가 남아 있어 최종 배포 전 승인 확인이 필요해요.

## 0.1.2

- 파일 처리 진행률을 실제 완료 비율로 표시해요.

- 반 머리글을 열 구간별로 적용하고, 학생 신원과 사진 위치의 확인 상태를 따로 판정해요.
- 머리글 충돌·느슨한 학생 표기·서로 다른 중복 정보는 사진 위치가 맞아도 미확인 이름으로 저장해요.
- 사진별 저장 결과와 실패·미처리 재시도를 유지하고, 같은 작업은 한 결과 폴더에 모아요.

## 0.1.1

- 공통 UI의 제목·본문 여백과 좁은 화면 입력 폭 수정을 반영했어요.

## 0.1.0

- 나이스 사진명렬표 XLSX·ZIP XLS의 사진을 원본 바이트 그대로 꺼내요.
- 학년·반·번호·이름 셀을 기준으로 정확한 사진을 연결하고, 추측·미확인 사진과 사진 없는 학생을 보존해요.
- 사진 미리보기·안전한 파일명 편집·전체 사진 저장·취소·실패 파일 다시 읽기를 지원해요.
- 여러 시트·공유 문자열·인라인 문자열·관계 경로를 읽고 ZIP·XML·메모리 한도를 검사해요.
- 필요한 앱 기능: fs 1.1 이상.
- 한도 초과 문서는 따로 거부하고 뒤의 작은 문서는 계속 읽어요. 명시적 취소는 일반 쓰기 실패와 구분해요.
