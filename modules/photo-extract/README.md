# 명렬표 사진 꺼내기

파일을 놓으면 파일 이름과 읽기 상태를 즉시 표시하고 파일 탐색창을 자동으로 열지 않아요. 별도 지정이 없으면 각 원본 파일과 같은 폴더에 새 파일을 저장하며 하위폴더를 만들지 않아요. 다른 폴더에 저장할 때는 **저장 폴더 선택**, 기본 위치로 되돌릴 때는 **원본 폴더에 저장**을 사용해요.

같은 XLSX 사진 위치에 서로 다른 이미지가 겹치면 입력 순서로 학생 이름을 붙이지 않아요. 경고를 표시하고 겹친 사진을 모두 미확인 이름으로 보존해요. 같은 이미지의 중복 참조는 별도 사진으로 확정하지 않아요. PDF 글자 위치는 확대 단위(UserUnit)·회전·CropBox를 반영해요.

나이스 **학급별 사진명렬표**에서 사진을 원본 바이트 그대로 꺼내는 독립 도구예요. 실제 내용이 XLSX ZIP인 `.xlsx`와 나이스의 `.xls` 파일을 읽어요. 옛 BIFF 바이너리 XLS와 HTML 표는 지원하지 않아요.

1. **파일 추가** 또는 파일 끌어 놓기로 명렬표를 추가해요.
2. 사진 썸네일과 예정 파일명을 확인해요. 학생 신원과 사진 위치가 모두 확인된 사진은 `10301_이름.jpg`처럼 학년·반·번호와 이름을 붙여요. 번호·반은 두 자리 이상 유지해요.
3. **사진 저장**을 누르면 각 사진의 원본 명렬표와 같은 폴더에 새 파일로 저장해요. **저장 폴더 선택**을 누르면 고른 폴더에 직접 모아 저장하고 **원본 폴더에 저장**으로 되돌릴 수 있어요.

사진 앵커와 같은 열, 바로 아래 한 행의 학생 셀을 사진 위치로 연결해요. 학년·반 머리글은 자신의 열부터 다음 머리글 열 전까지 적용해요. 다른 열의 더 아래 머리글이 이전 열 학생의 반을 바꾸지 않아요. 머리글 충돌·학생보다 아래에 있는 머리글·느슨한 숫자 표기·서로 다른 중복 정보는 학생 신원 미확인으로 남아요. 사진 위치가 맞아도 학생 신원이 모호하면 학번·이름을 자동으로 붙이지 않아요. 원본 TimeAlert의 읽기 순서·거리 폴백은 **추측**으로 표시하고 자동으로 학생 이름을 붙이지 않아요. 미확인 사진과 문서의 나머지 미디어도 누락 없이 따로 저장해요. 확인한 사진은 **저장할 이름**에서 직접 바꿀 수 있어요. 같은 이름은 번호를 붙여 구분해요. 잘못된 파일명 문자는 바꾸고 Windows 예약 이름을 피하도록 정리해요.

**학생 명단**에는 사진이 없는 학생도 남아요. 정형 `학년·반·번 이름`, 하이픈 표기, 페이지 머리글과 `번호번 이름`, 정형이 없을 때 숫자 세 개의 느슨한 표기를 원본과 같은 순서로 읽어요. 여러 반과 여러 시트를 지원하고, 스타일만 있는 빈 셀이 다음 학생을 삼키지 않아요. 중복 판정은 학년·반·번호를 함께 사용해요. 담임·날짜·콜론이 들어간 머리말은 학생으로 읽지 않아요.

## 처리와 취소

XLSX 안의 사진은 재압축·회전하거나 다시 저장하지 않아요. 바이트 서명을 보고 JPG·PNG·GIF·WebP 확장자를 정하고, 알 수 없는 미디어는 활성 파일로 실행되지 않도록 `.bin`으로 보존해요. 미리보기가 어려운 사진도 원본 저장에는 포함돼요. 1,600만 화소 또는 한 변 8,192px를 넘는 사진, 파손된 헤더는 썸네일만 표시하지 않아요. PDF 사진은 아래 절차에 따라 페이지에서 잘라 PNG로 저장해요.

**취소**를 누르면 읽기·Worker·쓰기 작업을 중단해요. 이미 확인한 사진은 화면에, 이미 저장한 사진은 결과 폴더에 남아요. 읽지 못한 파일은 별도 목록에서 **다시 읽기**로 재시도해요. 사진 한 장의 저장이 실패해도 다른 사진은 계속 저장해요. **사진별 저장 결과**에서 성공·실패·미처리를 확인하고 **저장하지 못한 사진 재시도**로 해당 항목만 다시 저장해요. 새 문서를 추가하거나 선택을 취소해도 이전 결과를 유지해요. 각 결과의 저장 위치를 열 수 있어요. 같은 사진의 반복 저장은 새 이름을 붙여 기존 결과를 보존해요. **목록 비우기**와 **저장 폴더 선택**은 출력 작업을 정리해요. 호스트 출력 작업이 5분간 사용되지 않아 만료되면 이전 결과를 유지하고 재시도 시 폴더를 다시 선택하도록 안내해요. 원본 문서를 수정하거나 삭제하지 않아요.

## 범위와 한도

모든 작업은 PC 안에서 `fs 1.4` SDK와 모듈 Worker로 처리해요. 외부 서버·웹 저장소·다른 도구의 명부와 연결하지 않아요. TimeAlert의 학적 등록이나 전체 백업 가져오기를 구현한 도구는 아니에요.

파일 하나 최대 32MiB, ZIP 실제 확장 데이터 최대 128MiB, 미디어 하나 최대 16MiB, XML 하나 최대 4MiB·총 16MiB예요. ZIP 엔트리는 최대 4,096개, 시트는 최대 100개, 시트별 학생·머리글·앵커와 파일별 사진은 각각 최대 1,000개예요. 한 화면에 파일은 16개, 보관한 사진 합계는 128MiB까지 읽어요. 과대한 입력은 조용히 일부를 버리지 않고 읽기를 중단해요. 경로 탈출·중복 ZIP 경로·외부 관계·DTD는 거부해요. ZIP 해제와 학생 수집·사진 매칭은 Worker에서 실행하고, XML 순회는 중간에 화면 제어권을 돌려줘요. Worker는 90초에 중단해요.

## 검증과 출처

원본 `time_alert`의 `NeisRosterReader.kt`와 그 안의 `RosterCellParser`, `NeisRosterImporter.kt`를 읽고 TypeScript로 포팅했어요. 원본 파일은 수정하지 않았어요. 원본 회귀 배치의 학생 14·24·33명, 빈 셀, 다중 반, 머리글, 추측 매칭과 원본 바이트 보존을 합성 데이터로 검증해요.

브라우저에서 실제 ZIP Worker·사진 매칭·실제 PNG 썸네일을 확인했고, 합성 학생 4명과 사진 3장으로 이름 수정 후 3장 모두 원본과 바이트가 같음을 확인했어요. 브라우저 검증의 파일 선택·읽기·쓰기는 SDK fs mock 경계에서 확인했으며, 실제 학교 개인정보 파일과 Windows 저장 권한은 사용하지 않았어요.

## PDF 사진 출석부

`.pdf`를 추가하면 [NEIS 원작](https://github.com/rochelobeJYJ/neis_photocrop)의 흐름대로 200 DPI 렌더 → 어두운 사진 상자 탐지 → 상자 안의 번호·이름과 페이지 머리글 연결 → 테두리·사진 아래 여백 제거를 처리해요. 글자 방향을 기준으로 90도 단위 회전도 보정해요. XLSX는 기존 TimeAlert 기반 해석과 이미지 원본 바이트를 유지해요.

이름·여백 조정에서 `{학번} {학년} {반} {번호} {이름}`을 조합하고 PDF 네 방향 추가 여백을 지정할 수 있어요. 이미 읽은 PDF에 여백을 바꾸려면 ‘PDF 여백 다시 적용’을 눌러요. 이름 수동 수정과 저장된 결과는 유지해요.

현재 한도는 파일 32MiB, PDF 100쪽, 렌더 페이지와 원본에 포함된 이미지 각각 2,400만 픽셀, 사진 2,000장·총 128MiB예요. 글자가 없는 스캔 PDF의 이름을 OCR로 추측하지 않아요. 사진 상자가 없는 페이지, 잘못된 여백, 모호한 머리글, 중복 학번을 경고하며 확정하지 못한 사진은 미확인 이름으로 보존해요. 임의 사진 레이아웃 전체를 지원한다고 보장하지 않아요.

PDF.js Worker·CMap·디코더·대체 글꼴은 모듈 자체에 동봉하며 네트워크 서비스를 호출하지 않아요. [PDF 자산 라이선스 제안](../../docs/proposals/pdf-resource-license.md)은 최종 배포 전 확인 대상이에요.
