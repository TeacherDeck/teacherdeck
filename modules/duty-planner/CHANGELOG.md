# 변경 기록

## 0.5.2

- 실제 수행자를 뒤쪽 칸부터 선택하거나 앞쪽 칸을 비워도 다른 칸의 교사를 유지해요. 날짜·월을 오가거나 저장에 실패해도 입력한 수행자가 사라지지 않아요.
- 배정대로 수행 기록과 백업 복원은 해당 자료로 편집 칸을 갱신해요. 저장·백업·월 마감에는 빈 칸을 제외한 고유 수행자 목록을 보존해요.

## 0.5.1

- 이번 달·하루 인원·명단/참여 인원과 배정·저장을 위에서 확인해요. 이름 추가와 교사별 참여·횟수·요일 조건을 명단 준비 영역으로 모았어요.
- 빈 명단은 준비 영역을 펼쳐 Enter로 연속 추가하고, 저장한 명단이 있으면 접힌 상태에서 달력과 선택일 편집으로 시작해요. 휴일·토요일 색과 제외·선택·고정·수행 표시, 좁은 날짜 편집의 포커스 복귀를 유지해요.
- 도구 아이콘을 같은 선 굵기의 단색 SVG로 정리했어요.

## 0.5.0

- 하루 1~3명 달력 흐름을 유지하고, 필요할 때 펼치는 세부 편성으로 교시×시험실·야자 시간대·업무 구분을 추가했어요.
- 같은 시간 여러 장소에는 서로 다른 교사를 배정해요. 업무별 고정·제외·직접 교체와 기존 교사의 참여·날짜·요일·순번 조건을 먼저 지키고 누적 총횟수를 균등하게 맞춰요.
- 날짜 고정은 그 날짜 세부 업무에 최소 한 번 참여를 보장해요. 충돌·동시간 인원 부족은 조건을 풀지 않고 안내하며 기존 결과를 유지해요.
- 업무 칸별 실제 수행과 업무별 횟수를 확인해요. 기본 지도일과 세부 수행을 월 마감 시 함께 집계하고 과거 마감 수정은 기록을 다시 계산해요.
- 기존 상태와 v1 백업을 그대로 읽어요. 세부 자료가 있는 자체 백업은 v2로 보존하고, 이를 담지 못하는 원작 GAS JSON 내보내기는 명확히 거부해요. CSV에는 기본·세부 구분과 시간대·시험실을 함께 담아요.
- 세부 편성도 기존의 세대별 원자 저장을 사용해요. 실제 수행·고정·직접 배정이 있는 교사나 업무를 임의로 삭제하지 않아요.

## 0.4.0

- 원작 GAS JSON을 연도 확인과 복원 확인창을 거쳐 가져와요. 기초 누적 횟수·두 담당자 순번·배정불가·원래 날짜 행을 보존하고 실제 수행은 추정하지 않아요.
- 하루 세 명이나 여러 연도가 섞인 자료는 기존 형식으로 조용히 잘라내지 않고 자체 JSON 백업·CSV를 안내해요.
- 손상된 저장값이 있어도 정상 JSON 백업으로 복구해요. 새 월 자료를 모두 저장한 뒤 활성 자료를 바꾸므로 저장 실패 시 기존 자료와 잠금을 유지해요.
- 2027~2030 내장 공휴일을 추가했어요. KASI 달력자료·역서와 현행 법령을 대조했고, 향후 발표·변경 여부와 2030 선거일 수동 추가를 안내해요.

## 0.3.3

- 월 마감·다음 달 누적·원본 형식 내보내기에서도 실제 수행을 다시 집계해요.

## 0.3.2

- 직접 배정을 해제해도 현재 담당자와 다른 날짜의 배정을 유지해요.
- 조건 변경은 조건에 맞는 결과를 보존하고, 영향받은 날짜와 직접 배정 충돌을 안내해요.
- 짧은 달로 바꾸면 선택일을 유효한 날짜로 옮겨 없는 날짜의 메모·배정 편집을 막아요.
- 작은 창에서는 달력 날짜를 누르면 편집 대화상자를 열어 담당자와 메모를 바로 바꿔요. 배정 조건은 펼쳐서 사용해요.

## 0.2.0

- 담당 교사를 선택하면 직접 배정·교체가 바로 반영돼요. 고정·제외 충돌은 원인을 안내하며 유지해요.
