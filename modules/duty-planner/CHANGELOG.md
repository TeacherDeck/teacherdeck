# 변경 기록

## 0.2.0

- 기존 중식 지도 도구의 달력 중심 흐름을 살려 연월·배정·저장을 상단에 두고 달력과 날짜 편집을 나란히 보여줘요.
- 달력 셀의 날짜·담당자·상태 어느 곳을 눌러도 해당 날짜를 편집할 수 있어요.
- 교사 이름을 Enter로 연속 추가하고(한글 조합 중 Enter는 제외), 여러 명 붙여넣기는 펼쳐서 사용할 수 있어요.
- 날짜·교사를 고른 뒤 체크로 고정·제외 조건을 바꾸고, 과거 횟수·요일 제외도 바로 반영해요.
- 담당 교사를 선택하면 직접 배정·교체가 바로 반영돼요. 고정·제외 충돌은 원인을 안내하며 유지해요.

## 0.1.0

- 월별 실제 달력과 하루 1~3명 배정, 직접·붙여넣기 교사 명단을 지원해요.
- 교사별 고정·제외 날짜·제외 요일·과거 실제 수행 횟수와 월 전체 제외 날짜를 설정해요.
- 조건을 우선 지키며 과거 횟수를 포함한 총횟수를 최소비용흐름으로 균등하게 배정해요.
- 날짜별 직접 배정·교체를 유지하고, 충돌한 고정·제외 조건은 이유를 안내해요.
- 2026년 공휴일 22개 날짜를 자동 제외하며 지원하지 않는 연도는 경고해요.
- 저장·복원은 storage 캡으로 이 PC 안에서 처리하고, 재배정은 실제 수행 횟수를 올리지 않아요.
