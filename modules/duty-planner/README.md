# 지도일배정기

월별 지도일에 하루 1~3명의 교사를 배정해요. 이름과 과거 실제 수행 횟수를 직접 입력하거나 표에서 붙여 넣고, 고정 날짜·제외 날짜·제외 요일을 설정할 수 있어요. 처리는 PC 안에서 이루어져요.

## 사용 순서

1. 연도·월·하루 인원을 고르고 교사 이름을 입력하고 **Enter**를 누르거나 **추가**를 눌러요. 이름 칸에 포커스가 유지돼 연속해서 입력할 수 있어요. 여러 명은 **여러 명 붙여넣기**를 펼쳐 이름을 한 줄씩 넣고 **명단 적용**을 눌러요. 과거 횟수가 있으면 이름 옆 열에 함께 붙여넣을 수 있어요.
2. 달력에서 날짜를 눌러 **이 날짜는 지도하지 않아요**를 체크하면 학교 휴업일을 제외해요.
3. 조건을 바꿀 교사를 고르고, 선택한 날짜의 **고정**·**제외**를 체크해요. 과거 실제 수행 횟수와 제외 요일도 바로 반영돼요. 서로 충돌하는 조건은 임의로 해제하지 않아요.
4. 상단 **배정**을 눌러 남은 날짜를 균등하게 채워요. 교사 명단에서 과거·이번 배정·총횟수를 확인해요.
5. 달력 날짜를 눌러 담당 교사를 선택하면 교체가 바로 반영돼요. 하루 2~3명은 모든 칸을 고른 뒤 반영돼요. 다시 배정해도 직접 선택한 날짜는 유지돼요. 자동 배정으로 돌리려면 **직접 배정 해제**를 눌러요.
6. **저장**을 누르면 명단·조건·배정표를 이 PC에 저장하고 다음 실행 때 복원해요. 붙여넣기 명단은 **명단 적용** 후 저장해요.

월을 바꾸면 그 달의 명단·조건·배정·수행 기록을 복원해요. 새 달에는 명단과 요일 제외만 이어지고 날짜 고정·제외는 비워요. 저장을 누르면 화면에서 작업한 모든 달을 이 PC에 보관해요.

## 배정 기준

고정 배정·직접 배정·교사 제외·날짜 제외를 모두 지켜요. 조건이 충돌하면 자동으로 해제하지 않고 원인과 조정 방법을 안내해요. 남은 칸은 **과거 실제 횟수 + 이번 배정 횟수**의 제곱합을 최소화하는 최소비용흐름으로 배정해요. 이 방식은 모든 가능한 배정을 고려하여 조건 안에서 총횟수를 균등하게 맞춰요. 누적 제곱합이 같으면 당월 횟수를 먼저 균등하게 맞추고 날짜별 순환 점수를 사용해요. 마지막으로 교환 가능한 두 날짜를 바꾸어 누적·당월 횟수를 그대로 유지하면서 근접 배정을 줄여요. 같은 입력의 결과는 같아요. 하루에 같은 교사를 두 번 넣지 않아요.

미리보기·다시 배정·저장은 과거 실제 횟수를 증가시키지 않아요. 날짜별 실제 수행자를 선택하고 월 마감을 눌러요. 배정 기준은 직접 입력한 기초 횟수 + 다른 마감 월의 실제 수행 횟수예요. 과거 월 수정 후 다시 저장·마감하면 기록으로 재집계하여 중복 증가하지 않아요. 배정 연산은 Web Worker에서 실행하여 화면 조작을 막지 않아요.

이미 기록한 실제 수행은 그 날짜를 나중에 지도 제외일로 바꿔도 유지해요. 주말·휴일 조건 변경도 실제 횟수를 지우지 않으며 월 마감·다음 달 누적·내보내기에서 그대로 집계해요. 제외 조건은 앞으로의 배정을 제한하고, 실제로 하지 않은 기록은 수행자 기록에서 직접 수정해요.

## 공휴일 지원 범위

2026년의 법정 공휴일·대체공휴일·전국동시지방선거일 22개 날짜를 자동 제외해요. 2026년 5월 1일 노동절과 7월 17일 제헌절의 새 공휴일 지정도 포함해요. 2026년 9월 28일은 추석 대체공휴일에 포함하지 않아요.

- [한국천문연구원 2026년 월력요항 발표](https://www.kasi.re.kr/kor/post/newsMaterial/32031)
- [인사혁신처 2026년 4월 29일 공휴일 안내](https://www.mpm.go.kr/mpm/comm/newsPress/newsPressRelease/?boardId=bbs_0000000000000029&category=&cntId=4250&mode=view&pageIdx=)

2027~2030년에는 2026년 개정 법령을 반영한 내장 날짜를 자동 제외해요. 2027·2028년은 KASI 달력자료(공식 월력요항 발표 전 자료), 2029·2030년은 KASI 역서의 음력 환산표와 현행 대체공휴일 규정으로 대조했어요. 향후 월력요항·법령 변경은 확인해 주세요. 2028년 국회의원선거일은 선관위의 예정일로 표시하며, 2030년 선거일은 확정표로 넣지 않았으므로 공식 발표 후 직접 제외해 주세요. 2025년 이전·2031년 이후에는 자동 제외 범위 경고를 보여 줘요.

- [KASI 2027·2028 달력자료](https://astro.kasi.re.kr/life/post/calendardata)
- [KASI 2016 역서, 242쪽 음·양력 환산표](https://astro.kasi.re.kr/resources/file/compressed.tracemonkey-pldi-09.pdf)

- [중앙선거관리위원회 선거 달력](https://www.nec.go.kr/site/eng/02/10203000000002020070611.jsp)

추가 임시공휴일과 학교 재량휴업일은 달력 날짜를 누르고 지도하지 않는 날로 체크해 주세요. 실행 중 외부 자료를 조회하지 않아요.

## 저장과 제한

`storage` 1.0과 `fs` 1.1 캡을 사용해요. 명단은 다른 모듈과 공유하지 않아요. 저장값이 손상되거나 읽기에 실패하면 기존 저장값을 보호하기 위해 저장을 잠가요. **월 마감 · 백업 · 내보내기 → JSON 백업 복원**에서 정상 파일을 열고 확인하면 복구할 수 있어요. 복구 자료를 새 저장 공간에 모두 쓴 뒤 활성 자료를 바꾸며, 실패하면 기존 자료와 잠금을 유지해요. 기존 손상값은 삭제하지 않아요. 일반 저장도 편집한 모든 달을 함께 확정해요. 저장에 성공한 뒤 이전의 정상 저장 공간만 정리하고, 첫 복구 이전 자료는 그대로 남겨요. 저장할 내용이 256KiB를 넘으면 저장 요청 전에 용량 안내를 보여 줘요.

검증: 윤년·달 경계, 1~3명, 과거 횟수, 고정·제외 충돌, 직접 교체, 전역 최적 배정, 500명·31일 성능, SDK mock host 저장·복원·손상·용량 검사를 포함해요.

## 월별 수행 기록과 내보내기

교사별 참여 여부, 날짜별 고사일(하루 한 명), 메모를 설정해요. 배정한 교사와 실제 수행자가 다르면 실제 수행자 칸을 바꿔요. 월 마감은 중복으로 할 수 없어요. 마감 수정 열기로 해당 달 기록을 고쳐 다시 마감하면 다른 달의 배정 기준에 반영돼요. 마감하지 않은 실제 기록은 다음 달 기초 횟수에 포함하지 않아요.

JSON 백업은 월별 명단·조건·배정·수행 기록·메모·마감을 모두 보존해요. 파일 열기 후 구조를 검증하고 **복원 적용 → 확인하고 복원**으로 화면에 넣어요. 확인창 취소는 기존 작업을 유지해요. 정상 저장소에서는 저장을 눌러야 PC 저장값에 반영돼요. 손상 복구는 확인 시 저장까지 성공해야 잠금을 풀어요. Excel CSV는 현재 달의 배정·실제 수행·메모를 내보내요. 기존 형식 JSON은 원본 GAS의 months/counts 및 date/dayKor/exclude/exam/final1/final2/memo 키를 사용해요. 원본 형식은 2명과 같은 연도의 월만 보존해요. 세 번째 담당자나 여러 연도가 있으면 내보내기를 막고 자체 백업·CSV를 안내해요. 원작 JSON 가져오기는 자료의 연도를 직접 확인해요. 원작에는 실제 수행/미수행 구분과 개인 조건이 없어서 counts를 기초 횟수로 가져오고 수행 기록·월 마감은 비워요. 두 번째 담당자만 있는 날과 배정불가 표시는 보존해요. 원작에 없던 날짜는 자동 재배정에서 제외하고, 새로 메모·배정을 만든 날짜는 다시 내보낼 때 포함해요. 법정 공휴일 자동 제외는 현재 내장 기준을 적용하므로 원작의 제외 표시와 달라질 수 있어요. 파일은 선택 폴더 아래 새 결과 폴더로 저장하며 원본을 덮어쓰지 않아요.

원본의 추출된 4열 시간표를 붙여 넣으면 4교시 수업 없는 요일은 1번째, 있는 요일은 2번째 담당 조건으로 적용해요. 교사별 순번 허용 요일을 직접 조정할 수도 있어요. 새 교사 추가 시 기존 참여자의 누적 평균을 소수점 한 자리로 보정하며 기초 횟수는 0.1 단위로 수정해요. 시간강사는 참여 여부를 꺼 주세요. 원본 XLSX의 병합셀·연강 해석은 아직 자동으로 처리하지 않아요. 현재 알고리즘은 범용 지도일의 제약을 지키면서 누적 횟수 제곱합을 최소화해요. 원본 웹 로그인·온라인 공유는 PC 내부 처리 약속에 따라 제공하지 않아요. 공통 명부 연결, XLSX 병합셀 해석도 제공하지 않아요. 전체 기능 대조는 [리뷰](../../docs/reviews/duty-planner-parity.md)를 참고해 주세요.

배정대로 수행 기록은 교사가 직접 누르는 동작이에요. 선택 날짜 또는 오늘까지의 배정을 실제 수행자로 기록하며 미래 날짜는 자동 기록하지 않아요. 대체 수행자는 실제 수행자 칸에서 수정해요. 지난 마감 달을 열고 기록을 바꾼 뒤 다시 마감하면 누적 횟수가 현재 기록으로 재집계돼요.

달력의 빨간 날짜는 일요일·공휴일, 파란 날짜는 토요일이에요. 공휴일명과 지도 없는 날 표시를 함께 보여 줘요. ◆는 직접/고정 배정, ✓는 실제 수행 기록이며 선택한 날짜는 테두리와 선택 문구로 구별해요. 날짜를 누른 뒤 오른쪽 맨 위에서 교사를 바로 바꿀 수 있어요. 수행자 수정과 월 기록은 펼쳐서 사용해요.

작은 창에서는 날짜를 누르면 편집 대화상자가 열리고, 닫으면 선택한 날짜로 돌아와요. **배정 조건**을 펼쳐 하루 인원과 주말 제외를 바꿔요. 월을 바꾸면 선택일은 그 달에 있는 날짜로 옮겨요. 직접 배정 해제는 담당자를 지우지 않고 다시 자동 배정할 수 있게 고정만 풀어요. 조건 변경 시 유효한 기존 결과는 유지하고, 맞지 않는 날짜만 비운 뒤 안내해요. 직접 배정 조건은 임의로 해제하지 않고 충돌을 안내해요. 전체 균형을 다시 계산하려면 **배정**을 눌러요. 계산 중 조건 충돌이 발견되어도 남아 있는 기존 결과를 지우지 않아요.
