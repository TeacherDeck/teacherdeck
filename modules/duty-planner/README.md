# 지도일배정기

월별 지도일에 하루 1~3명의 교사를 배정해요. 이름과 과거 실제 수행 횟수를 직접 입력하거나 표에서 붙여 넣고, 고정 날짜·제외 날짜·제외 요일을 설정할 수 있어요. 처리는 PC 안에서 이루어져요.

## 사용 순서

1. 연도·월·하루 인원을 고르고 교사 이름을 입력하고 **Enter**를 누르거나 **추가**를 눌러요. 이름 칸에 포커스가 유지돼 연속해서 입력할 수 있어요. 여러 명은 **여러 명 붙여넣기**를 펼쳐 이름을 한 줄씩 넣고 **명단 적용**을 눌러요. 과거 횟수가 있으면 이름 옆 열에 함께 붙여넣을 수 있어요.
2. 달력에서 날짜를 눌러 **이 날짜는 지도하지 않아요**를 체크하면 학교 휴업일을 제외해요.
3. 조건을 바꿀 교사를 고르고, 선택한 날짜의 **고정**·**제외**를 체크해요. 과거 실제 수행 횟수와 제외 요일도 바로 반영돼요. 서로 충돌하는 조건은 임의로 해제하지 않아요.
4. 상단 **배정**을 눌러 남은 날짜를 균등하게 채워요. 교사 명단에서 과거·이번 배정·총횟수를 확인해요.
5. 달력 날짜를 눌러 담당 교사를 선택하면 교체가 바로 반영돼요. 하루 2~3명은 모든 칸을 고른 뒤 반영돼요. 다시 배정해도 직접 선택한 날짜는 유지돼요. 자동 배정으로 돌리려면 **직접 배정 해제**를 눌러요.
6. **저장**을 누르면 명단·조건·배정표를 이 PC에 저장하고 다음 실행 때 복원해요. 붙여넣기 명단은 **명단 적용** 후 저장해요.

월을 바꿔도 조건은 일 번호 기준으로 유지돼요. 새 달에서 조건을 확인해 주세요. 해당 달에 없는 고정·직접 배정 날짜는 오류로 알려요. 현재 한 달의 작업 상태만 저장해요. 여러 달의 배정표 보관·공통 명부 연결·파일 내보내기는 후속 기능이에요.

## 배정 기준

고정 배정·직접 배정·교사 제외·날짜 제외를 모두 지켜요. 조건이 충돌하면 자동으로 해제하지 않고 원인과 조정 방법을 안내해요. 남은 칸은 **과거 실제 횟수 + 이번 배정 횟수**의 제곱합을 최소화하는 최소비용흐름으로 배정해요. 이 방식은 모든 가능한 배정을 고려하여 조건 안에서 총횟수를 균등하게 맞춰요. 동점은 명단 순서로 결정하며 같은 입력의 결과는 같아요. 하루에 같은 교사를 두 번 넣지 않아요.

미리보기·다시 배정·저장은 과거 실제 횟수를 증가시키지 않아요. 실제 수행 기록·월 마감 기능은 없으며, 과거 실제 횟수는 교사 조건에서 직접 조정해요. 배정 연산은 Web Worker에서 실행하여 화면 조작을 막지 않아요.

## 저장과 제한

`storage` 1.0 캡만 사용해요. 명단은 다른 모듈과 공유하지 않아요. 저장값이 손상되거나 읽기에 실패하면 기존 저장값을 보호하기 위해 저장을 잠가요. 저장할 내용이 256KiB를 넘으면 저장 요청 전에 용량 안내를 보여 줘요.

검증: 윤년·달 경계, 1~3명, 과거 횟수, 고정·제외 충돌, 직접 교체, 전역 최적 배정, 500명·31일 성능, SDK mock host 저장·복원·손상·용량 검사를 포함해요.
