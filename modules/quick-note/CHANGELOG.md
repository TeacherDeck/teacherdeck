# 변경 기록

## 0.1.1

- 메모 목록에는 제목·본문 요약·고정 상태를 표시하고 선택한 메모의 전문과 수정·백업·고정·보관 조작은 상세 영역에 모았어요.
- 입력의 색·고정 설정을 접어 두고 Ctrl+Enter 저장·초안 보호·보관함·백업 확인과 복구를 유지해요. 수정·보관 뒤 목록 초점을 돌려줘요.
- 도구 아이콘을 메모지 형태로 다듬었어요.

## 0.1.0

- 빠른 작성·수정, 고정·색 구분, 제목·본문 검색과 보관함을 제공해요.
- 저장 실패 시 입력을 유지하며 JSON 항목/전체 백업과 확인 후 추가·복원을 지원해요.
- 손상 자료 입력 잠금, 원자료 사본 저장과 이전 자료 복구를 제공해요. 기존 자료 보존 실패 시 적용하지 않아요.
