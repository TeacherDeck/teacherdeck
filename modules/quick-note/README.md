# 빠른 메모

제목과 내용을 적고 **메모 저장**을 눌러요. 제목은 비워도 돼요. 내용 입력 중 `Ctrl+Enter`로도 저장해요. 저장에 실패하면 입력을 유지하며 다시 시도할 수 있어요. 입력 중인 내용은 저장 전 초안이며 앱을 닫으면 유지되지 않아요.

저장한 메모 목록에서 제목·본문 요약·고정 상태를 보고 하나를 선택해요. 오른쪽 상세 영역(좁은 창에서는 목록 아래)에서 전문을 읽거나 선택해 복사하고 **수정**, **항목 백업 저장**, **고정**, **보관**할 수 있어요. 네 가지 색은 **색 · 고정 설정**을 펼쳐 고르며 제목·내용을 검색해요. 보관한 항목은 **보관함 보기 → 보관 해제**로 돌아와요. 목록은 한 번에 20개를 보여 줘요. 작성 중 다른 메모를 살펴봐도 초안을 유지하며, 다른 메모를 수정하려 하면 먼저 저장하거나 입력 취소하도록 안내해요. 수정·보관 후 목록으로 초점을 돌려주고 새 메모 저장 후에는 입력으로 돌아와요.

## 백업·가져오기·복구

**항목 백업 저장**은 한 메모를, **백업 · 가져오기 → JSON 백업 저장**은 보관함을 포함한 저장 목록을 담아요. 새 결과 폴더에 파일을 만들며 원본 파일은 덮어쓰거나 삭제하지 않아요. 입력 중인 초안은 백업에 들어가지 않으므로 먼저 저장해 주세요.

**JSON 백업 가져오기**는 항목 수·보관 수·처음 다섯 제목을 미리 보여 줘요. 기본 **현재 목록에 추가**는 기존 항목을 유지하고, 같은 ID는 새 ID로 추가해요. 체크를 해제하고 **확인하고 복원**하면 목록을 교체해요. 취소하면 저장 목록과 초안을 유지해요. 가져온 항목이 검색 조건에 맞지 않거나 보관 항목이면 검색어를 지우거나 보관함을 열어 주세요.

적용 전에 기존 저장값을 `recovery.v1.<임의 ID>`에 보존해요. 보존 또는 저장 실패 시 기존 활성 목록을 유지해요. **이전 자료 찾기**에서 별도 보존한 자료를 선택해 사본을 저장하거나 확인 후 복원할 수 있어요. 손상된 자료를 읽으면 입력·저장을 잠그며 **다시 읽기**, **원자료 사본 저장**, 정상 백업 가져오기를 제공해요. 손상된 이전 자료도 사본 저장은 가능하지만 정상 문서로 검증되지 않으면 복원하지 않아요. 복구 사본은 자동 삭제하지 않으므로 모듈 전체 저장 한도에 도달하면 외부 백업과 앱 전체 데이터 관리가 필요해요.

## 형식·한도

기존 `storage` 1.0과 `fs` 1.1 캡만 사용하며 네트워크 요청·알림·외부 서비스 연결은 없어요. 활성 키는 `state.v1`, JSON은 `{format:"teacherdeck-quick-note",version:1,items:[...]}`예요. 각 항목은 ID·제목·본문·고정·색 구분(`tone`)·보관 여부·수정 시각을 보존해요. 미래 버전, 알 수 없는 필드, 중복 ID, 잘못된 값은 가져오기를 거부하며 일부 항목을 잘라 저장하지 않아요.

최대 200개, 제목 120자, 본문 4,000자이며 UTF-8 JSON 224KiB 이내예요. 한도에는 보관 항목도 포함해요. 글자 수를 넘는 입력은 반영하지 않으며 백업·추가 결과가 전체 한도를 넘으면 현재 자료와 초안을 유지해요. 정상 입력 백업은 동일 한도를 사용하고 손상 원자료 사본 내보내기는 256KiB까지예요.

## 원작 참고와 이번 범위

사용자가 지정한 [LivelySam](https://github.com/rochelobeJYJ/livelysam)의 메모 위젯(`js/widgets/memo.js`)에서 빠른 작성·수정, 고정·색, 검색·보관의 작업 흐름을 참고했어요. 저자는 rochelobeJYJ이며 원본은 [LivelySam Custom Proprietary License](https://github.com/rochelobeJYJ/livelysam/blob/main/LICENSE.md)를 적용해요. 원본 소스·자산을 복사하거나 포함하지 않고 TeacherDeck 공통 UI·SDK로 독립 구현했어요.

이번 범위는 로컬 메모와 JSON 이동·복구예요. 원본의 체크리스트 전용 편집, 공통 레코드 태그·범주·위젯 간 전환, 배경화면·외부 서비스 연계는 포함하지 않아요.

## 검증

합성 자료로 저장 실패 후 재시도, 보관·검색·재열기, 확인 창 취소와 초안 유지, 손상 자료 보존 실패·복원 재시도, ID 충돌 추가, JSON 엄격 검증·용량 제한, 파일 청크 읽기와 쓰기 실패 정리를 검사해요. 실제 설치본·Windows 파일 선택 창·DPI 조작 검증은 별도예요.

## 파일 입력과 저장 위치

파일을 끌어 놓으면 선택창 없이 기존 검증과 확인 절차로 읽고, 입력한 파일명과 결과를 화면에 표시해요. JSON 가져오기는 한 번에 한 파일씩 받아요. 처리 중이거나 지원하지 않는 형식이면 화면에서 이유를 알려요.

이 화면에서 가져오기를 완료한 자료와 연결된 결과는 원본 파일의 폴더에 새 이름으로 저장해요. 다른 폴더를 명시적으로 고르면 그 폴더에 바로 저장해요. 원본 파일이 없는 새 자료·양식·복구 사본은 저장할 폴더를 선택해요. 자동 하위 폴더를 만들거나 원본 파일을 덮어쓰지 않아요.
