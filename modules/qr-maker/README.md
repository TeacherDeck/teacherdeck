# QR 코드 만들기

링크 또는 글을 입력하면 QR 코드가 바로 나타나요. PNG 또는 SVG로 저장해 문서와 슬라이드에 넣을 수 있어요.

- **링크**: `http://` 또는 `https://`로 시작하는 주소를 입력해요. 앞뒤 공백만 제거하며 주소를 자동으로 바꾸지 않아요.
- **글**: 공백과 줄바꿈을 그대로 담아요. UTF-8 기준 2,000바이트까지 지원해요.
- **PNG**: 문서와 슬라이드에 넣는 기본 형식이에요. 모듈당 8픽셀로 그리며 흰 여백 4모듈을 포함해요.
- **SVG**: 크기를 바꾸거나 인쇄할 때 선명하게 쓸 수 있어요.
- 저장 폴더는 한 번 선택한 뒤 도구를 닫을 때까지 재사용해요. 같은 이름이 있으면 호스트가 새 이름으로 저장해요. 원본을 덮어쓰지 않아요.
- 생성은 이 PC의 작업 스레드에서 수행해요. 네트워크 요청, 내용 기록, 웹 저장소를 사용하지 않아요.

QR 인코더는 [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) 2.0.4(MIT)를 사용해요. 오류 정정은 M이며, 코드의 색과 여백은 테마와 관계없이 검정·흰색으로 유지해요. 파일 저장에는 fs 1.2 이상이 필요해요. 빌드 시 Vite의 의존성 고지를 생성하고 원래 인코더의 저작권·MIT 전문을 `qr-encoder-notice.txt`로 패키지에 동봉해요.

검증: `pnpm exec vitest run modules/qr-maker/src`로 입력 검증, 독립 디코더 해독, SDK mock 저장·취소, 이전 미리보기 방지를 확인해요.
