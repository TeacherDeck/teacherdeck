# 변경 기록

## 0.1.0

- 공개 YouTube 영상 한 개를 선택한 폴더 안의 새 결과 폴더에 MP4로 저장해요. `media-download` 1.0이 있는 앱이 필요해요.
- 첫 실행 환경 준비·다운로드·파일 확인을 구분하고 크기 진행, 취소와 조회 실패 재확인을 제공해요.
- 분리된 MP4 영상·M4A 음성도 PC 안에서 재인코딩 없이 합쳐 저장하며 처음 필요한 Deno·FFmpeg 준비를 안내해요.
- 다음 작업이 실패해도 앞서 저장한 파일의 위치 열기를 유지하고 언로드 중 늦은 시작 응답에도 취소를 요청해요.
- 로그인 요구·인증서·연결·지원 형식·크기 제한은 호스트의 고정 안내로 알려 주고 도움 프로세스 원문은 표시하지 않아요.
