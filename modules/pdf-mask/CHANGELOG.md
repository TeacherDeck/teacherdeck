# 변경 기록

사용자에게 보이는 변경은 버전을 올리고 여기에 적어요(MOD-013, VER-004). `requires`를 올리면 "필요 앱 버전"도 적어요.

## 0.1.1

- PDF 렌더링 자산과 글꼴 네 파일의 해시를 확인하고 원문 라이선스·원천 목록을 도구에 동봉해요.

## 0.1.0

- 전화번호·주민번호와 문맥이 있는 개인정보 후보, 검색어·CSV/TXT 목록을 찾아요.
- 페이지 미리보기에서 제거 후보를 확인하고 직접 사각 영역을 추가할 수 있어요.
- 선택 영역의 픽셀을 지운 이미지로 새 PDF를 만들고 텍스트·주석·첨부 제거를 확인해요.
- 원본 보호, 취소, 이미지·페이지·출력 한도를 적용했어요.
