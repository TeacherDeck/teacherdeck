# 변경 기록

## 0.2.2

- 자주 쓰는 자동 탐지와 페이지 확인을 먼저 보여 주고, 명단·검색어 관리·이미지 글자 다시 읽기·직접 지정 좌표는 필요할 때 펼치도록 정리했어요.
- 접힌 상태에서도 명단·검색어 포함 여부와 검색어·후보 수를 확인할 수 있어요.

## 0.2.1

- 도구 기능을 구분할 수 있는 공통 규격 아이콘으로 정리했어요.

사용자에게 보이는 변경은 버전을 올리고 여기에 적어요(MOD-013, VER-004). `requires`를 올리면 "필요 앱 버전"도 적어요.

## 0.2.0

- 스캔 PDF는 선택 즉시 PC 안에서 한국어·영어 OCR을 실행해 기존 개인정보 탐지에 연결해요. 글자와 사진이 섞인 문서는 현재 쪽·전체 쪽을 다시 읽을 수 있어요.
- OCR 엔진·모델을 고정 버전·해시·원문 라이선스와 함께 동봉해 외부 전송이나 첫 실행 다운로드 없이 동작해요.
- 읽기 취소·시간 초과·낮은 인식 신뢰도·빈 결과를 구분하고 실패하면 이전 문서와 직접 지정한 영역을 유지해요. 저장은 기존 픽셀 삭제·이미지 PDF 재작성 절차를 사용해요.

## 0.1.3

- PDF 글자 좌표와 읽는 방향을 사용해 같은 행의 분할 라벨·이름을 연결하고 라벨이 있는 영문 이름을 찾아요. 멀리 떨어진 열을 자동으로 합치지 않아요.
- 주소의 가까운 다음 줄을 함께 후보로 묶고 다른 항목·열·문단에서 멈춰요. 자동 탐지 한계와 명단·검색어 포함 여부·발견 건수를 화면에 보여줘요.
- 검색어·수동 지정과 선택 영역의 실제 픽셀 제거·새 이미지 PDF 작성은 유지해요. OCR과 무라벨 이름 추측은 추가하지 않아요.

## 0.1.2

- PDF의 확대 단위(UserUnit)를 글자 폭에 반영해 자동 제거 영역이 글자 끝까지 덮도록 고쳤어요. 회전과 잘라낸 페이지 범위를 함께 검사해요.

## 0.1.1

- PDF 렌더링 자산과 글꼴 네 파일의 해시를 확인하고 원문 라이선스·원천 목록을 도구에 동봉해요.

## 0.1.0

- 전화번호·주민번호와 문맥이 있는 개인정보 후보, 검색어·CSV/TXT 목록을 찾아요.
- 페이지 미리보기에서 제거 후보를 확인하고 직접 사각 영역을 추가할 수 있어요.
- 선택 영역의 픽셀을 지운 이미지로 새 PDF를 만들고 텍스트·주석·첨부 제거를 확인해요.
- 원본 보호, 취소, 이미지·페이지·출력 한도를 적용했어요.
