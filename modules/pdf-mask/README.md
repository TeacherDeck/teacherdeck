# PDF 개인정보 지우기

PDF 하나를 선택하면 전화번호·주민번호와 문맥이 있는 계좌번호·생년월일·주소·학번·이름의 후보를 찾는다. 직접 검색어, CSV 첫 열 또는 TXT 한 줄 목록을 함께 사용할 수 있다. 각 페이지 미리보기에서 선택을 해제하거나 사각 영역을 직접 추가한 뒤 새 결과 폴더에 저장한다. 원본은 변경하지 않는다.

출력은 선택 영역의 픽셀을 치환한 200 DPI PNG 페이지로만 새로 작성한 PDF다. 원본 페이지·텍스트·첨부·주석·속성 객체를 복사하지 않으며 저장 전에 텍스트·주석·첨부가 없는지 다시 확인한다. 검색·복사·벡터·양식·링크·서명은 사라진다. 탐지되지 않은 개인정보는 이미지에 남을 수 있으므로 각 페이지를 확인해야 한다. 스캔 페이지는 자동 OCR을 제공하지 않으며 직접 영역 지정으로 처리한다.

입력은 32 MB·100쪽까지, 이미지와 렌더 캔버스는 2,400만 픽셀까지, 출력은 128 MB까지 처리한다. 오류가 있는 PDF 또는 제한을 넘는 원본 이미지가 있으면 저장을 중단한다. 검색어와 개인정보는 저장소에 보관하지 않는다.

PDF.js 6.4.299와 pdf-lib 1.17.1, 모듈 내부 Worker와 로컬 폰트·CMap·WASM 자산을 사용한다. 네트워크 요청은 필요하지 않다. 동봉 LiberationSans의 라이선스 예외 검토가 끝나기 전 배포는 보류한다.

검증: 합성 PDF의 큰 글자 하강부와 0/90/180/270도 회전, 선택 영역 픽셀 삭제, 출력 재열기·텍스트/첨부/속성 제거, 큰 원본 이미지 거부를 검사했다. 범위·CSV 파싱·분할 텍스트·새 PDF 객체 테스트를 포함한다.
