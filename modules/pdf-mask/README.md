# PDF 개인정보 지우기

다른 도구로 잠시 이동해도 검토 중인 문서와 제거 영역을 유지해요. 실제 도구 종료나 앱 종료 때는 저장 여부를 확인해요. 다른 PDF를 열거나 문서를 비울 때는 미저장 영역을 버릴지 먼저 확인하며, 저장에 실패하면 현재 문서를 유지해요. 영역을 바꾸면 확인란에 다시 표시해야 저장할 수 있어요. 이 작업 보호는 정상 실행 중인 앱에 적용하며 강제 종료 뒤 복구는 지원하지 않아요.

PDF 내부 이미지 크기 검사는 별도 Worker에서 실행해요. 검사 중에도 취소할 수 있으며 90초를 넘기면 Worker를 종료하고 안내해요. 읽기에 실패해도 앞서 열어 둔 문서는 유지해요.

파일을 끌어 놓으면 입력한 파일명·목록과 추가 상태를 바로 표시해요. 저장 폴더를 지정하지 않으면 각 원본 파일과 같은 폴더에 새 결과 파일을 저장해요. **다른 저장 폴더 선택**으로 지정하면 선택한 폴더에 직접 저장해요. 결과 하위 폴더를 자동으로 만들지 않으며 기존 파일을 덮어쓰지 않아요. 원본이 없는 양식은 저장할 폴더를 직접 선택해요. 필요 앱 버전은 **0.8.0** (`fs ^1.4.0`)이에요.

0.2.0은 좌표상 같은 행의 분할 글자와 라벨을 연결하고, 라벨이 있는 한글·영문 이름을 후보로 찾아요. 가까운 다음 행에 이어진 주소도 함께 묶되 새 항목·다른 열·떨어진 문단에서 멈춰요. 주소 줄의 위치·표기와 글자 방향이 특이하면 누락될 수 있어요. 라벨 없는 이름은 무작정 추측하지 않으며 **명단·검색어도 후보에 포함**을 켜고 이름 목록을 추가해 주세요. 추가한 검색어 수와 발견 영역 수를 함께 보여줘요. 스캔 문서는 선택 즉시 한국어·영어 로컬 OCR로 읽어요. 글자와 사진이 섞인 문서는 현재 쪽 또는 전체 쪽을 다시 읽을 수 있어요. OCR도 누락·오인식이 있으므로 빈 결과를 개인정보 없음으로 판단하지 않아요. [탐지 회귀와 로컬 OCR 설계](../../docs/reviews/file-mask-detection-followup-2026-10-11.md)에 현재 한계를 구분했어요.

PDF의 확대 단위(UserUnit), 페이지 회전, 잘라낸 페이지 범위(CropBox)를 적용한 화면 좌표로 자동 제거 영역을 계산한다. 합성 확대·회전 입력으로 글자 시작과 끝이 제거 영역 안에 있는지 검사한다.

PDF 하나를 선택하면 전화번호·주민번호와 문맥이 있는 계좌번호·생년월일·주소·학번·이름의 후보를 찾는다. 직접 검색어, CSV 첫 열 또는 TXT 한 줄 목록을 함께 사용할 수 있다. 각 페이지 미리보기에서 선택을 해제하거나 사각 영역을 직접 추가한 뒤 원본과 같은 폴더 또는 직접 지정한 폴더에 새 파일로 저장한다. 원본은 변경하지 않는다.

출력은 선택 영역의 픽셀을 치환한 200 DPI PNG 페이지로만 새로 작성한 PDF다. 원본 페이지·텍스트·첨부·주석·속성 객체를 복사하지 않으며 저장 전에 텍스트·주석·첨부가 없는지 다시 확인한다. 검색·복사·벡터·양식·링크·서명은 사라진다. 탐지되지 않은 개인정보는 이미지에 남을 수 있으므로 각 페이지를 확인해야 한다. 스캔 페이지는 150 DPI 이미지에서 로컬 OCR을 실행하며, 자동 후보와 직접 지정 영역을 함께 사용할 수 있다. 90초 동안 응답이 없는 엔진은 종료하며 취소·실패한 작업은 기존 후보를 덮어쓰지 않는다.

입력은 32 MB·100쪽까지, 이미지와 렌더 캔버스는 2,400만 픽셀까지, 출력은 128 MB까지 처리한다. 오류가 있는 PDF 또는 제한을 넘는 원본 이미지가 있으면 저장을 중단한다. 검색어와 개인정보는 저장소에 보관하지 않는다.

PDF.js 6.4.299와 pdf-lib 1.17.1, 모듈 내부 Worker와 로컬 폰트·CMap·WASM 자산을 사용한다. 네트워크 요청은 필요하지 않다. 동봉 LiberationSans 네 파일은 승인된 한정 글꼴 예외와 원문 고지를 보존한다. OCR은 Tesseract.js 6.0.1, core 6.0.0, tessdata_fast 4.1.0의 한국어·영어 모델을 사용하며 모두 Apache-2.0 원문 고지와 해시 목록을 포함한다. 분리된 짧은 라벨을 읽도록 sparse-text 분할을 사용한다.

검증: 합성 PDF의 큰 글자 하강부와 0/90/180/270도 회전, 선택 영역 픽셀 삭제, 출력 재열기·텍스트/첨부/속성 제거, 큰 원본 이미지 거부를 검사했다. 범위·CSV 파싱·분할 텍스트·새 PDF 객체 테스트를 포함한다.

OCR 검증: 합성 이미지의 한국어 라벨·전화번호 인식, 탐지 영역 삭제 후 전화번호 재인식 불가, 외부 요청 0건을 실제 로컬 Worker에서 확인했다. 이 결과가 모든 문서의 완전한 자동 탐지를 보장하지는 않는다.
