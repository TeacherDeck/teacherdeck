# D-day

일정 이름과 날짜를 적고 **일정 저장**을 눌러요. 날짜는 `YYYY-MM-DD` 형식이며 분류는 선택이에요. 앞으로 남은 날은 `D-`, 지난 날은 `D+`, 오늘은 **D-Day · 당일**로 보여 줘요. PC의 로컬 날짜만 계산하며 시각·일광절약시간 때문에 하루가 틀어지지 않도록 날짜의 달력 값으로 비교해요. 화면은 30초마다, 창으로 돌아올 때, 표시 상태가 바뀔 때 오늘 날짜를 확인해요.

이름·분류·날짜로 검색하고 **수정**, **보관**, **보관 해제**를 할 수 있어요. **지난 일정 보관**은 오늘보다 이전인 활성 일정만 보관하며 당일 일정은 유지해요. 목록은 날짜순으로 한 번에 20개를 보여 줘요. 저장에 실패하면 입력과 목록을 유지해 다시 시도할 수 있어요. 입력 중인 내용은 저장 전 초안이며 앱을 닫으면 유지되지 않아요.

## 백업·가져오기·복구

**항목 백업 저장**은 한 일정을, **백업 · 가져오기 → JSON 백업 저장**은 보관함을 포함한 저장 목록을 담아요. 새 결과 폴더에 파일을 만들며 원본 파일은 덮어쓰거나 삭제하지 않아요. 초안은 백업에 들어가지 않으므로 먼저 저장해 주세요.

**JSON 백업 가져오기**는 항목 수·보관 수·처음 다섯 이름과 날짜를 보여 줘요. 기본 **현재 목록에 추가**는 기존 일정을 유지하고 같은 ID는 새 ID로 추가해요. 체크를 해제하고 **확인하고 복원**하면 목록을 교체해요. 취소하면 저장 목록과 초안을 유지해요. 가져온 항목이 검색 조건에 맞지 않거나 보관 항목이면 검색어를 지우거나 보관함을 열어 주세요.

적용 전에 기존 저장값을 `recovery.v1.<임의 ID>`에 보존해요. 보존 또는 저장 실패 시 기존 활성 목록을 유지해요. **이전 자료 찾기**에서 별도 보존한 자료를 선택해 사본을 저장하거나 확인 후 복원할 수 있어요. 손상된 자료는 **다시 읽기**, **원자료 사본 저장**, 정상 백업 가져오기로 복구하며 확인 전 입력·저장을 잠가요. 손상된 이전 자료도 사본 저장은 가능하지만 검증되지 않으면 복원하지 않아요. 복구 사본은 자동 삭제하지 않으므로 모듈 전체 저장 한도에 도달하면 외부 백업과 앱 전체 데이터 관리가 필요해요.

## 형식·한도

기존 `storage` 1.0과 `fs` 1.1 캡만 사용해요. 네트워크·예약 알림·외부 서비스 연결은 없어요. 활성 키는 `state.v1`, JSON은 `{format:"teacherdeck-dday",version:1,items:[...]}`예요. ID·이름·날짜·분류·보관 여부·수정 시각을 보존해요. 미래 버전, 알 수 없는 필드, 중복 ID, 존재하지 않는 날짜는 거부하며 일부 항목을 잘라 저장하지 않아요.

보관함을 포함해 최대 200개, 이름 120자, 분류 80자, 날짜 1900~9999년이며 UTF-8 JSON 224KiB 이내예요. 글자 수를 넘는 입력은 반영하지 않으며 추가 결과가 전체 한도를 넘으면 기존 자료와 초안을 유지해요. 정상 입력 백업은 동일 한도를 사용하고 손상 원자료 사본 내보내기는 256KiB까지예요.

## 원작 참고와 이번 범위

사용자가 지정한 [LivelySam](https://github.com/rochelobeJYJ/livelysam)의 D-day 위젯(`js/widgets/dday.js`)에서 이름·날짜·그룹, 남은 날짜 계산, 검색·보관·지난 일정 보관의 흐름을 참고했어요. 저자는 rochelobeJYJ이며 원본은 [LivelySam Custom Proprietary License](https://github.com/rochelobeJYJ/livelysam/blob/main/LICENSE.md)를 적용해요. 원본 소스·자산을 복사하거나 포함하지 않고 TeacherDeck 공통 UI·SDK로 독립 구현했어요.

이번 범위는 로컬 D-day와 JSON 이동·복구예요. 원본 공통 레코드·위젯 간 전환, 배경화면·외부 서비스·알림 연계는 포함하지 않아요.

## 검증

합성 자료로 윤년·일광절약시간 경계·과거·당일·미래의 날짜 계산, 엄격 JSON 검증·용량 제한, 보관·검색·재열기, 저장 실패 후 재시도, 확인 취소와 초안 유지, 손상 자료 복구 실패·재시도, ID 충돌 추가, 청크 파일 읽기·쓰기 정리를 검사해요. 실제 설치본·Windows 파일 선택 창·자정 복귀·DPI 조작 검증은 별도예요.
