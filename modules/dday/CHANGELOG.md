# 변경 기록

## 0.2.1

- 입력 중인 초안을 자동 보관하고 도구·앱을 다시 열 때 복원해요. 저장 직전 이탈·저장 실패 때 입력을 보호해요.


## 0.2.0

- 필요 앱 버전: 0.8.0. fs 1.4가 필요해요.
- 드래그한 파일을 선택창 없이 읽고 파일명과 입력 결과를 표시해요. 여러 가져오기 파일과 처리 중 입력은 안내해요.
- 가져온 파일과 연결된 결과는 원본 폴더에 새 파일로 저장해요. 별도 폴더를 선택한 경우 그 폴더에 바로 저장하고 자동 하위 폴더를 만들지 않아요.

## 0.1.1

- 도구 기능을 구분할 수 있는 공통 규격 아이콘으로 정리했어요.

## 0.1.0

- 로컬 날짜로 D-/D+/당일을 계산하고 이름·분류·검색·수정·보관·지난 일정 보관을 제공해요.
- 저장 실패 시 입력을 유지하며 JSON 항목/전체 백업과 확인 후 추가·복원을 지원해요.
- 손상 자료 입력 잠금, 원자료 사본 저장과 이전 자료 복구를 제공해요. 기존 자료 보존 실패 시 적용하지 않아요.
