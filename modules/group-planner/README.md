# 모둠 만들기

첫 화면에서 번호·이름 명단과 모둠 수/한 모둠 목표 인원을 적용하고 바로 편성한다. 공통 명부 연결 없이 임시 명단으로 사용할 수 있다. TeacherDeck 0.3.0 이상에서는 공유 승인 후 설정의 공통 명부를 불러온다. 불러오기 대기 중 확정한 이력은 보존한다. 그 사이 명단이 바뀌거나 다른 저장이 진행 중이면 응답을 적용하지 않고 다시 읽도록 안내한다. 기존 명단이 있는 작업은 공통 명부 입력을 접어 편성 결과부터 살펴본다.

교사의 학생 고정·모둠 전체 고정·이번 제외·학생 분리 조건이 최우선이다. 고정 모둠이 목표 인원보다 커도 유지하며 나머지 인원을 고르게 나눈다. 충돌은 자동으로 완화하지 않는다. 전체 고정이 남은 학생 배치를 막거나 고정과 분리가 충돌하면 원인을 안내한다. 제한 시간 안에 탐색을 끝내지 못한 경우와 불가능을 판정한 경우를 구분한다. 탐색 예산은30ms/20,000노드로 제한한다.

학생을 다른 모둠으로 직접 이동하거나 두 학생을 교환할 때도 같은 조건을 검사한다. 편성 확정만 이력을 추가하고 다시 편성·미리보기는 이력을 바꾸지 않는다. 확정 이력은 당시 이름·번호·모둠을 보존하며 동일 편성을 중복 확정하지 않는다. 명단 변경·새 조건 적용은 확정 이력을 유지한다.

명단1,000명·최대1,000모둠·분리조건200쌍·확정이력20건을 지원한다. storage 저장이 완료된 뒤 화면에 적용하고 실패 시 이전 자료를 유지한다. 손상 저장값의 변경을 잠그되 확인 후 정상 기록 가져오기·새 작업으로 복구하며 복구 저장 실패 시 잠금을 유지한다. 기록 파일은 이 도구의 JSON 형식이며 원본을 덮어쓰지 않고 새 결과 폴더에 저장한다. 가져오기와 새 작업은 확인 후 적용한다.

학생 보기는 모둠별 이름·번호와 활동 이름만 보여준다. 화면 복제에 사용하며 window 1.1 이상에서는 **확장 학생 화면**에서 모니터를 선택해 별도 학생 창을 연다. 보조 화면을 우선 선택하지만 교사가 표시 대상을 확인한다. 현재 공개 결과는 열기·갱신 버튼을 눌러야 반영하며 편집·추첨·배정은 자동 반영하지 않는다. 창 닫힘은 안내하고 모니터 연결·배율 변경은 공개 내용을 비워 재선택을 요청한다. 기존 window 1.0에서는 화면 복제용 학생 보기를 유지한다. 학생 기기 접속은 제공하지 않는다. 순수 불변식·SDK 저장·화면 흐름 테스트를 갖추고 통합 담당자가 실제 파일 입출력·키보드·DPI·테마·`pnpm verify`를 확인한다.

확정 이력은 반복하는 학생 식별자·이름을 사전과 정수 튜플로 보존하고 세대별 청크로 저장한다. 청크당240KiB 미만·한 작업 압축 자료2MiB·모듈 전체5MiB를 검사한다. 1,000명 명단의 확정 이력20건을 512,858바이트로 무손실 왕복한 합성 검증이 있다. 예전 단일 JSON도 읽는다. 복구는 확인 후 마지막 참조 전환이 성공했을 때만 잠금을 푼다. 한도를 넘는 이력은 자르지 않고 이전 자료를 유지한다.

100명이 넘는 학생 조건 목록은50명씩 표시하고 번호·이름으로 찾는다. 대명단의 고정 모둠은 번호로 입력하며0은 고정 안 함이다. 작은 명단은 기존 모둠 선택 목록을 유지한다. 페이지와 검색은 실제 학생 명단·조건을 바꾸지 않는다.

확장 화면 검증: 공개 자료 화이트리스트·명시 갱신·revision·연결 해제·닫힘·늦은 응답 회귀를 합성 테스트로 검사한다. 실제 여러 모니터·Windows DPI·확장 창 배치는 별도 통합 검증 대상이다.
