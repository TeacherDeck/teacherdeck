# 변경 기록

## 0.2.0

- 파일을 끌어 놓으면 입력한 파일과 추가 상태를 바로 보여 주며, 자동 처리에 파일·폴더 선택창을 열지 않아요.
- 별도 지정이 없으면 각 원본과 같은 폴더에 새 파일로 저장하고, 다른 폴더를 지정하면 그 폴더에 직접 저장해요. 자동 결과 하위 폴더를 만들지 않아요.
- 기존 파일은 덮어쓰지 않으며, 같은 이름은 별도 이름으로 저장해요.
- 필요 앱 버전: 0.8.0 (fs 1.4).

사용자에게 보이는 변경은 버전을 올리고 여기에 적어요(MOD-013, VER-004). `requires`를 올리면 "필요 앱 버전"도 적어요.

## 0.1.3

- 실행 방식을 옵션에서 선택하고, 정렬·수동 편집·충돌 확인 뒤 실행 구역에서 복사나 원본 변경을 시작해요. 취소·진행 표시와 결과·보호된 되돌리기를 각 단계에 모았어요.
- 긴 미리보기는 하나의 목록 스크롤로 확인하며, 키보드로 실행 영역에 바로 이동할 수 있어요. 50행 페이지 보기와 이름 재료 상세는 유지해요.

## 0.1.2

- 문서의 시험·평가 월을 편집 날짜보다 우선하며 완전한 날짜를 일반 월 후보에서 제외해요. 학기·분기에서 얻은 월은 추정으로 표시해요.
- 시험명에서 과목을 잘못 얻지 않도록 하고 괄호의 상세 과목·과목 단계와 사용자 분류 키워드를 보존해요. 수능 교시의 과목 추론은 수능 문서에만 적용해요.

## 0.1.1

- 부분 실행 후 5분이 지난 이름 변경 계획은 계속 실행하지 않아요. 완료한 결과와 이력을 유지하고 실패·미처리만 새 미리보기로 옮기도록 안내해요.

## 0.1.0

- 직접 패턴·엑셀 정확 연결·문서 정보의 세 방식을 같은 목록과 미리보기에 담았어요. 수동 편집, 정렬·순서 이동, 미연결 행 지정, 패턴 저장과 XLSX 양식 저장을 제공해요.
- 새 폴더 복사를 기본으로 하며 청크 복사·취소·완료 결과 보존·실패와 미처리 재시도를 지원해요.
- 별도 확인한 원본 이름 변경과 호스트의 지속 이력·보호된 되돌리기를 추가했어요. 이름 교환·대소문자 변경, 재시작 중단 복구, 파일 ID·내용·수정 시각·목적지 보호를 검사해요. 복사 결과를 삭제하지 않아요.
- XLSX의 패키지 루트 관계 경로와 텍스트·명시적 숫자 서식의 선행 0을 지원해요. PDF/HWP5/HWPX 상단 추출은 후보로 표시하며 직접 수정값을 유지해요.
- 필요한 앱 버전: 0.3.0 (`fs ^1.3`, `file-ops ^1.0`, `storage ^1.0`). PDF 자산 고지 원문·출처·해시를 검증하고 동봉해요.
