# 퀵캡처

폴더를 선택한 뒤 영역을 띄워 두면 Ctrl+Shift+C 또는 영역 더블클릭으로 PNG/JPG를 바로 저장해요. 영역 안 드래그로 이동하고 가장자리·모서리로 크기를 조절해요. 설정 화면을 닫거나 다른 도구로 이동해도 시작한 캡처 세션은 유지돼요. 명시적으로 캡처 종료 또는 TeacherDeck 종료 시 끝나요.

저장 폴더 기억은 사용자가 선택해요. 기억한 폴더가 사라지면 다시 선택해야 해요. 파일명은 연번·날짜 시각·내 접두어를 지원하고 중복은 번호를 붙여 새 파일로 저장해요. 기존 파일을 덮어쓰거나 삭제하지 않아요. 단축키 변경 충돌은 기존 조합을 유지해요. 수정한 설정은 실행 중인 캡처에 설정 적용으로 반영해요.

Windows 네이티브 capture/overlay/global-shortcut 1.0, fs 1.2, storage 1.0을 사용해요. 물리 픽셀 좌표를 사용하고 혼합 DPI·음수 화면 좌표를 지원해요. 화면 pixels나 폴더 경로를 외부로 전송하지 않아요. 모니터 변경·잠금 화면·권한 오류는 캡처 실패로 안내해요. 최대 영역 32Mi픽셀, 축 16384px이며 커서는 포함하지 않아요.
