# 퀵캡처

폴더를 선택한 뒤 영역을 띄워 두면 Ctrl+Shift+C 또는 영역 더블클릭으로 PNG/JPG를 바로 저장해요. 하나의 투명 영역 창 위에 작은 도구줄을 표시해요. 영역 안 드래그로 이동하고 가장자리·모서리로 크기를 조절해요. 설정 화면을 닫거나 다른 도구로 이동해도 시작한 캡처 세션은 유지돼요. 명시적으로 캡처 종료 또는 TeacherDeck 종료 시 끝나요.

저장 폴더 기억은 사용자가 선택해요. 기억한 폴더가 사라지면 다시 선택해야 해요. 파일명은 연번·날짜 시각·내 접두어를 지원하고 중복은 번호를 붙여 새 파일로 저장해요. 기존 파일을 덮어쓰거나 삭제하지 않아요. 유효한 설정은 입력을 마친 뒤 250ms 후 자동 적용해요. 캡처 중 바꾼 설정은 작업이 끝난 뒤 반영하고 단축키 충돌은 기존 조합을 유지해요.

Windows 네이티브 capture/overlay/global-shortcut 1.0, fs 1.2, storage 1.0을 사용해요. 물리 픽셀 좌표를 사용하고 혼합 DPI·음수 화면 좌표를 지원해요. 화면 pixels나 폴더 경로를 외부로 전송하지 않아요. 모니터 변경·잠금 화면·권한 오류는 캡처 실패로 안내해요. 최대 영역 32Mi픽셀, 축 16384px이며 커서는 포함하지 않아요.

저장 설정과 캡처 설정을 나란히 보여 줘요. 단축키 버튼을 누른 뒤 실제 조합을 누르고 Esc로 취소해요. 한글 입력 상태에서도 물리 키를 인식해요. 테두리 색은 색 선택기를 사용하며 좌표·직접 키 선택·색 코드·폴더 연결 해제는 고급 설정에 있어요.

화면 상단에 영역을 놓으면 도구 모음을 영역 아래로 옮겨 실제 캡처 좌표를 유지해요. 아래쪽 공간도 없으면 도구 모음을 화면 안의 영역 위에 표시하며, 캡처 때 창을 숨겨 도구 모음이 결과에 들어가지 않게 해요. 도구 모음은 최소 300DIP 폭을 확보하고 상태 문구를 줄여 버튼을 유지해요. 실제 캡처 영역은 5×5px부터 지원하며 이동 버튼과 지금 캡처 버튼을 사용할 수 있어요. 키보드로 이동 버튼을 실행하면 설정이 열려 물리 픽셀 좌표를 바꿀 수 있어요. 마지막 세션 종료는 숨겨진 메인 창을 다시 표시하고, 표시가 실패하면 복귀용 트레이를 유지해요.
