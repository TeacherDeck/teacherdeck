# 변경 기록

## 0.1.4

- 시작/지금 캡처, 저장 장수, 현재 단축키와 폴더 변경을 주 화면에 두고 파일 형식·파일명·테두리 설정은 접어서 조절해요.
- 저장 폴더 연결 끊김과 캡처·설정 실패, 단축키 충돌은 설정을 접어도 표시해요. 기존 단축키와 즉시 적용, 고정 영역·더블클릭·Enter·자동 저장을 유지해요.
- 도구 아이콘을 같은 선 굵기의 단색 SVG로 정리했어요.

## 0.1.3

- 기존 캡이 지원하는 F13~F24, Space·Enter·방향키를 실제 조합 입력과 고급 키 선택에 추가했어요. F12와 수정키 없는 조합은 기존 캡 정책에 따라 제외해요.

## 0.1.2

- 마지막 캡처 세션을 끝내면 숨겨 둔 메인 창으로 돌아와요.
- 화면 상단에서도 도구 모음을 화면 안에 놓고 실제 캡처 좌표는 유지해요.
- 5px의 작은 영역에서도 도구 모음의 이동·캡처·설정 버튼을 사용할 수 있어요.

## 0.1.1

- 원본의 저장/캡처 두 설정 영역을 복원하고 색 선택기와 실제 키 조합 입력을 제공해요.
- 유효한 설정을 자동 적용하며 캡처 중 변경은 작업 뒤에 반영해요. 단축키 충돌은 기존 키를 유지해요.

- 폴더 교체 중 캡처가 겹쳐도 새 폴더 연결을 마저 적용하고, 충돌했던 단축키를 다시 선택할 수 있어요.

## 0.1.0

- 이동·크기 조절 가능한 지속 영역, 전역 단축키·더블클릭·트레이 캡처를 추가했어요.
- PNG/JPG 자동 폴더 저장, 파일명 세 가지, 폴더 기억·권한 해제, 연번 초기화와 비덮어쓰기를 지원해요.
- 네이티브 세션 복원과 입력 검증, 시작 실패 리소스 정리를 적용했어요.
