# 이미지 자르기

사진 위를 직접 끌어 자를 영역을 고르는 기본 이미지 편집 도구예요. JPG·PNG·WebP 정지 이미지를 여러 개 추가하고, 회전·반전한 뒤 새 파일로 저장해요.

1. **파일 추가** 또는 끌어 놓기로 사진을 추가해요.
2. 사진을 끌어 영역을 고르고, 영역 안쪽을 끌어 이동하거나 모서리를 끌어 크기를 바꿔요. 자유 비율과 1:1·4:3·3:4·16:9·9:16을 고를 수 있어요.
3. **현재 사진 저장**을 누르고 처음 한 번만 폴더를 선택해요. 같은 작업은 한 결과 폴더에 모으며 저장한 뒤 다음 사진으로 이동해요. **전체 사진 저장**은 각 사진에 남겨 둔 편집을 한 번에 저장해요.

방향키로 영역을 이동하고 Shift+방향키로 크기를 바꿔요. Ctrl을 함께 누르면 10픽셀씩 바꿔요. **픽셀로 정확하게 지정**에서 왼쪽 X·위쪽 Y·너비·높이를 숫자로 입력해도 돼요. 화면 미리보기는 원본 좌표를 쓰므로 표시 크기나 창 크기가 바뀌어도 같은 영역을 잘라요.

**오른쪽으로 90도 회전**, **좌우 반전**, **상하 반전**을 지원해요. 회전할 때 영역을 선택한 비율로 다시 잡아요. **현재 설정을 모두 적용**은 회전·반전·비율과 사진 안의 상대적인 자르기 범위를 다른 사진에도 적용해요. 사진마다 구도가 다를 수 있으므로 이전/다음 사진으로 확인해 주세요.

**크기·밝기·대비**에서 저장 너비를 바꾸면 자르기 비율에 맞춰 높이를 정해요. 밝기·대비는 100%가 원본이며 0~200% 범위에서 조정해요. 저장 크기는 한 변 10,000px·2,400만 화소를 넘으면 실패하고 줄여서 저장하지 않아요.

**텍스트·사각형 표시**에서는 한 줄 텍스트(200자 이내) 또는 사각형 테두리 한 개를 넣어요. 위치·사각형 크기는 회전한 사진 전체의 백분율이고 글자 크기는 원본 픽셀이에요. 표시 색을 선택할 수 있으며 자르기 밖 표시는 저장 결과에 포함하지 않아요. 여러 레이어·자유 그리기·개인정보 영구 제거 도구는 아니에요. **편집 되돌리기 / 편집 다시 적용**은 각 사진의 크롭·회전·반전·크기·조정·표시를 최근 20단계까지 복원해요. 저장된 파일을 덮거나 삭제하지 않아요.

PNG는 투명도를 유지하고, JPG는 투명 부분을 흰 배경으로 저장해요. JPEG의 EXIF 방향은 읽을 때 적용해요. 결과는 촬영 정보를 제거한 새 이미지이며 원본은 그대로 남아요. 파일명 뒤에 `_자르기`를 붙이고 이름이 겹치면 순번으로 구분해요.

같은 사진을 다시 저장하면 번호를 붙인 새 파일을 만들어요. **목록 비우기**로 새 작업을 시작하거나 **다음 저장 폴더 변경**을 누르면 다음 저장 때 폴더를 다시 선택해요. 사진별 저장 결과에 성공·실패·아직 저장하지 않은 사진을 표시하고, **저장하지 못한 사진 재시도**는 실패·미처리 항목만 처리해요. 각 항목에서 저장 위치를 열 수 있어요.

## 처리와 한도

모든 읽기·쓰기는 fs 1.1 SDK만 사용해요. 사진 디코딩·회전·반전·자르기·인코딩은 Worker의 OffscreenCanvas로 처리해요. 실제 출력은 원본 픽셀의 지정 영역으로 만들며, 화면 미리보기만 긴 변 1,400px로 줄여요. 큰 중간 회전 캔버스를 따로 만들지 않고 결과 캔버스에 바로 그려요.

파일당 64MiB·2,400만 화소, 한 작업 1,000개까지 추가해요. 원본 캐시는 합계 128MiB까지 보관하고, 캐시 밖 사진은 선택·저장할 때 핸들로 다시 읽어요. 한 번에 한 사진만 읽고 Worker에서 처리하므로 파일 수만큼 원본을 모두 메모리에 올리지 않아요. 보관한 미리보기는 합계 32MiB로 제한하고, 그보다 큰 미리보기는 사진을 고를 때 다시 만들어요. 움직이는 APNG·WebP, GIF·HEIC와 알 수 없는 형식은 지원하지 않아요. 읽지 못한 사진은 **다시 읽기**로 재시도해요. Worker는 90초에 중단해요.

**취소**는 Worker와 파일 전송을 중단해요. 읽기가 끝난 사진과 편집 내용은 화면에 남고, 저장이 끝난 결과는 새 폴더에 남아요. 사진 한 장의 처리 실패는 다른 사진 저장을 막지 않아요. 폴더 선택을 취소하면 파일을 만들지 않고 기존 결과를 유지해요. 출력 작업은 호스트에서 5분간 사용하지 않으면 만료될 수 있어요. 만료를 감지하면 기존 결과를 유지하고, 재시도할 때 새 폴더를 선택하도록 안내해요. 출력 핸들은 목록 비우기·저장 폴더 변경·화면 종료 때 정리해요.

## 범위

이 도구는 새로 만든 기본 이미지 편집기예요. 기존 `simple_crop`의 PDF 사진명렬표 자동 추출·테두리 제거·학생 정보 인식 기능을 이식한 도구는 아니에요. PDF 사진명렬표 추출은 **명렬표 사진 꺼내기** 모듈의 별도 기능으로 제공해요. XLSX 사진명렬표의 원본 사진 추출은 **명렬표 사진 꺼내기** 모듈을 사용해요.

합성 좌표·비율·픽셀 한도·SDK 출력/취소·화면 편집 흐름 테스트를 수행해요. production Worker 번들은 별도 Skia Canvas 어댑터에서 실제 PNG/JPG 픽셀로 크기·밝기·대비·텍스트·사각형·회전·자르기·PNG 투명도·JPG 흰 바탕을 확인했어요. 이는 Chromium/WebView의 OffscreenCanvas 실증을 대신하지 않으며, 실제 브라우저·native UI와 EXIF 방향 검증은 남아 있어요. Worker에는 메인 화면이 공개 폰트 토큰을 전달하여 React·Fluent 런타임을 포함하지 않아요.
