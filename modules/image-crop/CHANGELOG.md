# 변경 기록

## 0.3.0

- 파일을 끌어 놓으면 입력된 파일 이름과 읽기·처리 상태를 바로 보여줘요. 저장 위치를 묻는 탐색창은 자동으로 열지 않아요.
- 기본은 각 원본 파일과 같은 폴더에 새 결과 파일을 저장해요. 저장 폴더를 따로 고르거나 원본 폴더로 돌아갈 수 있고, 결과 하위폴더를 자동으로 만들지 않아요.
- `fs ^1.4.0`의 원본·폴더 핸들을 사용하며 기존 파일은 덮어쓰지 않아요.

## 0.2.1

- 도구 기능을 구분할 수 있는 공통 규격 아이콘으로 정리했어요.

## 0.2.0

- 이미지 Worker는 메인 화면에서 공개 폰트 토큰을 받아 UI 런타임을 불러오지 않고 텍스트를 그려요.

- 한 작업에 사진 1,000개를 추가해요. 원본 캐시 128MiB·미리보기 32MiB 상한은 유지하고 나머지는 선택·저장 때 순차로 다시 읽어요.
- 자르기 비율을 유지하는 출력 크기, 밝기·대비, 한 줄 텍스트·사각형 표시를 미리보기와 실제 PNG·JPG 출력에 적용해요.
- 사진마다 최근 편집 20단계를 되돌리거나 다시 적용해요. 전체 적용도 각 사진에서 되돌릴 수 있어요.
- 읽기·저장 중 추가한 사진과 취소 후 미처리 사진을 보존하며 원본 크기가 바뀐 사진은 저장하지 않아요.

## 0.1.2

- 파일 처리 진행률을 실제 완료 비율로 표시해요.

- 한 편집 작업의 결과 폴더를 유지해 연속 저장할 때 폴더를 다시 고르지 않아요.
- 사진별 저장 성공·실패·미처리를 유지하고 저장하지 못한 사진만 재시도해요.
- 작업 종료·목록 비우기·저장 폴더 변경 때 출력 핸들을 정리하고, 만료되면 새 폴더 선택을 안내해요.

## 0.1.1

- 공통 UI의 제목·본문 여백과 좁은 화면 입력 폭 수정을 반영했어요.

## 0.1.0

- 사진을 직접 끌어 영역을 고르고 숫자·방향키로 정밀하게 지정해요.
- 자유·고정 비율, 90도 회전, 좌우·상하 반전을 지원해요.
- 여러 사진을 순서대로 편집하거나 현재 설정을 모두 적용하고 PNG·JPG로 저장해요.
- fs 1.1로 새 결과 폴더에 저장하며 원본을 유지해요. Worker와 파일 작업을 취소할 수 있어요.
- PDF 사진명렬표 자동 추출과 별개인 새 기본 이미지 편집 도구예요.
- 원본 128MiB와 별개로 미리보기 캐시를 32MiB로 제한해요. 큰 미리보기는 선택할 때 다시 만들어요.
