# 변경 기록

## 0.1.2

- 파일 처리 진행률을 실제 완료 비율로 표시해요.

- 한 편집 작업의 결과 폴더를 유지해 연속 저장할 때 폴더를 다시 고르지 않아요.
- 사진별 저장 성공·실패·미처리를 유지하고 저장하지 못한 사진만 재시도해요.
- 작업 종료·목록 비우기·저장 폴더 변경 때 출력 핸들을 정리하고, 만료되면 새 폴더 선택을 안내해요.

## 0.1.1

- 공통 UI의 제목·본문 여백과 좁은 화면 입력 폭 수정을 반영했어요.

## 0.1.0

- 사진을 직접 끌어 영역을 고르고 숫자·방향키로 정밀하게 지정해요.
- 자유·고정 비율, 90도 회전, 좌우·상하 반전을 지원해요.
- 여러 사진을 순서대로 편집하거나 현재 설정을 모두 적용하고 PNG·JPG로 저장해요.
- fs 1.1로 새 결과 폴더에 저장하며 원본을 유지해요. Worker와 파일 작업을 취소할 수 있어요.
- PDF 사진명렬표 자동 추출과 별개인 새 기본 이미지 편집 도구예요.
- 원본 128MiB와 별개로 미리보기 캐시를 32MiB로 제한해요. 큰 미리보기는 선택할 때 다시 만들어요.
