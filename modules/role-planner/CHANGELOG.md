# 변경 기록

사용자에게 보이는 변경은 버전을 올리고 여기에 적어요(MOD-013, VER-004). `requires`를 올리면 "필요 앱 버전"도 적어요.

## 0.2.1

- 복구·새 작업 확인창을 열 때만 생성해 닫힌 확인창의 초점 처리와 겹치지 않게 해요.
- 복구 검증은 선택한 기록의 확인창 안에서 가져오기를 눌러 확인 전 원본 보존을 검사해요.

## 0.2.0

- 설정에 등록한 공통 명부에서 학급·수업을 연결하고, 필요할 때 현재 작업으로 불러와요.
- 직접 입력과 임시 작업을 유지하며, 같은 재학 식별자의 기존 횟수·조건과 확정 이력을 보존해요.
- 공통 연결은 TeacherDeck 0.3.0 이상에서 사용할 수 있고 이전 앱에서는 직접 입력을 유지해요.

## 0.1.0

- 역할별 필요인원과 학생 고정·제외 조건을 먼저 반영하고 총 수행횟수가 낮은 대상부터 배정해요.
- 배정·재편성으로 횟수를 늘리지 않고 실제 수행 완료만 기록해요.
- 직접 교환·개별 완료·마지막 완료 되돌리기·새 배정·파일 보관·화면 복제용 학생 보기를 제공해요.
- 명단1,000명·역할100개·필요인원 합계1,000명·완료 기록10,000건을 지원해요.
- 총횟수 집계를 한 번 계산해 큰 명단도 빠르게 배정하고 손상 자료를 확인 후 복구해요.
- 배정은 Worker에서 실행하고 취소·30초 중단 시 이전 배정을 유지해요.
- 대명단 조건·배정 결과는50명씩 확인하며 검색하고 담당자는 결과 위에서 교환해요.
