# 역할·당번 나누기

첫 화면에서 명단·역할별 필요인원을 붙여넣고 적용한다. 전체 학생을 모두 배정할 필요가 없다. 고정·제외·정원 조건을 먼저 지키고, 남은 자리에 총 실제 수행횟수가 가장 적은 대상을 선정한다. 역할별횟수·업무 가중치는 첫 버전에서 균등 기준으로 사용하지 않는다.

고정과 제외가 충돌하거나 고정 인원이 역할 정원을 넘으면 조건을 자동으로 풀지 않고 안내한다. 직접 담당자를 바꾸거나 이미 배정된 학생과 교환할 때도 모든 고정·제외·정원을 검사한다. 편성·다시 배정·미리보기는 횟수를 바꾸지 않고 개별·일괄 수행 완료로 학생마다 1회 기록한다. 완료 기록이 있는 배정은 수정하지 못하도록 보호하며 완료를 되돌리거나 새 배정으로 이어간다. 새 배정은 총횟수와 교사 조건을 유지한다.

공통 명부 없이 임시 명단으로 사용할 수 있다. TeacherDeck 0.3.0 이상에서는 설정의 공통 명부를 공유 승인 후 불러온다. 대기 중 저장한 수행 기록은 최신 작업에 보존하며, 명단 자체가 바뀌거나 다른 저장이 진행 중이면 적용하지 않고 다시 읽도록 안내한다. 명단 수정 후 이전 수행 기록의 당시 이름·번호·역할은 그대로 유지한다. 변경은 storage에 저장한 뒤 화면에 적용하고 실패 시 이전 기록을 유지한다. 손상된 저장값은 빈 작업으로 자동 대체하지 않는다. 확인을 거친 정상 파일 가져오기·새 작업으로 복구할 수 있고 복구 저장 실패 시 잠금을 유지한다.

잠시 빠졌던 동일 학생은 **이 작업의 이전 학생과 기록 연결**을 명시적으로 선택해 번호·이름이 일치하는 이전 ID·기존횟수·수행 이력을 복원한다. 기본은 제거된 학생과 연결하지 않으며 다른 반은 새 작업으로 분리한다. 과거의 같은 번호·이름에 여러 ID가 있으면 연결을 거부한다. 입력에 기존횟수를 명시하면 그 값이 우선한다. 개선 이전에 제거한 학생은 완료 기록으로 ID를 찾지만 제거 당시 기초 횟수는 직접 확인해 입력해야 한다. 보관 학생은 최대10,000명이며 기록 파일에도 함께 저장한다.

역할 결과는 먼저 카드 격자로 보여준다. 고정·제외 조건과 행별 담당자 교환은 펼쳐 사용하고, 작은 명단도 번호·이름으로 조건을 검색할 수 있다. **수행 완료 한꺼번에 기록**을 누르면 미수행 학생을 이번 기록에서 제외한 뒤 인원을 확인해 적용한다. 이것은 실제 수행 기록이며 배정 미리보기·대화상자 취소는 집계하지 않는다. 이미 완료한 학생은 다시 집계하지 않으며 저장 실패 시 이전 기록을 유지한다.

명단1,000명·역할100개·필요인원 합계1,000명·완료기록10,000건을 지원한다. 기록 파일은 이 도구의 JSON 형식이며 원본을 덮어쓰지 않고 새 결과 폴더에 저장한다. 파일 가져오기와 새 작업은 변경 전 확인한다. 학생 보기는 역할별 이름·번호·배정 이름만 보여주며 화면 복제에 사용한다. window 1.1 이상에서는 **확장 학생 화면**에서 모니터를 선택해 별도 학생 창을 연다. 보조 화면을 우선 선택하지만 교사가 표시 대상을 확인한다. 현재 공개 결과는 열기·갱신 버튼을 눌러야 반영하며 편집·추첨·배정은 자동 반영하지 않는다. 창 닫힘은 안내하고 모니터 연결·배율 변경은 공개 내용을 비워 재선택을 요청한다. 기존 window 1.0에서는 화면 복제용 학생 보기를 유지한다. 학생 기기 접속은 제공하지 않는다.

순수 로직·SDK 저장·실제 화면 흐름 테스트를 갖추고, 통합 담당자가 실제 파일 입출력·키보드·DPI·테마·`pnpm verify`를 확인한다.

저장 형식은 문자열 사전·정수 튜플로 수행 기록을 보존하고 세대별 청크로 저장한다. 청크당240KiB 미만·한 작업 압축 자료2MiB·모듈 전체5MiB를 검사하고 마지막 참조 전환이 성공한 뒤 화면에 적용한다. 예전 단일 JSON도 읽으며, 한도를 넘는 기록을 조용히 버리지 않는다.

역할 배정은 모듈 내부 Worker에서 실행한다. 처리 중 배정 취소와 30초 중단을 제공하며 취소·실패는 저장된 이전 배정을 유지한다. 총횟수 맵과 후보 한 번 정렬로 배정 비용을 줄인다. 100명이 넘으면 학생 조건과 배정 결과를50명씩 표시하고 번호·이름으로 찾는다. 대명단의 담당자 교환은 결과 위의 바꿀 담당자·새 담당자 두 선택으로 처리해 후보 목록을 행마다 만들지 않는다. 작은 명단은 기존 행별 교환을 유지한다.

확장 화면 검증: 공개 자료 화이트리스트·명시 갱신·revision·연결 해제·닫힘·늦은 응답 회귀를 합성 테스트로 검사한다. 실제 여러 모니터·Windows DPI·확장 창 배치는 별도 통합 검증 대상이다.

## 파일 입력과 저장 위치

파일을 끌어 놓으면 선택창 없이 기존 검증과 확인 절차로 읽고, 입력한 파일명과 결과를 화면에 표시해요. JSON 가져오기는 한 번에 한 파일씩 받아요. 처리 중이거나 지원하지 않는 형식이면 화면에서 이유를 알려요.

이 화면에서 가져오기를 완료한 자료와 연결된 결과는 원본 파일의 폴더에 새 이름으로 저장해요. 다른 폴더를 명시적으로 고르면 그 폴더에 바로 저장해요. 원본 파일이 없는 새 자료·양식·복구 사본은 저장할 폴더를 선택해요. 자동 하위 폴더를 만들거나 원본 파일을 덮어쓰지 않아요.
