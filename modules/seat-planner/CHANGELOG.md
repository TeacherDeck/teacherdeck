# 변경 기록

## 0.4.0

- 필요 앱 버전: 0.8.0. fs 1.4가 필요해요.
- 드래그한 파일을 선택창 없이 읽고 파일명과 입력 결과를 표시해요. 여러 가져오기 파일과 처리 중 입력은 안내해요.
- 가져온 파일과 연결된 결과는 원본 폴더에 새 파일로 저장해요. 별도 폴더를 선택한 경우 그 폴더에 바로 저장하고 자동 하위 폴더를 만들지 않아요.

## 0.3.1

- 도구 기능을 구분할 수 있는 공통 규격 아이콘으로 정리했어요.

## 0.3.0

- 교사 화면을 유지하며 선택한 모니터에 공개 결과만 확장해 보여줘요. 갱신은 버튼으로 확인하고, 화면 연결 변경·닫힘을 안내해 다시 선택할 수 있어요. 기존 화면 복제용 학생 보기도 유지해요.

사용자에게 보이는 변경은 버전을 올리고 여기에 적어요(MOD-013, VER-004). `requires`를 올리면 "필요 앱 버전"도 적어요.

## 0.2.2

- 공통 명부를 기다리는 동안 확정한 자리 이력을 보존해요. 명단 자체가 바뀌면 불러오기를 중단해요.
- 명단이 있는 작업에서는 공통 명부 입력을 접고 배치를 먼저 살펴봐요.
- 1,000자리 회귀 검증은 정확한 레이블·접근성·조건 검색을 유지하면서 불필요한 전체 좌석 이름 계산을 줄였어요.

## 0.2.1

- 학생 조건 검색·쪽 변경 중에는 교실 자리 화면을 다시 그리지 않아 큰 명단을 빠르게 탐색해요.
- 자리별 학생 조회에 인덱스를 사용해 큰 교실의 반복 명단 탐색을 줄여요.

## 0.2.0

- 설정에 등록한 공통 명부에서 학급·수업을 연결하고, 필요할 때 현재 작업으로 불러와요.
- 직접 입력과 임시 작업을 유지하며, 같은 재학 식별자의 기존 횟수·조건과 확정 이력을 보존해요.
- 공통 연결은 TeacherDeck 0.3.0 이상에서 사용할 수 있고 이전 앱에서는 직접 입력을 유지해요.

## 0.1.0

- 임시 명단 입력·파일 읽기부터 교실 행·열·통로·비워둘 자리와 학생별 고정·제외·앞줄·분리 조건을 설정해요.
- 필수 조건을 지키는 배치 미리보기와 두 자리 클릭·끌기 교환, 교사 시점, 지난 자리·옆자리 반복 줄이기를 지원해요.
- 확정 당시 이름을 보존하고 확정본만 학생 보기·복사용 텍스트·새 파일로 공개해요.
- 1000명·1000자리와 학생 조건 검색·쪽 나누기를 지원하고 조각 저장·응답 유실·손상 자료 복구를 검증했어요.
