# 회의록

화자를 고르고 발언을 직접 입력하는 수동 회의록 도구예요. 원본 meeting_note의 ‘참석자 입력 → 회의 시작 → 화자 선택 → Enter 기록’ 흐름을 TeacherDeck 공통 UI로 옮겼어요.

1. 시작 화면에 회의 제목, 참석자(한 줄에 한 명, 최대 12명), 장소·결석자를 입력하고 **회의 시작**을 눌러요. `Ctrl+Enter`로도 시작해요.
2. 화면에 보이는 참석자 버튼이나 `Alt+1~9`, `0`, `-`, `=`로 화자를 골라요. 한 번 고른 화자는 계속 유지돼요. `Alt+↑/↓`는 이전/다음 화자, `Alt+백틱`은 화자 미지정이에요.
3. 발언을 입력하고 Enter를 눌러요. 한국어 조합 중에도 한 번만 눌러 기록해요. `Shift+Enter`는 줄바꿈, `Ctrl+Enter`는 강제 기록이에요.
4. 기록은 시간·화자·본문의 짧은 행으로 시간순으로 표시돼요. 각 행의 **화자**를 누르면 바로 화자를 정정할 수 있어요. **수정**으로 입력창에서 고친 뒤 Enter로 저장하거나 Esc로 취소해요. **삭제**, **기록 되돌리기**, **다시 적용**도 지원해요. `Ctrl+Alt+숫자`는 마지막 기록의 화자를 정정하고, 빈 입력창에서 `Ctrl+Z`는 기록을 되돌려요.
5. **참석자(F9)**에서 명단을 바꿔요. 기존 기록의 화자 이름은 그대로 남아요. **도움말(F4)**에서 단축키와 입력 기호를 확인해요.

## 기록 종류

**종류 · 비공개 선택**을 펼치면 **발언·결정·조치·질의·안건** 버튼과 **비공개 메모** 체크박스를 쓸 수 있어요. 원본 입력 기호도 그대로 쓸 수 있어요.

| 기호                   | 의미                         |
| ---------------------- | ---------------------------- |
| `! 내용`               | 결정                         |
| `* 내용 @담당자 ~기한` | 조치                         |
| `? 내용`               | 질의                         |
| `# 내용`               | 안건                         |
| `// 내용`              | 비공개 메모                  |
| `2 내용`               | 그 기록에만 2번 화자 적용    |
| `\내용`                | 기호 해석 없이 본문으로 기록 |

`! \3 학년 예산안`처럼 기호 뒤 숫자의 화자 해석도 끌 수 있어요. `2:1로 가결`은 본문으로 남아요. 비공개 안건은 공개 제목으로 내보내지 않아요.

## 파일 저장과 불러오기

**내보내기(F8)**에서 마크다운·일반 텍스트·결정/조치 요약을 미리 보고 선택해 Ctrl+C로 복사해요. **공개용 파일 저장**은 비공개 메모를 제외해요. **.json 백업 저장**은 현재 회의, 비공개 메모와 초안을 모두 담는 개인 보관 파일이에요. JSON 원문을 화면에 표시하지 않아요.

파일 저장 시 폴더를 선택하면 그 안에 새 결과 폴더를 만들고 파일을 저장해요. 기존 파일은 덮어쓰지 않아요. **파일(.json) 불러오기**는 TeacherDeck 백업과 원본 meeting_note의 회의 JSON을 받아요. 선택한 파일만 fs 1.1 캡으로 읽고 결과도 SDK로 저장해요. 파일 선택을 취소하면 현재 회의를 유지해요. 입력 파일은 최대 2MiB이며 자동 저장 한도(250KiB)를 넘는 회의는 전환하지 않아요.

한글·워드용 HTML 파일은 안건별 기록, 결정 목록과 조치 표의 서식을 담아요. HTML 파일을 브라우저에서 열어 본문을 선택해 복사할 수 있어요. 0.4부터 clipboard 1.0이 있는 호스트에서는 내보내기 창의 서식 복사 버튼도 사용할 수 있어요.

## 자동 저장·위원회·지난 회의

현재 회의와 입력 중 초안은 TeacherDeck storage 캡으로 PC 안에 저장해요. 350ms 동안 입력이 없을 때 순서대로 저장하며 다시 열면 복원해요. 저장 실패 안내는 성공하기 전까지 유지돼요. **지금 저장**을 누르거나 `.json 백업 저장`으로 보관해 주세요. 즉시 앱 종료와 iframe 언로드의 비동기 저장 완료를 보장할 수 없으므로 **저장했어요** 안내를 확인해 주세요. 실제 Windows 한국어 IME·DPI 검증은 별도예요.

시작 화면의 **위원회 · 저장된 명단**에서 명단을 최대 40개까지 저장하고 불러와요. 동일 이름은 명단 저장·갱신으로 갱신해요. 명단 삭제는 확인 창을 거치고, 원본 위원회 JSON 가져오기와 전체 명단 파일 저장을 지원해요.

**새 회의**나 파일·지난 회의 불러오기 전에 현재 회의를 지난 회의에 먼저 보관해요. 보관/새 회의 저장 실패 시 현재 회의를 유지하고, 전환 중에는 입력을 잠시 잠가 새 발언이 사라지지 않게 해요. 지난 회의는 최대 20개이며 가득 차면 새 보관을 중단해요. 오래된 회의를 자동으로 삭제하지 않아요. 개별 값 250KiB·모듈 전체 5MiB 한도 때문에 20개보다 먼저 가득 찰 수 있어요. **지난 회의 → 보관 제거**에서 확인 후 앱 내 보관을 제거하면 자리를 비울 수 있어요. 현재 회의와 외부 백업 파일은 유지해요.

## 출처와 저자

gritiquol의 MIT 라이선스 **meeting_note** 원본(2026)의 화면 흐름, 화자 유지, 단축키, 입력 기호와 비공개 제외 동작을 참고했어요. 원본 코드는 복사하지 않고 TeacherDeck SDK·공통 UI·React TypeScript로 구현했어요. 원본 파일은 수정하지 않았고 TeacherDeck 모듈 기여자 표기는 module.json에 유지했어요.

동명이인은 순번으로 구분하고 내부 ID로 기록을 연결해요. 명단에서 빠졌더라도 기록이 있는 화자는 최대 24명까지 보존해요. 각 기록의 화자 선택 상자로 즉시 정정하고, 안건 삭제 시 기록을 앞 안건에 합치는 동작을 확인해요. 공개 파일의 종료 시각은 비공개 메모를 제외한 마지막 발언 시각이에요.

## 0.4의 복사와 입력 처리

내보내기(F8)의 **서식을 유지해 복사**를 누르고 한글·Word에서 붙여넣으면 제목·표·굵은 화자·줄바꿈을 전달해요. **텍스트 복사**는 서식 없는 공개 본문을 전달해요. 두 복사 모두 비공개 메모를 제외하며, 기록을 읽거나 자동 복사하지 않아요. clipboard 1.0이 없는 구형 호스트에서는 공개용 파일 저장을 사용해요. 호스트의 256KiB 출력 한도를 넘는 회의록은 잘라 복사하지 않고 파일 저장을 안내해요. 실제 문서 앱의 붙여넣기 결과는 앱별로 달라질 수 있어요.

타이핑 중 기존 기록 목록과 내보내기 문서를 다시 만들지 않아요. 명단에서 빠진 화자는 기존 기록에 보존되며, 현재 명단을 다시 열 때에는 활성 참석자만 표시해요. 브라우저 및 자동화 검증은 실제 Windows 한국어 IME의 입력 지연 측정과 구별해요.

## 0.5 화면 흐름

원본처럼 상단에 회의 정보와 내보내기·참석자·도움말, 중앙에 연속 기록과 오른쪽 화자 목록, 하단 전체폭에 2줄 입력창을 두어요. 화자마다 보조색과 번호키 표식을 표시하고 선택한 화자를 강조해요. 현재 안건·화자와 입력 기호를 입력창 바로 위에 표시해 연속 입력 중 확인할 수 있어요. 기록별 큰 화자 선택 상자는 기본으로 접고 행의 **화자** 버튼으로 열어요. 처음에는 참석자 입력에 초점을 두고 저장된 위원회를 바로 불러올 수 있어요.

기존 기록을 수정하거나 취소해도 작성 중인 새 발언 초안과 종류·비공개 선택은 보존해요. 수정 내용만 저장하고 초안을 입력창에 돌려놓으며, 검토하던 목록 위치도 유지해요. 낮은 창에서는 기록 목록에 최소 다섯 줄 높이를 확보하고 종류·비공개 선택을 대화상자로 열어요. 텍스트 확대 때문에 더 많은 공간이 필요하면 작업 영역을 스크롤할 수 있어요.
