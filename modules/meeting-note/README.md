# 회의록

화자를 등록하고 발언을 직접 입력하는 수동 회의록 도구예요. 음성 인식이나 AI 요약은 사용하지 않아요.

1. **회의 설정과 화자 등록**을 펼쳐 회의 제목과 화자 명단(한 줄에 한 명, 최대 12명)을 입력하고 **화자 등록**을 눌러요.
2. `Alt+1~9`, `Alt+0`, `Alt+-`, `Alt+=`로 화자를 선택해요. 선택한 화자는 다음 기록에도 유지돼요. `Alt+백틱`은 화자를 미지정으로 바꿔요.
3. 내용을 입력하고 Enter를 눌러요. 한국어 조합 중 Enter는 조합 종료 후 기록하고 Shift+Enter는 줄바꿈해요.
4. **기록 되돌리기**, **다시 적용**으로 마지막 기록을 되돌리거나 복원해요.
5. **공개용 텍스트 보기**에서 내용을 선택하고 Ctrl+C로 복사해요. 비공개 메모는 공개용 텍스트에 포함되지 않아요.

## 입력 기호

| 기호                   | 의미                       |
| ---------------------- | -------------------------- |
| `! 내용`               | 결정                       |
| `* 내용 @담당자 ~기한` | 조치                       |
| `? 내용`               | 질의                       |
| `# 내용`               | 안건                       |
| `// 내용`              | 비공개 메모                |
| `2 내용`               | 그 기록에만 2번 화자 적용  |
| `\내용`                | 기호 해석 없이 그대로 기록 |

`! \3 학년 예산안`처럼 기호 뒤 숫자의 화자 해석도 끌 수 있어요. `2:1로 가결`은 본문으로 유지해요. 비공개 안건(`#`)은 공개 안건으로 바뀌지 않아요.

## 저장과 제한

저장은 TeacherDeck storage 캡으로 PC 안에서만 처리해요. 현재 회의와 입력 중 초안을 자동 저장하고 다시 열면 복원해요. 불러오기에 실패하면 저장을 시작하지 않아요. 저장은 순서대로 처리하며 350ms 동안 입력이 없을 때 실행해요. 입력과 기록 목록은 별도로 렌더하며 화면에는 최근 100건을 보여요. 공개용 텍스트에는 전체 공개 기록이 담겨요.

저장 값이 250KiB를 넘거나 저장이 실패하면 안내가 표시돼요. **전체 보관용 텍스트 보기**에서 비공개 메모와 초안을 포함한 JSON 텍스트를 개인 보관하고 **지금 저장**을 눌러 주세요. 전체 보관용 텍스트에는 비공개 메모가 포함되므로 다른 사람에게 전달하지 마세요. 도구 전환 중에도 입력 상태를 유지하도록 keepAlive를 사용하고 화면이 숨겨지거나 닫힐 때 대기 중인 저장을 요청해요. 즉시 앱 종료와 LRU에 따른 iframe 언로드에서는 저장 완료를 보장할 수 없고, 네이티브 환경 검증도 아직 하지 않았어요. 저장 완료 안내를 확인해 주세요.

현재 호스트에는 파일 내용 읽기·쓰기와 클립보드 캡이 없어 파일 내보내기, JSON 가져오기, 서식 유지 복사, 과거 회의 보관함은 후속 작업이에요. 자동 클립보드 호출이나 브라우저 다운로드로 우회하지 않아요. 이 버전은 현재 회의 한 건을 다뤄요.
