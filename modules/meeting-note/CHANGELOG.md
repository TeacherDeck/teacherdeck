# 변경 기록

## 0.6.0

- 필요 앱 버전: 0.8.0. fs 1.4가 필요해요.
- 드래그한 파일을 선택창 없이 읽고 파일명과 입력 결과를 표시해요. 여러 가져오기 파일과 처리 중 입력은 안내해요.
- 가져온 파일과 연결된 결과는 원본 폴더에 새 파일로 저장해요. 별도 폴더를 선택한 경우 그 폴더에 바로 저장하고 자동 하위 폴더를 만들지 않아요.

## 0.5.4

- 현재 회의 정보와 회의 중 조작을 정리하고 지난 회의·새 회의는 가벼운 관리 버튼으로 구분했어요.
- 입력 아래 작은 행에 되돌리기·다시 적용·저장 상태·지금 저장을 모았어요. 저장과 관리 작업 오류는 입력 근처에서 계속 보여 줘요.
- 기록 목록이 좁을 때 기록과 조작을 세로로 배치해 확대된 버튼이 옆으로 잘리지 않게 했어요.
- 화자 선택·Enter 기록·한글 조합·수정·자동 저장 흐름을 유지하고 도구 아이콘을 회의 기록 형태로 다듬었어요.

## 0.5.3

- 원본처럼 진행 중인 회의의 경과시간을 분·시간으로 보여 줘요. 긴 회의와 창 복귀에도 갱신하며 입력창은 그대로 유지해요.

## 0.5.2

- 숫자 접두어로 입력한 기록의 화자를 정정한 뒤 본문을 수정해도 현재 화자와 기록 정보를 유지해요.
- 수정 중에는 `@`·`~`·숫자를 본문으로 보존하고 조치 담당자·기한을 별도 입력칸에서 바꿔요.
- 저장 자료를 읽지 못하면 다시 읽기·현재 회의 계속하기·백업 복구를 제공해요. 복구 전 원래 자료를 별도로 보관하며 보관 실패 시 대체하지 않아요.
- 손상된 회의와 위원회 목록의 원자료를 새 폴더에 내보낼 수 있어요.

## 0.5.1

- 기존 기록의 수정·취소·자동 저장 중에도 작성 중인 새 발언 초안과 종류·비공개 선택을 보존해요.
- 과거 기록 수정과 화자 변경 뒤 검토하던 목록 위치를 유지하고 새 기록만 따라가요.
- 버튼에서 Space를 눌렀을 때 입력창으로 초점을 빼앗지 않아요.
- 낮은 창에서는 보조 선택을 대화상자로 열고 기록 목록의 가용 높이를 보장해요.

## 0.5.0

- 원본의 상단 도구/중앙 기록·오른쪽 화자/하단 전체폭 입력 흐름을 복원했어요.
- 시간·화자·종류·본문을 짧은 행으로 보이고 화자 변경은 행 버튼으로 열어요.
- 화자별 Fluent 보조색·번호키 표식·선택색·발언 통계와 현재 안건을 표시해요.
- 처음 열면 참석자 입력에 초점을 두고 저장된 위원회를 바로 불러올 수 있어요. 종류·비공개 보조 선택은 접어 두어요.
- 기존 단축키·한글 조합·자동 저장·공개 복사·백업 기능을 유지해요.

## 0.4.0

- 승인된 clipboard 1.0이 있는 호스트에서 공개용 회의록을 표·제목·굵은 화자와 함께 복사해요. 구형 호스트에서는 파일 저장을 계속 제공해요.
- 타이핑·화자 선택 시 기존 기록 목록을 다시 그리지 않고, 내보내기 창을 열 때만 문서를 생성해요.
- 이전 참석자를 보존하면서 현재 참석자 편집·단축키 순서를 분리하고 안건을 발언 건수에서 제외해요.

## 0.3.0

- 동명이인 화자 구분과 명단에서 빠진 기존 화자의 기록 보존을 추가했어요.
- 개별 기록 화자 선택, 발언 건수, 안건 삭제 확인을 추가했어요.
- 위원회 갱신·삭제·JSON 가져오기·내보내기를 추가했어요.
- 공개 마지막 발언 시각, 안건별 기록, 결정 목록·조치 표, 한글·워드용 HTML 파일 출력을 추가했어요.

## 0.2.0

필요 앱 버전: 0.1.0 이상(fs 1.1).

- 참석자 입력 후 회의 시작, 보이는 화자 버튼, 시간순 기록으로 원본 흐름을 복원했어요.
- 발언 수정·삭제·되돌리기, Alt+↑↓, Ctrl+Alt+숫자, F4/F8/F9를 지원해요.
- 기록 종류 버튼과 비공개 체크박스를 제공해 입력 기호를 몰라도 기록할 수 있어요.
- fs 1.1로 공개용 텍스트·마크다운·요약 파일과 비공개 포함 JSON 백업을 새 폴더에 저장해요.
- 원본/TeacherDeck JSON 불러오기, 위원회 명단 저장, 지난 회의 보관·복원을 지원해요.
- 회의 전환 중 입력을 동결하고 저장/보관 실패 시 현재 회의를 유지해요.

## 0.1.0

- 화자 등록, Alt 단축키 선택 및 화자 유지를 지원해요.
- 한국어 조합을 보호하며 Enter로 연속 기록해요.
- 결정·조치·질의·안건·비공개 입력 기호를 지원해요.
- 기록 되돌리기와 복원, 비공개를 제외한 공개용 텍스트 보기를 제공해요.
- SDK storage로 자동 저장하고 재시작 시 현재 회의를 복원해요.
- 도구 전환 중에도 입력 상태를 유지하고, 저장 실패 시 비공개 메모·초안을 포함한 개인 보관 텍스트를 제공해요.
