# 변경 기록

## 0.3.1

- 문서를 추가해도 앞서 변환한 결과와 실패 안내를 유지해요. 기본 변환은 대기 중인 문서만 처리하고 실패·중지 문서는 별도 다시 변환으로 처리해요.

## 0.3.0

- 파일을 끌어 놓으면 입력한 파일과 추가 상태를 바로 보여 주며, 자동 처리에 파일·폴더 선택창을 열지 않아요.
- 별도 지정이 없으면 각 원본과 같은 폴더에 새 파일로 저장하고, 다른 폴더를 지정하면 그 폴더에 직접 저장해요. 자동 결과 하위 폴더를 만들지 않아요.
- 기존 파일은 덮어쓰지 않으며, 같은 이름은 별도 이름으로 저장해요.
- 필요 앱 버전: 0.8.0 (fs 1.4).

사용자에게 보이는 변경은 버전을 올리고 여기에 적어요(MOD-013, VER-004). `requires`를 올리면 "필요 앱 버전"도 적어요.

## 0.2.3

- 파일 선택을 취소하거나 지원하지 않는 파일·이미 등록한 파일을 추가해도 완료 결과와 실패 항목 재시도를 유지해요.
- 한 번에 같은 파일이 여러 번 전달되어도 문서 개수를 한 번만 세어요. 목록을 비운 뒤에는 다시 추가할 수 있어요.

## 0.2.2

- 문서를 추가한 뒤에는 작은 문서 추가 행으로 이어서 선택해요. 최초 실행 전의 빈 결과 안내를 줄였어요.
- 변환 중에만 중지를, 실패·중지한 문서가 있을 때만 다시 변환을 보여 줘요. 원본 보존·성공 결과 유지·실패 항목 재시도 동작은 유지해요.
- 긴 이름의 미리보기와 결과 버튼이 작은 창에서 줄바꿈되도록 정리했어요.

## 0.2.1

- 한글 2024에서 HWP→HWPX 저장·재열기와 원본 보존을 실제 합성 문서로 확인했어요. 한글·영문 세 문단의 순서, 글자 크기와 굵은 서식도 검사했어요.
- 한글의 성공값 `1` 해석과 빈 선택 인자로 인한 저장 오류를 수정했어요.
- 이미 열린 한글을 닫아야 하는 상황을 다른 문서 변환 대기와 구분해 안내해요. 연속 변환 전에 이전 작업의 종료를 확인해요.
- 검증 범위와 남은 제한은 [실제 변환 검수](../../docs/reviews/hancom-conversion-2026-10-11.md)에 있어요. 호스트 수정이 포함된 TeacherDeck 0.5.1과 함께 사용해 주세요.

## 0.2.0

- 한글 공식 경로 확인 ABI의 독립 Rust DLL로 작업용 입력 사본과 신규 출력 파일만 허용해요. 한글 시작 전에 고유 등록을 준비하고 새 소유 프로세스 확인 뒤에만 접근을 연결하며, 기존 설정·원본·사용 중인 Office는 유지해요.
- 안전한 한글 접근 연결 실패를 설치 여부와 구분해 직접 변환을 안내해요. 한글 창 자동 클릭이나 모든 경로 허용은 하지 않아요.
- 현재 PC의 합성 검증은 `RegisterModule(FALSE)`로 저장 전에 종료됐어요. 120초 승인 대기는 조기에 실패하도록 바뀌었지만, HWP→HWPX 변환·본문·서식의 실제 성공 검수는 남아 있어요.

## 0.1.3

- 한글 변환 중 파일 접근 승인창이 나타나면 ‘접근 허용’을 직접 선택하도록 안내해요. 열기·저장·다시 열기에서 각각 승인이 필요할 수 있어요.
- 한글 응답 제한 뒤에는 중지된 작업과 다음 시도의 승인 확인을 구분하고, 실패한 문서가 있으면 성공 완료처럼 안내하지 않아요.
- 실제 합성 저장의 승인 대기창을 확인했어요. 자동 승인·보안 설정 변경은 하지 않으며, 직접 승인 후 HWPX 변환 검수는 아직 남아 있어요.

## 0.1.2

- Excel XML 사전 검사에서 실제 workbook 관계와 namespace를 확인해요. 정상 시트 이름의 AUTO_OPEN을 매크로 이름으로 잘못 판단하던 경우를 구분해요.
- 응답 시간이 지나 중지한 작업은 이미 닫힌 승인 창을 찾도록 안내하지 않아요. 다시 시도하는 동안 한글·Office의 문서 접근 승인을 확인하도록 안내해요.
- 한글 합성 검증의 첫 HWP 저장 응답 대기는 아직 해결되지 않았으며, HWPX 변환 성공은 미검증이에요.

## 0.1.1

- 사용 중인 PowerPoint를 닫아야 하는 경우와 다른 변환을 기다려야 하는 경우를 구분해 안내해요.
- Excel 파일을 열기 전 CFB/BIFF 구조 검사를 추가했어요. OOXML의 관계·이름 구조 검사 보강은 후속 승인 대기이며, 전체 XLM 차단을 보증하지 않아요.
- 소유한 한글 편집창을 표시해 사용자가 파일 접근 승인 창을 확인할 수 있게 해요.

## 0.1.0

- 설치된 한글·Excel·PowerPoint·Word로 실제 형식 변환과 재열기 검증을 제공해요.
- 원본을 유지하고 새 출력 폴더에 일괄 저장하며 실패 항목 재시도·중지·매크로 보존을 지원해요.
