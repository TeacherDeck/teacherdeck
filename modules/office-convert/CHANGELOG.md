# 변경 기록

사용자에게 보이는 변경은 버전을 올리고 여기에 적어요(MOD-013, VER-004). `requires`를 올리면 "필요 앱 버전"도 적어요.

## 0.1.2

- Excel XML 사전 검사에서 실제 workbook 관계와 namespace를 확인해요. 정상 시트 이름의 AUTO_OPEN을 매크로 이름으로 잘못 판단하던 경우를 구분해요.
- 응답 시간이 지나 중지한 작업은 이미 닫힌 승인 창을 찾도록 안내하지 않아요. 다시 시도하는 동안 한글·Office의 문서 접근 승인을 확인하도록 안내해요.
- 한글 합성 검증의 첫 HWP 저장 응답 대기는 아직 해결되지 않았으며, HWPX 변환 성공은 미검증이에요.

## 0.1.1

- 사용 중인 PowerPoint를 닫아야 하는 경우와 다른 변환을 기다려야 하는 경우를 구분해 안내해요.
- Excel 파일을 열기 전 CFB/BIFF 구조 검사를 추가했어요. OOXML의 관계·이름 구조 검사 보강은 후속 승인 대기이며, 전체 XLM 차단을 보증하지 않아요.
- 소유한 한글 편집창을 표시해 사용자가 파일 접근 승인 창을 확인할 수 있게 해요.

## 0.1.0

- 설치된 한글·Excel·PowerPoint·Word로 실제 형식 변환과 재열기 검증을 제공해요.
- 원본을 유지하고 새 출력 폴더에 일괄 저장하며 실패 항목 재시도·중지·매크로 보존을 지원해요.
