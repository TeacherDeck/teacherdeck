# 제안: 학교 자료 복구 파일과 시간표 이미지 저장

상태: 승인. 2026-10-11 사용자가 승인 대기 제안 3건을 승인하고 계속 구현하도록 요청했다. 기존 A의 학교 자료 관리·XLSX 교환과 분리한 신뢰 셸 출력 명령 두 개를 구현한다. 네이티브 실기·최종 통합 검증 결과는 별도로 기록한다.

## 배경과 정지 조건

학교 자료 JSON을 읽는 복구 기능은 있지만 정상 상태에서 같은 파일을 만들 수 없다. 시간표 격자에서 종이에 붙이거나 동료에게 전달할 PNG를 만드는 경로도 없다. 모듈의 fs 권한으로 신뢰 셸을 가장하는 방식은 쓰지 않는다. Tauri main ACL에 명령 두 개가 추가되므로 GEN-005 승인 대상이다. 새 런타임 의존성은 없다.

## 제안

1. `school_data_export_backup() -> bool`: main 셸만 호출한다. 호스트가 현재 검증된 SchoolDataDocument를 직접 읽어 UTF-8 JSON으로 직렬화한다(최대 32MiB). 사용자가 고른 폴더에 `티처덱_명부시간표_복구.json`을 새 이름으로만 저장한다. 기존 `school_data_read_backup`/`school_data_recover`가 그대로 읽을 수 있다. 명부·학기·학생 식별자·수업 연결·일과 시각·주간표·날짜 변경을 보존한다. **사진 파일은 포함하지 않는다.** UI와 파일 선택 전 안내에 이를 명시한다. 이 출력은 같은 PC의 명부·시간표 복구용이며 사진을 포함한 이동용 전체 백업이라고 표시하지 않는다. TimeAlert `.teacherbackup` 호환 B의 승인을 대신하지 않는다.
2. `school_data_export_timetable_image({pngBase64: string}) -> bool`: main 셸이 사용자가 보고 있는 시간표를 PNG로 렌더링해 전달한다. 호스트는 입력 길이(인코딩 전 최대 16MiB), PNG 형식, 한 변 최대 4096px·최대 16메가픽셀을 기존 승인 image 라이브러리로 검사한다. 사용자가 고른 폴더에 `티처덱_시간표.png`를 새 이름으로만 저장한다. 임의 확장자·경로·실행 명령은 받지 않는다.

출력은 기존 OutputBatch의 임시 쓰기·append-new 게시를 재사용한다. 취소는 false, 실패는 고정 오류 코드/안내를 반환하고 경로·파일명·학생 자료를 로그에 남기지 않는다. 모듈 iframe, 캡 브리지, overlay는 이 명령을 호출할 수 없다. 학교 자료 자체 저장과 사진은 변경하지 않는다.

## 파일과 버전

- ADR-0020 및 `docs/spec/school-data.md`에 신뢰 셸 출력 범위를 기록한다.
- `caps/school_data.rs`, 학교 자료 출력 순수 로직/테스트, `build.rs`, main ACL, `lib.rs`, 셸 `host.ts`와 학교 자료 화면을 변경한다.
- 호스트 인자 타입은 Rust에서 생성한다. SDK의 모듈 메서드와 school-data 1.0 계약은 유지한다. 앱 패치 버전을 올리고 CHANGELOG에 기록한다.

## 검토한 대안과 검증

- XLSX만 쓰면 일과 시각·날짜 예외·연결을 잃으므로 복구 파일을 대체하지 못한다.
- 브라우저 다운로드 링크나 모듈 권한 우회는 사용하지 않는다.
- 합성 명부·시간표의 JSON 저장→기존 복구 파서 왕복, 취소·원본 보존·이름 충돌·잘못된 PNG·큰 입력 거부, 모듈 origin/overlay 거부, 작은 창·다크 모드·한국어 PNG 실제 렌더를 확인한다. 마지막에 `pnpm verify`를 실행한다.

승인 범위: 위 두 main 전용 출력 명령과 최소 Tauri ACL 추가. B 전체 TimeAlert 백업 및 C 확장 표시창은 포함하지 않는다.
