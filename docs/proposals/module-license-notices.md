# 제안: 도구별 오픈소스 라이선스 고지 정리

- 상태: 승인됨 (2026-10-12 사용자 명시 승인)
- 정지 조건: GEN-005 "라이선스·저작자 표기 파일 변경". About 화면의 고지 구성과 생성물 형식을 바꾼다. GEN-007에 따라 기존 고지를 하나도 빼지 않는다.
- 결정 기록: [ADR-0030](../adr/0030-module-license-notices.md)

## 배경

About 화면의 서드파티 고지는 출처별로 흩어져 있었다.

- "오픈소스 라이선스" 표 하나에 셸 npm 의존성과 호스트 Rust 크레이트 427개를 이름순으로 늘어놓았다. 어떤 기능 때문에 들어간 구성 요소인지 알 수 없었다.
- "쿨 예약실 실행 환경 라이선스"만 따로 있었고, 내부 원문의 제목이 `Lib/site-packages/...` 같은 파일 경로였다.
- 도구 번들에 들어가는 구성 요소는 About에 보이지 않았다. 각 도구의 React·Fluent, PDF 도구의 PDF.js·pdf-lib·Liberation 글꼴, 개인정보 마스킹의 tesseract.js·tessdata, 영상 다운로드의 관리 Python·yt-dlp·Deno·FFmpeg가 여기에 해당한다. 원문 파일은 도구 번들이나 실행 캐시에 있었지만 사용자가 앱 안에서 볼 수 없었다.

## 제안

1. `pnpm gen`이 `apps/desktop/src/generated/module-notices.json`을 생성한다. 동봉 도구(`modules/*`, `_template` 제외)마다 이름·버전과 구성 요소 목록(이름·버전·라이선스·종류)을 담는다. 같은 원문은 한 번만 저장하고 구성 요소가 키로 참조한다.
2. 수집 원천은 다음과 같다.
   - 라이브러리: 도구 `package.json`의 `dependencies`를 따라가는 실행 의존성 닫힘. 워크스페이스 패키지(`@deck/*`)는 목록에서 빼되 그 의존성은 따라간다. 셸 표와 같이 원문 없이 이름·버전·라이선스만 보여 준다.
   - PDF 자산: 기존 `pdf-resources` 수집 결과(ADR-0018)의 원문 고지와 Liberation 글꼴 예외 원문.
   - OCR 자산: tesseract.js·tesseract.js-core 원문과 tessdata-fast 4.1.0 원문(해시 고정).
   - 쿨 예약실: 기존 관리 Python 실행 환경과 CoolReserve 원문(ADR-0023). 해시 검증은 그대로 유지한다.
   - 영상 다운로드: 같은 관리 Python 실행 환경 원문, yt-dlp·yt-dlp-ejs wheel 안의 원문, Deno·FFmpeg 원문(`vendor/media`).
3. `apps/desktop/src/generated/messaging-notices.json`은 위 파일로 합치고 삭제한다.
4. About 화면의 "오픈소스 라이선스" 절은 묶음별로 보여 준다.
   - "앱 공통": 기존 `third-party.json` 표. 설명에 구성 요소 수와 주요 라이선스 개수를 요약한다.
   - 도구별 묶음: 같은 요약과 구성 요소 표. 원문이 있는 구성 요소는 "CPython 3.14.8 원문 고지"처럼 이름으로 펼쳐 보며, 원문 제목은 펼친 안쪽에만 작게 쓴다.
   - 원문 묶음은 About 화면을 열 때만 불러와 셸 시작 비용을 늘리지 않는다.
5. 생성기 시험으로 모든 동봉 도구가 포함되는지, 자산·실행 환경 구성 요소마다 원문이 있는지, 기존 쿨 예약실 원문이 모두 보존되는지 검사한다. `check-gen`이 생성물의 최신 여부를 검사한다.

## 검토한 대안

- 현재 구조 유지: 도구 번들의 구성 요소가 계속 화면에 보이지 않는다.
- 셸이 도구 origin에서 고지 파일을 실행 중에 읽기: CSP·커스텀 프로토콜 변경(정지 조건)이 필요하다. 이번 범위에서는 설치본에 동봉한 버전 기준으로 빌드 때 모은다. 원격 업데이트로 받은 도구 버전이 다르면 그 버전 기준임을 화면에 밝힌다.
- 모든 npm 의존성 원문까지 포함: 셸 번들이 크게 늘어난다. 기존 셸 표와 같은 수준(이름·버전·라이선스)을 유지하고, 별도 해시 고정 원문이 있는 자산·실행 환경만 전문을 보여 준다.

## 영향

- 버전: 앱 patch 변경(About 화면). 도구 코드·매니페스트·브리지·카탈로그 포맷 변경 없음.
- 보안: CSP·ACL·프로토콜 변경 없음. 생성기는 네트워크와 Python 없이 동작한다.
- 개인정보: 해당 없음.
- 하위호환: 생성물 경로가 바뀐다. 셸 외에 사용처 없음.
- 문서: [design-system.md §5](../spec/design-system.md#5-about크레딧-화면) 갱신.
