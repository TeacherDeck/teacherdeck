# 제안: PDF 렌더링 자산의 한정 라이선스 예외

- 정지 조건: GEN-004의 라이선스 allowlist와 GEN-005의 라이선스 관련 변경.
- 배경: PDF.js 6.4.299 패키지는 Apache-2.0이지만, 내부 표준 PDF 글꼴 대체 자산 `standard_fonts/LiberationSans-{Regular,Bold,Italic,BoldItalic}.ttf` 네 개는 패키지의 `LICENSE_LIBERATION`에 적힌 GPL v2 및 문서 임베딩 예외를 따른다. 패키지의 최상위 라이선스만 검사하면 이 차이를 놓친다.
- 제안: 해당 버전의 네 파일과 원래 고지에 한정한 예외를 기록하고, PDF 모듈의 로컬 자산으로 원형 그대로 동봉한다. 일반 UI 글꼴로 사용하지 않는다. 제3자 고지에 패키지 원천·개별 파일 SHA-256·원문 라이선스와 소스 위치를 기록하고 자산 목록 검사로 범위를 고정한다. 임의 GPL v2 패키지 전반을 허용하지 않는다.
- 검토한 대안: 글꼴을 빠뜨리거나 OS 글꼴로 대체하면 표준 PDF 글자의 모양·폭이 달라질 수 있다. 다른 글꼴로 교체하려면 PDF.js의 대체 글리프·폭 데이터와 일치하는지 별도 렌더링 검증이 필요하다. 임베디드 글꼴이 없는 문서를 모두 거부하면 일반 문서 처리 범위가 줄어든다.
- 영향: 호스트 권한·네트워크·원본 파일 변경 없음. PDF.js의 다른 동봉 자산은 각각 BSD/Apache/MIT/CC0 고지를 보존한다. 앱의 기존 저자·라이선스는 바꾸지 않는다. 각 모듈은 다른 모듈의 자산을 읽지 않는다.
- 필요한 승인: 위 PDF 전용 자산 네 개의 한정 예외와 제3자 고지·검사 반영. 승인 전 배포하지 않는다.
- 배포 전 작업: 모듈별 `pdfjs-dist`·`pdf-lib`와 각 PDF 자산의 원문 고지를 패키지에 포함한다. 현재 앱 고지 생성기는 셸·호스트만 수집하므로 앱 생성 표만으로 모듈 고지를 갈음하지 않는다. 렌더링에 사용하지 않는 `quickjs-eval.js`·`quickjs-eval.wasm`은 빌드 자산에서 제외했다.

참고 원천: [PDF.js 배포 저장소](https://github.com/mozilla/pdfjs-dist/tree/master/standard_fonts), 설치된 `pdfjs-dist@6.4.299/standard_fonts/LICENSE_LIBERATION`. 이번 제안은 파일의 라이선스 표기 확인이며 법률 검토를 대신하지 않는다.
