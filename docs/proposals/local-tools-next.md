## 로컬 OCR

PDF 모듈 안에 Apache-2.0 `tesseract.js 6.0.1`, `tesseract.js-core 6.0.0`, `tessdata_fast 4.1.0`의 한글·영문 모델을 고정한다. 공식 원천 파일을 해시로 검증해 동봉하고 모든 처리를 PC에서 수행한다. 네트워크 요청·웹 저장소·원격 모델·새 호스트 권한은 추가하지 않는다. Tesseract의 후원 안내 postinstall은 제품 실행에 필요하지 않아 실행하지 않는다.

사진으로 된 쪽의 글자와 위치를 읽어 기존 개인정보 탐지에 연결한다. 인식 실패·빈 결과는 개인정보가 없다는 뜻으로 표시하지 않는다. 처리 취소·시간·픽셀·후보 수 상한을 유지하고 수동 영역을 보존한다. 실제 출력에서 선택 정보가 제거되는지 별도로 검사한다.

## 메모와 D-Day

기존 storage·fs 캡만 쓰는 `quick-note`, `dday` 모듈이다. LivelySam의 업무 흐름을 참고하며 독자 구현한다. 개별 JSON 저장/불러오기, 형식 검증과 복원 전 확인을 제공한다. 전체 설정의 통합 자료 관리 설계는 아래 별도 문서를 따른다.

## 영상 다운로드

사용자가 넣은 공개 YouTube 단일 영상 URL만 처리하는 호스트 다운로드 기능을 준비한다. 모듈에는 일반 HTTP·프로세스 실행·파일 경로 권한을 제공하지 않는다. 로그인 쿠키나 사용자 파일을 보내지 않으며 새 결과 폴더에만 저장한다. 분리된 MP4 영상과 M4A 음성은 PC 안에서 고정 FFmpeg로 재인코딩 없이 합친다. Deno와 FFmpeg는 첫 사용에 공식 고정 파일만 내려받아 private cache에서 사용하며, 전역 설치·임의 실행 권한을 제공하지 않는다. 엔진·실행 환경은 공식 버전·해시·라이선스를 고정하고, 취소·출력 크기·실행 시간·인자 검증을 적용한다. 네트워크 예외는 사용자가 지정한 영상 조회/다운로드와 고정 실행 환경의 첫 준비에 한정하며 기존 로컬 변환·분석 약속은 유지한다. 확정된 계약·배포 자산·규격 변경은 별도 ADR과 구현 기록에 남긴다.

## 전체 자료 관리

이번 사용자 요청은 전체 설정에서 메모·D-Day·학생/교사 명부를 포함한 로컬 자료의 통합 백업·불러오기 **설계**다. [설계 문서](../proposals/local-data-management.md)에 포함 범위·복구 미리보기·호환성·권한 재설정·원자적 적용을 명시한다. 실제 통합 복구 기능이 없는 상태에서 버튼만 제공하거나 완료라고 표시하지 않는다.
