# 개발 현황

기준일: 2026-10-11. 작업 브랜치는 `codex/parallel-tools-foundation`이에요. GPT-6.1 Sol 에이전트3개와 주 작업자가 병렬 구현·교차 검토·통합 검수를 진행했어요.

## 0.5.0 로컬 도구·OCR·배정 확장 — 전체 검증·설치본 구성 대조 통과

빠른 메모·D-day·영상 다운로드를 더해 기본 모듈은 20개예요. 메모와 D-day는 PC 저장과 개별 JSON 백업·복구를 제공하며, 여러 도구·학생·교사 자료를 설정에서 함께 관리하는 [통합 백업 설계](proposals/local-data-management.md)를 작성했어요. 전체 자료 관리 화면 구현은 후속 단계예요.

PDF 개인정보 지우기는 스캔 문서의 한국어·영어 로컬 OCR을 추가했어요. 지도일 배정은 기존 기본 달력에 선택형 교시·시험실·업무별 편성을 더했어요. 회의록의 화자 입력 흐름과 퀵캡처 고정 영역·자동 저장을 유지하며 주기적 입력 화면 갱신과 단축키 선택을 보완했어요. 전체 기능을 원작과 동일하게 복제했다고 주장하지 않아요.

소스는 [PR #13](https://github.com/TeacherDeck/teacherdeck/pull/13)으로 관리해요. 0.5.0 로컬 `pnpm verify` 16단계와 JavaScript 1,330개·Rust 271개 테스트가 통과했어요. 실제 공개 시험 영상 다운로드·MP4 결합·새 파일 저장도 확인했어요. [후속 요청 검수](reviews/request-followup-2026-10-11.md)에 근거와 한계를 별도로 기록했어요. CoolReserve 원작은 공유 모듈 PR을 병합하고 [v1.5.0](https://github.com/rochelobeJYJ/CoolReserve/releases/tag/v1.5.0)을 공개했어요.

TimeAlert 나머지 업무 도구는 [이슈 #12](https://github.com/TeacherDeck/teacherdeck/issues/12)와 [후속 목록](TIMEALERT_BACKLOG.md)에 사용자 작업 예정으로 명시했어요. 한글 자동 변환은 재시도했지만 이 PC의 보안 모듈 등록 실패가 남아 있어 실제 성공으로 세지 않아요.

Windows 설치본은 `target/review-040/release/bundle/nsis/TeacherDeck_0.5.0_x64-setup.exe`(37.46MiB)예요. 최종 모듈 20개와 네이티브 601개를 포함한 NSIS 자산 623개의 목록·해시를 대조했어요. 실제 설치·제거와 Windows 화면 실기는 이번 검증에 포함하지 않았어요.

## 0.4.0 자료 호환·학생 화면 — 전체 검증 통과

TimeAlert 전체 암호화 백업·사진 호환 B와 별도 학생 화면 C는 이후 사용자 승인으로 구현했어요. 최종 `pnpm verify` 16단계와 1,513개 테스트(JavaScript 1,258개·Rust 255개)가 통과했어요. 아래 0.3.x의 승인 대기 문구는 당시 기록이며 현재 승인 상태를 뜻하지 않아요. 공동작업자의 PR #11까지 `6d08e85`를 반영했어요.

이번 변경에는 지도일 원작 JSON 왕복·다중 월 저장, 이미지 자동 압축과 간단한 편집, 파일명 문서 정보 판별, PDF 개인정보 후보 탐지 보완도 포함해요. 학생 화면에는 공개 결과만 전달하며 모니터 구성 변경 시 결과를 가려요. TimeAlert는 원작 DB7·사진·미편집 비공개 자료 보존과 명시적 학생 연결을 기준으로 검증했으며 Java↔Rust 암호화 왕복도 확인했어요.

사용자 요청에 따라 컴퓨터 유즈를 쓰지 않고 코드·합성 입출력·원작 형식 대조·실제 Worker 픽셀 검사로 확인해요. 한글 보안 모듈은 독립 경로 검사를 통과했지만 이 PC에서 `RegisterModule`이 실패해 실제 HWP 변환은 미해결이에요. 전체 검증·빌드 결과는 [0.4.0 검수 기록](reviews/portability-presentation-qa-2026-10-11.md)에 갱신해요.

**0.4.0 Windows 설치본 빌드와 동봉 파일 대조도 통과했어요.** `target/review-040/release/bundle/nsis/TeacherDeck_0.4.0_x64-setup.exe`는 25.75MiB예요. 모듈 17개와 네이티브 601개를 포함한 NSIS 자산 620개의 목록·해시를 확인했어요. 현재 실행 중인 앱을 종료하지 않고 별도 출력 폴더에서 만들었으며, 새 설치본의 설치·제거·실기 검수는 남아 있어요.

## 0.3.1 적대적 리뷰 보완

[적대적 감사](reviews/adversarial-review-2026-10-11.md)의 A01~A10을 수정하고, 반복 작업에서 드러난 파일·명부·대화상자 문제도 보완했어요. PDF 마스킹 좌표, 공통 명부 조회 중 기록 보존, 지도일 실제 수행 횟수, 회의록 화자 정정·복구, 사진 대응, 파일명 작업의 부분 실패 복구가 포함돼요. 공통 시간표 격자·학기별 초안·XLSX 가져오기 되돌리기와 역할 일괄 완료도 추가했어요.

최종 `pnpm verify` **16단계**, JavaScript **1,150개**·Rust **208개** 테스트가 통과했어요. 0.3.1 NSIS 설치본을 만들고 동봉 모듈 17개와 네이티브 599개 파일을 대조했어요. Excel 합성 변환·재열기, 브라우저에서 PDF 출력 픽셀과 시간표·역할의 반복 조작을 확인했어요. 한글은 합성 문서 저장 단계에서 120초 시간 초과가 남아 있어 실제 변환 성공으로 세지 않아요. 세부 수정·반례·증거와 설치본 검증은 [0.3.1 보완 기록](reviews/adversarial-remediation-2026-10-11.md)에 있어요.

0.3.1을 검증할 당시 학교 자료 JSON·시간표 PNG 출력, Excel XML 구조 파서 의존성, Keyborg 버전 정렬은 별도 승인 대기였어요. 이후 세 범위를 승인받아 위 0.3.2 후속 작업으로 구현했어요. 실제 Windows 캡처·IME·설치·제거와 네트워크 전환·쿨메신저 등록은 아래 실기 범위로 남아 있어요.

## 이전 후속 도구 개발 — 0.3.0까지

발표자 뽑기·역할/당번·모둠·자리 배치·PDF 압축·PDF 개인정보 지우기 6개 모듈(각0.1.0)을 추가하고, 명렬표 사진 꺼내기는 PDF 입력을 지원하는0.2.0으로 보완했어요. 원본 대응과 실제 화면·출력 근거, 한도와 실패 복구는 [후속 도구 검수 보고서](reviews/next-tools-qa-2026-10-11.md)에 있어요.

이 후속 도구 단계의 커밋 `9670ded`에서 `pnpm verify` 15단계, JavaScript773개·Rust126개로 총899개 테스트가 통과했어요. 아래에서 진행 중인 0.3.0 변경의 최종 검증 결과와는 구분해요. 검사 대상과 기본 시간 제한은 유지하고 DOM 테스트의 동시 실행 수만4개로 제한했어요.

2026-10-11에 파일명 통합·보호된 원본 변경/되돌리기, Office·네트워크·CoolReserve의 제한된 새 권한, 공통 자료 공유 A, PDF 대체 글꼴 네 파일 예외, Windows API 경계 네 파일 예외를 승인받았어요. 0.3.0에는 파일명 정리·문서 형식 변환·네트워크 루틴·쿨 예약실과 공통 학급 자료를 추가했어요. 기본 모듈은 총17개예요. 네 교실 도구에는 명시적으로 선택한 공통 명부 불러오기와 직접 입력을 함께 연결했어요. PDF 자산은 승인한 글꼴 해시와 원래 라이선스 고지를 함께 묶어요.

모둠·역할 도구의 백업 복원 확인창과 자리 배치의 대규모 명단 처리를 보완하고 세 도구를0.2.1로 올렸어요. 자리 배치는 조건을 검색할 때1,000개 좌석을 다시 그리지 않으며, 학생 조회도 ID 인덱스를 사용해요. 타이머는 공동작업자의 새 입력기를 유지하면서 한 번의 시작 클릭이 빠지는 문제를0.3.1에서 고쳤어요.

TimeAlert 전체 암호화 백업 B와 별도 확장 화면 C는 아직 승인 범위 밖이에요. CoolReserve의 Python 3.14.8·원본 의존성 네 개와 정확한 585개 파일·라이선스 고지는 추가 승인받았어요. 원작 실행 코어와 모듈 소스를 원작 저장소에서 함께 관리하고, 티처덱은 검토한 커밋의 파일·해시를 고정해 가져와요. 실제 PC 네트워크 전환·메시지 발송은 이번 개발 검증에서 실행하지 않아요. [이번 통합 검수 기록](reviews/native-foundations-qa-2026-10-11.md)에 검증 범위와 남은 한계를 구분해 두었어요.

공동작업자의 PR #8까지 병합한 0.3.0 최종 `pnpm verify` 15단계가 모두 통과했어요. JavaScript 1,091개와 Rust 191개, 총 1,282개 테스트예요. 실제 Excel·Word 변환과 PowerPoint의 새 실행부터 변환·재열기·원본 보존까지 확인했어요. PowerPoint는 두 번 연속 통과했고, 한글은 합성 문서 SaveAs 단계의 120초 시간 초과가 남아 있어요.

0.3.0 Windows 설치본 빌드도 통과했어요. `target/release/bundle/nsis/TeacherDeck_0.3.0_x64-setup.exe`는 24.50MiB예요. 모듈 17개와 관리 실행 환경의 파일·해시가 일치하고, 빌드한 앱에서 17개 모듈 모두 준비 상태인 것과 메인 창 생성·정상 응답을 확인했어요. 설치·제거와 개별 네이티브 조작 검증은 별도예요.

이전 변경의 [PR #6](https://github.com/TeacherDeck/teacherdeck/pull/6)은 main에 병합됐어요. CoolReserve 원작 코어와 모듈은 [원작 PR #1](https://github.com/rochelobeJYJ/CoolReserve/pull/1)에 올렸고, 티처덱에서 해당 커밋을 고정해 재사용해요. 이번 후속 도구 소스와 아래0.2.2 설치본은 구분해야 해요.

## 0.2.2 검증 근거

최종 `pnpm verify` 15단계가 모두 통과했어요. JavaScript 388개(51개 파일), Rust core 59개·host 67개로 총514개 테스트가 통과했어요. 로그는 `target/ux-remediation/verify.log`에 있어요. 생성물·린트·타입·라이선스·보안 설정 검사도 포함해요. 별도 gitleaks는 설치되어 있지 않아요.

- 실제 셸800×560 안의600×468 모듈 화면과 글자·줄 높이150%를 확인했어요. 회의록은 기록 영역과 입력을 유지하며 큰 글자에서는 세로 스크롤을 허용해요. 지도일 편집 대화상자는 닫은 뒤 선택 날짜로 초점이 돌아와요.
- 타이머180분 발표 화면을1280×720 및600×468에서 확인했고 숫자·버튼이 겹치지 않았어요. 리셋에 초점을 둔 Space도 뜻하지 않게 시작하지 않았어요.
- 실제 CaptureOverlay를 합성 문서 위 투명 iframe에 띄워 안의 글·표가 가려지지 않는지 확인했어요. 화면 상단의 아래 툴바와5×5px/200%배율 모델에서도 이동·캡처 등6개 버튼을 사용할 수 있었어요.
- 이미지 자르기는 실제 Worker로800×400→회전400×800을 같은 결과 폴더에 두 번 저장했어요. 폴더 선택1회·생성1회, 새 이름·모서리 픽셀·투명도를 확인했어요. 압축은 실제 Worker로 정상2개·손상1개와 실패만 재시도하는 흐름을 확인했어요. 사진 추출은 출력3개의 원본 바이트가 일치했어요.

브라우저 검수에서 OS 파일 선택·저장과 네이티브 창 명령은 모의했어요. 실제 Windows 화면을 캡처해 디스크에 저장했다고 주장하지 않아요.

Windows 릴리스 빌드도 성공했어요. `target/release/teacherdeck.exe`는16,074,240바이트, `target/release/bundle/nsis/TeacherDeck_0.2.2_x64-setup.exe`는6,978,350바이트(6.66MiB)예요. 로그는 `target/ux-remediation/build.log`에 있어요. 기본 모듈7개의 버전·패키지 크기·SHA-256을 카탈로그와 대조했어요. 수정본을 실행한 뒤 시작 버전0.2.2와7개 모듈Ready, TeacherDeck 메인 창 생성·프로세스 응답을 확인했어요. Vite의 큰 청크 안내와 기존 ts-rs serde 경고는 남아 있지만 빌드는 정상 완료됐어요.

## 공동작업자와 승인 상태

`main`의 `b43ce4e`를 `3c9bc5a`에서 통합한 뒤, 업로드 직전 도착한 `ed35a1c`도 `24116df`에서 병합했어요. [PR #7](https://github.com/TeacherDeck/teacherdeck/pull/7)의 타이머 0.3.0·개발 포트 8265·120% 배율·이동 기록·보호 경로 훅 제거와 [PR #8](https://github.com/TeacherDeck/teacherdeck/pull/8)의 가는 테마 스크롤바·투명 배경 수정까지 반영됐어요. 갤러리를 닫은 뒤 다른 테마의 스크롤바 색이 남는 회귀도 찾아 보완했어요. 공동작업자가 요청한 개발 origin과 훅 제거를 검토했으며, 문서의 사람 승인 조건과 CODEOWNERS는 유지돼요. [PR #5](https://github.com/TeacherDeck/teacherdeck/pull/5)의 제목 표시줄 권한 요청은 앞선 변경에서 적용했어요.

[클립보드 출력](proposals/clipboard-output.md), [퀵캡처](proposals/quick-capture.md), [한정 라이선스 예외·로컬 시각](proposals/clipboard-license-followup.md)은 이미 승인받은 범위예요. 새 캡처 파일만 저장하고 기존 결과를 덮어쓰거나 삭제하지 않아요. 모듈은 경로 대신 핸들만 받아요. 위 캡처·클립보드 작업에서는 사용자 파일과 개인정보를 외부로 보내지 않아요.

## 남는 작업

사용자 요청으로 컴퓨터 유즈를 사용하지 않아요. 실제 Windows 투명 창, 타 앱 위 이동·크기 변경·더블클릭·전역키·트레이·폴더 선택부터 저장, 혼합 DPI 모니터 이동, 절전 복귀, 한국어 IME 고속 입력, 한글/Word 붙여넣기, NSIS 설치·제거는 아직 실기 증거가 없어요. 빌드·프로세스 시작을 이 항목의 통과로 세지 않아요.

TimeAlert 전체 암호화 백업과 별도 확장 화면은 승인 후 0.4.0에서 구현·자동 검증했으며 실제 Android 복원·새 PC 이동·모니터 실기는 남아 있어요. 공통 명부·시간표 XLSX와 전체 백업은 서로 다른 기능이에요. 쿨 예약실의 실제 쿨메신저 등록과 네트워크 루틴의 실제 IP/DNS 전환은 개발 검증에서 수행하지 않았어요. PDF OCR과 영상 다운로드는 0.5.0에서 추가하며 아래 과거 기록의 미구현 표시는 현재 상태를 대신하지 않아요. TimeAlert 나머지 단편 도구는 사용자 후속 작업으로 보류했어요. 통합 자료 백업 화면은 설계 다음 단계예요. 문서 변환은 공급 프로그램별 실제 확인 결과를 통합 검수 기록에서 구분해요.
