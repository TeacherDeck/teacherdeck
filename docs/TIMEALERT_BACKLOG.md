# TimeAlert 후속 작업 — 사용자 작업 예정

2026-10-11 사용자가 나머지 TimeAlert 작업의 우선순위를 낮추고 추후 직접 작업할 예정이라고 지정했다. 이 목록은 누락이나 취소가 아니라 명시적으로 보류한 후속 작업이다. 현재 개발에서 새 TimeAlert 기능 구현을 시작하지 않는다.

추적 이슈: [#12 · 사용자 작업 예정](https://github.com/TeacherDeck/teacherdeck/issues/12), 담당 `rochelobeJYJ`.

## 현재 기반

- 공통 명부·수업·주간 시간표, 사진 연결, 임시 명단, 네 가지 교실 도구 연결.
- DB7 `.teacherbackup` 암호화 파일 입출력, 원작 사진과 미편집 기록 보존.
- 자리·발표·모둠·역할 결과의 별도 학생 화면.

## 이후 구현할 범위

- [ ] 오늘 일정과 현재·다음 수업을 보여 주는 작은 도구.
- [ ] 시험·행사·창체·비정규 수업·날짜 변경을 합성하는 원작 날짜별 일정 엔진.
- [ ] 담임·수업 출결 조회와 편집.
- [ ] 수업 기록·학생 기록을 원작 흐름에 맞춰 조회·편집하는 도구.
- [ ] 필요한 수업 시수 등 원작 부가 기능을 선별하고 채택·제외 이유 기록.
- [ ] DB7 왕복에서 지원하지 않는 날짜별 주간표 선택·원작 연결 삭제의 호환 정책 검토.
- [ ] 비공개 원형 기록 보존 세션 종료 후 다시 원본을 여는 현재 흐름의 개선 검토.
- [ ] 실제 Android 앱에서 가져오기·수정·내보내기·복원과 사진 재배치를 검증.

## 재개 원칙

원작 `time_alert`의 검증된 UX와 파일 형식을 기준으로 시작한다. 백업 안에 기록을 보존하는 것과 해당 기록을 편집하는 기능을 구분한다. 교실 도구에 비공개 기록을 자동 공개하지 않는다. 알림은 계속 MVP 우선순위 밖이며 동기화는 요청하지 않은 범위다.

이번에 별도로 진행하는 메모·D-Day와 전체 설정의 로컬 자료 백업 설계는 이 보류 범위에 포함하지 않는다. 현재 TimeAlert 호환 기능의 회귀 수정도 중단하지 않는다.
