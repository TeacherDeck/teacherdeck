# 회의록 원본 기능 대조

대상: 읽기 전용 `D:/codex_work/meeting_note/index.html`, TeacherDeck `meeting-note` 0.4.0.

| 원본 기능                                         | 모듈 결과                                                     |
| ------------------------------------------------- | ------------------------------------------------------------- |
| 참석자 시작, 화자 유지, Enter/IME, 줄바꿈, 단축키 | 기존 0.2 유지                                                 |
| 동명이인 분리, 명단 탈퇴 화자의 기록 보존         | 내부 ID, 12명 입력 및 기록 화자 최대 24명 보존                |
| 개별 기록 화자 즉시 변경, 화자 건수               | 기록별 선택 상자와 화자 버튼 건수                             |
| 안건 제목 수정, 삭제 확인 및 앞 안건 합류         | 일반 수정으로 제목 변경, 확인 삭제 후 기록 유지               |
| 위원회 동일명 갱신, 삭제, JSON 입출력             | 앱 명단 갱신, 확인 삭제, 원본 JSON 가져오기 및 전체 파일 저장 |
| 공개 마지막 발언 종료 시간, 비공개 제외           | 공개 본문 기록만 종료 시간 계산                               |
| 안건별 문서, 빈 안건, 결정 목록, 조치 표          | 텍스트/마크다운/HTML, 줄바꿈 및 HTML·표 구분자 이스케이프     |
| 입력 포커스 안전망, undo 메모리 제한              | 편집 필드 밖 문자 입력 시 입력창 포커스, 50개·6MB 한도        |
| 한글·워드 서식 클립보드 쓰기                      | 승인된 clipboard 1.0으로 공개용 표·제목·굵은 화자를 복사, 구형 호스트 파일 저장 유지 |
| 저장소와 파일 로컬 처리                           | storage + fs 1.1 SDK만 사용, 기존 파일 덮어쓰기 없음          |

서식 클립보드는 사용자가 `clipboard-output.md` 제안을 승인한 범위에서 구현한다. 원시 HTML이나 클립보드 읽기는 모듈에 노출하지 않는다.

추가 회귀: 타이핑과 화자 선택으로 기존 기록의 시각 포맷·목록 렌더링이 반복되지 않는지 40개 합성 기록으로 확인한다. 내보내기 창을 닫은 상태에서는 본문 생성도 생략한다. 현재 참석자 수를 따로 보관해 이전 화자가 다시 단축키 슬롯을 차지하지 않게 한다. 안건 등록은 발언 건수에 포함하지 않는다.

브라우저에서 참석자 등록, Alt+2, 여러 줄 입력과 Enter 저장, 화자 제외 후 기존 기록 보존 및 명단 재편집을 확인했다. SDK mock을 썼으며 실제 Windows IME 및 한글·Word 서식 붙여넣기 확인은 별도 수동 검증이 필요하다. 통합 검사 결과는 개발 현황 문서에 기록한다.
