# 지도일 배정 원본 대조

2026-10-10에 제공된 중식배정.gs의 setupTeacherList, assignLunchDuty, getBestCandidate, updateMonthlyCounts, recalculateCumulativeCounts, closeAndArchiveMonth, getAllDataForExport 및 시간표추출하기.gs를 읽고 대조했어요. 원본은 읽기 전용으로 확인했으며 실존 명단·학교 자료를 복사하지 않았어요.

| 원본 장점                                 | TeacherDeck 0.3.0            | 남은 차이                                                 |
| ----------------------------------------- | ---------------------------- | --------------------------------------------------------- |
| 월별 달력·제외일                          | 구현                         | 2026 공휴일 자동 제외 추가                                |
| 참여 여부·고사일 1명·메모                 | 구현                         | 범용 하루 1~3명 지원                                      |
| 선배정·최종 수동 교체                     | 고정·직접 배정으로 구현      | 명시한 충돌은 자동 해제하지 않음                          |
| 기초+과거+당월 균등 배정                  | 구현                         | 기초는 0.1단위·신규 참여자 평균 보정                      |
| 당월 실제 담당자 집계                     | 수행 기록으로 분리           | 배정과 실제 수행을 명시적으로 구분                        |
| 동일 연월 마감 중복 방지·지난 기록 재집계 | 구현                         | 월 키 기반이며 수정 열기 후 다시 마감 가능                |
| 원본 JSON months/counts export            | 키·MM/dd·월 데이터 표시 호환 | 원본처럼 2명 필드만 있으므로 세 번째는 CSV/자체 백업 사용 |
| 이식 모듈의 전체 백업·복원                | 추가 구현                    | 원본 JSON import는 미지원                                 |
| Excel 확인용 표                           | UTF-8 BOM CSV 구현           | XLSX 서식은 미지원                                        |
| 시간표 병합셀·연강 추출                   | 추출된 4열 TSV 입력 구현     | XLSX 병합셀 원본 자동 해석은 미지원                       |
| 4교시 O/X별 1차/2차 후보                  | 구현                         | TSV에서 자동 설정 또는 순번별 허용 요일 직접 설정         |
| 신규 교사 평균 기초 보정                  | 구현                         | 현재 참여자 누적 평균의 소수점 한 자리로 일반화           |
| 간격 우선·일자 순환 동점                  | 구현                         | 전역 누적·당월 제곱합 이후 날짜별 순환 및 횟수 보존 교환  |
| 온라인 웹 열람·수정·로그인                | 제외                         | 제품의 PC 내부 처리 약속과 맞지 않음                      |

원본 배정·조건·기록 운영의 핵심 장점을 범용 지도일 모델에 흡수했어요. 원본 순차 그리디와 결과를 완전히 같게 만드는 이식은 아니며 전체 누적 균등을 먼저 보장해요. 남은 원본 XLSX 병합셀 자동 해석은 공통 시간표 가져오기 방향에 맞추어 후속으로 검토해요. 온라인 웹 배포는 제품 범위에서 제외해요. 수행 기록은 선택 날짜/오늘까지를 명시적으로 기록하며 미래 자동 수행을 차단해요.
