## 0.3.1 달력 조작·가독성 복원

원본 중식배정.gs generateCalendar(310~352행)는 평일 한 행에 날짜·요일·제외일·고사일·선배정/최종 담당·메모를 둬 담당 교사를 바로 고르는 구조다. 기존 TeacherDeck은 담당 교사 교체가 메모·실제 수행자 아래에 있어 흐름이 느려졌다. 선택일 교체를 패널 맨 위로 올렸고 실제 수행자 수정/월 기록은 접을 수 있게 했다. 배정 알고리즘과 모든 조건·기록·내보내기는 유지한다.

원본 gs에 주말 글자색 정의는 없으며 일요일·공휴일 빨강/토요일 파랑은 사용자의 명시 요청과 한국 달력 관습을 따른다. Fluent light/dark 의미색을 사용한다. 날짜 글자색은 요일/공휴일, 중립 배경은 제외, 브랜드 outline과 선택 문자는 선택일, 경고색 ◆는 직접/고정, 성공색 ✓는 실제 수행을 각각 뜻한다. 서로 중첩해도 상태를 숨기지 않으며 직접 제외한 공휴일에도 공휴일명을 유지한다. 셀 전체를 빨강/파랑으로 채우지 않는다.

0.3.1 실제 브라우저 1280×720에서는 첫 화면에 2026년10월 달력 전체가 보이고, 3일/5일/9일 공휴일 빨강·토요일 파랑·제외 중립 배경을 확인했다. 합성 교사4명·하루2명 배정은 각10회이며, 6일 담당자 즉시 교체 시 ◆ 직접 배정, 실제 수행 기록 시 ✓ 수행 기록2명 표시를 확인했다. 어두운 테마에서도 휴일/주말 색과 선택·수행 표식을 구분한다.

## 0.4.0 원작 JSON과 손상 복구

원작 getAllDataForExport는 연도·개인 조건·실제 수행 구분을 담지 않는다. 가져오기는 사용자 확인 연도와 날짜/요일이 일치해야 하며 중복 월·날짜·이름을 거부한다. counts는 기초 누적으로 보존하고 과거 배정을 실제 수행으로 자동 집계하지 않는다. 최종 담당자 두 칸의 위치, 배정불가 표시, 원래 날짜 행을 보존한다. 기존 형식은 여러 연도·세 명 결과를 표현할 수 없으므로 내보내기 전에 안내한다. TeacherDeck 전체 JSON은 조건·실제 수행·마감까지 보존한다.

손상된 PC 저장값은 JSON 복원 확인에서 새 저장 공간에 모두 쓰고 활성 포인터를 바꾸는 방식으로 복구한다. 저장 실패 시 기존 값/잠금을 유지하며 새 시도에서 생성한 임시 키만 정리한다. 이후 일반 저장도 여러 달을 한 번에 확정한다. 원작이나 손상 값을 직접 지우지 않는다.

2027·2028 공휴일은 KASI 달력자료의 잠정 상태를 밝히고, 2029·2030 음력 기준은 KASI 2016 역서 242쪽 원문 표를 대조했다. 노동절·제헌절은 2026 개정 법령을 반영했다. 2030 선거일과 임시공휴일은 확정 자동 제외로 주장하지 않는다. 근거 링크와 정확한 한계는 모듈 README에 있다. 새 UI는 SDK mock host 회귀로 확인하며 실제 Windows 앱 조작은 별도 검증 범위다.
