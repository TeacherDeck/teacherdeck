# UX 감사 후 보완

기준: [적대적 감사](adversarial-ux-audit-2026-10-10.md)의 A01–A19. 사용자 요청에 따라 GPT-6.1 Sol 3개 작업자를 병렬 운영하고 주 작업자가 셸·공통 통합·실제 브라우저 검수를 담당했다. 과거 감사의 발견 사실은 그대로 두고 수정 근거를 이 문서에 기록한다.

통합 검수에서 A20도 발견했다. 세 이미지 모듈이 공통 ProgressBar의0–100 계약에0–1 값을 전달해, 3개 중1개 처리 상태가0.33%로 표시됐다. 세 모듈을 같은 계약에 맞춰 수정하고 실제 접근성 값에 대한 진행률 회귀 검사3건을 추가했다.

교차 검토에서는 이번 수정이 만든 경계 조건도 재검토했다. 압축 입력의 같은 배치 내 중복 드롭을 동기적으로 제거하고, 타이머 발표 모드에서 버튼에 초점이 있어도 Escape가 작동하도록 회귀 검사를 보강했다.

## 통합 화면 검수

- 작은 회의록은 기록과 입력을 유지한다. 글자·줄 높이150%에서는 기록 영역150px을 확보하고 전체 페이지 세로 스크롤을 허용한다. 상단 도구와 많은 화자를 한 화면에 모두 고정해 보인다는 의미는 아니다. Alt+2→입력→Enter 후 두 번째 화자와 입력 초점을 확인했다.
- 타이머180분 표시는1280px 폭에서777×288px,600px 폭에서347×129px이었다. 버튼과 숫자가 겹치지 않았다. 발표 모드의 OS 전체 화면 전환은 모의했다.
- 캡처 검수는 실제 CaptureOverlay를 합성 글·표 위 투명 iframe에 올렸다. 흰 배경으로 덮이지 않는 점과 위 공간이 없는 배치·작은 영역의 버튼 접근성을 확인했다. Windows 합성·실제 화면 저장 검증을 대신하지 않는다.
- 이미지 자르기는 실제 Worker로800×400 합성 이미지를 저장한 뒤 회전한400×800 결과를 같은 결과 폴더에 `_2` 이름으로 저장했다. 모서리 픽셀의 색·투명도도 확인했다. 압축은 합성 PNG·EXIF JPEG·손상 파일을 선택해 성공2개·실패1개를 확인하고 실패만 재시도해 성공 결과가 유지되는지 확인했다.
- OS 파일 선택·권한·디스크 쓰기는 모의했고 이미지 Worker와 UI는 실제 구현이다. 테스트에는 합성 자료만 사용했다.

## 검증 및 배포 상태

`pnpm verify` 15단계 모두 통과했다. JavaScript 51개 파일388개, Rust core59개·host67개로 총514개 테스트를 통과했다. 생성물 비교, ESLint, 타입 검사, cargo fmt/clippy/test/deny, 모듈·SPDX·버전·문서·보안 설정·라이선스·억제 검사까지 포함한다. 로그는 `target/ux-remediation/verify.log`다. 별도 gitleaks는 설치되지 않았다.

2026-10-11 Windows 릴리스 빌드도 성공했다. 실행 파일 `target/release/teacherdeck.exe`는16,074,240바이트, 설치본 `target/release/bundle/nsis/TeacherDeck_0.2.2_x64-setup.exe`는6,978,350바이트(6.66MiB)다. 로그는 `target/ux-remediation/build.log`다. Vite의 큰 청크 안내와 기존 ts-rs serde 경고가 있으며 종료 코드는0이었다.

기본 모듈7개의 버전·크기·SHA-256을 카탈로그와 대조했다. 새 실행본은0.2.2로 시작했고7개 모듈이Ready였다. 실행 후 TeacherDeck 메인 창 핸들과 프로세스 응답을 확인했다. 기존 실행본을 종료한 뒤 새 실행본을 열었다. 실행 확인과 네이티브 기능 검증을 구분한다. 임시 검수 코드와 로그는 `target/ux-remediation/`에 둔다.

## 남는 실기 확인

네이티브 앱 제어가 비활성화된 환경이므로 실제 Windows 투명 창, 타 앱 위 이동·크기 변경, 전역키, 트레이 종료, 파일 저장, 혼합 DPI 이동·절전 복귀, 한국어 IME 고속 입력과 NSIS 설치·제거는 자동 통과로 기록하지 않는다. 새 캡·의존성·ACL·CSP·모듈 브리지 계약 변경은 없다. 호스트가 전용 셸에 보내는 내부 배치 상태만 보완했다.
