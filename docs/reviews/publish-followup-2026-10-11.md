# 업로드 전 후속 개선 검수

2026-10-11. 앱 0.6.2. 사용자 요청에 따라 GPT-6.1 Sol 에이전트 3개가 현재 화면·원작 흐름을 나눠 다시 검토하고, 확인한 결함을 보완했다.

## 확인한 결함과 수정

| 범위 | 문제 | 수정과 검증 |
|---|---|---|
| 설정 업데이트 | 확인 Promise 실패 뒤 계속 확인 중으로 남음. 설치 재시도가 성공해도 이전 오류가 남음. 재시작 실패 처리가 없음 | 각 실패에서 다시 조작할 수 있게 복구하고, 새로운 실행의 오류 상태를 초기화. 원문 오류 대신 경로 없는 안내 사용 |
| 좁은 설정 | 작은 창에서 큰 글자·확대를 함께 쓰면 자료 관리·테마·업데이트 버튼이 밖으로 밀림 | 실제 가용 폭에서 조작을 다음 줄로 배치하고 테마 선택 폭을 제한 |
| 도구 정보 | 아이콘 파일 로드 실패 시 깨진 이미지가 남음 | 홈과 같은 카테고리 아이콘으로 대체하고 아이콘 URL이 바뀌면 다시 로드 |
| 홈 즐겨찾기 | 별에 키보드 초점을 둔 채 즐겨찾기를 해제하면 카드가 사라지면서 초점도 없어짐 | 같은 도구의 전체 목록 별로 초점 복원. 키보드는 해당 버튼을 화면에 보이고, 마우스는 스크롤 위치 유지 |
| 캡처 오버레이 | 버튼은 캡처 중 비활성이지만 더블클릭·키 입력은 명령을 보내 불필요한 실패 안내를 표시 | 모든 캡처 진입점을 같은 세션·진행 상태로 검사. 호스트 상태 이벤트 전에도 요청 중복 차단 |
| 퀵캡처 0.1.5 | 자동 설정 적용 실패 뒤 다음 변경이나 새 캡처 시작이 성공해도 오류가 남음 | 설정 오류만 별도로 관리해 적용·시작 성공 시 해제. 캡처·저장 오류는 유지 |
| 문서 변환 0.2.3 | 취소·중복·지원하지 않는 파일 입력도 기존 결과를 지움 | 실제 새 문서가 추가될 때만 결과 초기화. 한 번에 들어온 중복도 제거 |

파일명·메모·회의록·지도일은 이번 검토에서 추가로 확정한 결함이 없어 동작을 다시 설계하지 않았다. 저장 형식·권한·네이티브 캡·의존성을 바꾸지 않았다.

## 원격과 공개 검사

- `origin/main`의 `baf3dab`은 기존 PR #13 병합이며 이전 기준 `7f91680`과 소스가 같았다. 해당 main 이력을 작업 브랜치에 병합했다.
- [영상 다운로드 보류 #15](https://github.com/TeacherDeck/teacherdeck/issues/15)와 [TimeAlert 후속 #12](https://github.com/TeacherDeck/teacherdeck/issues/12)를 유지한다.
- 원작 CoolReserve 모듈0.1.1은 커밋 `80f1481`을 게시하고 [PR #2](https://github.com/rochelobeJYJ/CoolReserve/pull/2)를 열었다. TeacherDeck이 고정한 원천을 GitHub에서도 받을 수 있다. 공개 파일116개 검사를 통과했다.
- 개발용 Gitleaks8.30.1을 공식 배포 체크섬과 대조해 작업 폴더에서 사용했다. 다운로드 ZIP SHA-256은 `d29144deff3a68aa93ced33dddf84b7fdc26070add4aa0f4513094c8332afc4e`다. 앱 런타임이나 시스템 설치에 추가하지 않았다. 원작 새 커밋1개와 기존 미게시 TeacherDeck 커밋5개에서 비밀값 발견0건. 최종 변경도 커밋 훅과 게시 직전 검사에 포함한다.

## 검증 범위

- 셸 회귀 시험 20개, 실제 브라우저 동작 11개와 세 화면·두 크기·두 테마·두 확대 조건의 화면 측정 24개를 통과했다. 결과는 `output/playwright/shell-ux-results.json`과 `shell-ux-review.md`에 있다.
- 최초 설정 화면의 회색 버튼은 테마 색 전환 100ms 도중 촬영한 것이었다. 전환 완료 후 다시 측정해 활성 버튼의 대비가 다크 14.55:1·라이트 15.52:1임을 확인하고 스크린샷을 교체했다. 근거는 `shell-ux-button-colors.json`이며 제품 코드를 바꿀 문제는 아니었다.
- 퀵캡처·오버레이 지정 시험 36개를 통과했다. 실제 React와 합성 호스트에서 설정 오류 회복, 별도 캡처 오류 보존, 재시작 뒤 오류 해제, 호스트 상태 알림 전 중복 입력 차단과 완료 뒤 재캡처를 확인했다. `output/playwright/design-duty/README.md`에 증거를 연결했다.
- 파일 도구 지정 시험 49개를 통과했다. Office의 파일 선택 취소·중복·지원하지 않는 입력, 기존 결과 보존과 실패한 파일만 재시도하는 흐름을 포함한다.
- 다른 담당자가 마지막 캡처 요청 잠금·오류 초기화·홈 입력 방식별 초점 수정을 독립 검토했다.
- 첫 전체 검사는 15단계와 JavaScript 1,387개가 통과했지만 `cargo test`가 `reqwest`·`tracing_core`의 rlib 형식을 찾지 못해 실행 전에 실패했다. 해당 라이브러리 파일은 존재했다. 작업 폴더 안의 `teacherdeck`·`reqwest`·`tracing-core` 개발 캐시만 Cargo로 정리해 재생성했다. 첫 실패와 재생성 기록은 `target/release-062/verify.log`·`repair-dev-cache.log`에 보존한다.

최종 `pnpm verify` 16단계가 모두 통과했다. JavaScript 154파일 1,387개와 Rust 276개(core 104·host 169·한글 보안 3), 총 1,663개 테스트가 통과했다. 첫 실패 이후 소스·검사 대상·시간 제한·병렬 설정을 바꾸지 않았다. 로그는 `target/release-062/verify-final.log`다.

브라우저는 실제 React 화면과 합성 호스트를 사용하며, Windows 캡처 픽셀·혼합 DPI·실제 IME·설치/제거의 실기 증거를 대신하지 않는다.

## 설치본과 게시

`pnpm tauri build`를 기존 `target/review-040`에서 실행해 0.6.2 Windows x64 설치본을 만들었다. `target/release-062/build.log`·`check-062.ps1`·`bundle-062.json`에 결과와 대조 근거를 남겼다.

- 설치본: `target/review-040/release/bundle/nsis/TeacherDeck_0.6.2_x64-setup.exe`, 39,355,329바이트(37.53MiB).
- SHA-256: `f6e96022125ac208ffafc1ed49fa94401852ea7188585704d22dd3462a5eaa9c`.
- 기본 모듈 20개의 카탈로그 버전·크기·SHA-256, 패키지 매니페스트와 소스 아이콘 일치를 확인했다. 퀵캡처 0.1.5·문서 변환 0.2.3이 포함된다.
- QR Worker·필수 고지, 영상 다운로드 제외, NSIS 입력 자산 623개의 존재를 대조했다.
- 성공 후 0.6.1 설치본과 두 모듈의 이전 패키지, 총 3개·39,680,953바이트(약 37.84MiB)가 자동 정리됐다. 실패 시 최신 설치본을 삭제하지 않는 기존 규칙을 유지했다.

게시 대상은 `codex/parallel-tools-foundation` 브랜치이며 PR에서 검토한다. main 병합과 정식 릴리스 배포는 별도다. 기존 Vite 청크 크기 안내·ts-rs serde 경고는 남아 있지만 최종 검사와 빌드는 성공했다.
