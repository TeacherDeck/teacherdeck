# 사진명렬표 사진 추출 원본 기능 대조

원천은 읽기 전용 TimeAlert `NeisRosterReader.kt`(하단 RosterCellParser 포함), `NeisRosterImporter.kt`, 관련 Kotlin 테스트다. 도구 범위는 **명렬표의 사진을 꺼내는 독립 도구**이며 학적 저장소·다른 모듈 공유·TimeAlert 전체 백업은 포함하지 않는다.

| 원본의 장점·회귀 사례                         | TeacherDeck 구현                                                 |
| --------------------------------------------- | ---------------------------------------------------------------- |
| 사진이 아닌 학생 셀을 명단 기준으로 수집      | strict/contextual/loose 순서 포팅, 사진 없는 학생 보존           |
| 스타일 자기닫힘 빈 셀이 다음 학생을 먹던 회귀 | XML DOM의 개별 c 셀 파싱, 합성 14·24·33명으로 전원/원본사진 확인 |
| 한 파일의 여러 반, 학년·반·번호 중복 키       | 파일 안 여러 반과 시트, 번호만으로 중복 처리하지 않음            |
| 담임용 페이지 머리글과 번호·이름              | 가장 가까운 위쪽 머리글, 같은 행의 가장 가까운 열                |
| 담임·날짜·콜론 줄 유령 학생 방지              | 정형·맥락·느슨한 패스에 같은 필터 적용                           |
| 사진 col,row → 학생 같은 col,row+1            | 확정 1:1 좌표 매칭                                               |
| 정확 좌표 우선 후 읽기 순서/최근접 폴백       | 확정 매칭 유지, 폴백은 추측 표시·미확인 파일명                   |
| 학생보다 사진이 적거나 많은 파일              | 사진 없는 명단 유지, 미확인·비연결 media도 모두 별도 보존        |
| BIFF XLS를 조용히 빈 결과로 읽지 않기         | PK ZIP 검사와 읽기 실패 안내·파일별 재시도                       |
| 사진 원본 빠른 저장                           | fflate Worker ZIP 해제, 원본 bytes → fs writeBlob, 재인코딩 없음 |
| 원본을 건드리지 않는 가져오기                 | 핸들 read only, 저장은 매번 신규 output folder                   |
| 원본 외의 namespace·관계 경로·다중 시트       | namespace 중립 탐색, workbook/sheet/drawing rels 상대 경로 처리  |

추가 안전성: ZIP 실제 출력 제한, 디렉터리 탈출·중복 ZIP 경로·외부 관계·DTD 거부, Worker 취소·90초 타임아웃, 원본 바이트 유지와 별개로 과대 이미지 썸네일 제한. 알 수 없는 형식은 `.bin`으로 보존한다.

검증: 순수 추출·안전성·SDK mock·UI 테스트 21개 통과, 모듈 lint 통과. 브라우저에서 실제 ZIP Worker·PNG 렌더·파일명 수정·전체 저장 3장의 원본 bytes 동일함을 확인했다. 브라우저의 fs는 SDK mock 경계다. 실제 학교 파일이나 Windows 권한을 검증했다고 주장하지 않는다. 통합 pnpm verify·번들 검증은 lead agent가 수행한다.
