# 0.3.2 승인 후속 검수

기준일: 2026-10-11. 사용자가 학교 자료 출력 두 명령·최소 ACL, quick-xml 0.42.0 직접 사용, Keyborg 3.498.0 정렬을 명시 승인한 범위다. [0.3.1 보완 기록](adversarial-remediation-2026-10-11.md)의 결과와 이번 결과를 구분한다. 합성 자료만 사용했다.

## 구현과 교차검토

- 학교 복구 JSON은 저장된 자료를 기존 복구기가 읽는 형식으로 내보낸다. 사진 파일과 미저장 초안을 포함하지 않는다. 시간표 PNG는 현재 화면의 초안을 포함하지만 학교 자료를 저장하지 않는다. 두 명령은 신뢰 셸 main에서만 호출할 수 있고 모듈·오버레이의 호출은 거부한다. 기존 폴더 선택과 새 이름 출력을 재사용한다.
- 큰 자료가 compact JSON으로 저장은 되지만 들여쓴 백업은 32MiB를 넘어 실패하는 반례를 발견했다. 저장과 같은 compact 인코딩을 사용하고, 상한을 넘는 바이트를 추가하기 전에 거부하는 writer로 보완했다. 정상 대규모 자료의 복구 왕복과 경계값을 검사한다.
- Excel의 workbook 관계·namespace·속성·definedName을 XML 문맥으로 검사한다. 문자열에 `macrosheet`가 들어간 정상 그림 이름과 Default/Override MIME 선언 조합을 잘못 거부하는 두 반례도 수정했다. 검사 대상 메타데이터의 크기 한도와 기존 CFB/BIFF 검사는 유지한다.
- Fluent의 한 의존 경로만 기존 Keyborg 3.498.0으로 맞췄다. 서로 다른 두 소유자의 구독, 하나의 해제 후 남은 구독, 재생성 세 주기를 실제 라이브러리와 키 입력 이벤트로 검사한다.
- 한글 시간 초과 후 이미 종료한 작업 창을 확인하라는 안내를 재시도 시 승인창을 확인하는 문구로 고쳤다. [한글 후속 진단](hancom-save-timeout-followup-2026-10-11.md)에 관측과 추정을 구분했다. 실제 SaveAs 정체 원인은 아직 확정하지 않았다.

## 화면과 실제 Excel

실제 SchoolData 컴포넌트와 Canvas 출력기를 브라우저에서 사용했다. 파일 선택·파일 저장 명령만 모의했다. 복구 확인창 취소 → 재열기 → 저장, 마우스 수업 선택, 미저장 칸 편집 → PNG 생성 → JSON 확인을 진행했다. PNG에는 편집한 화요일 칸이 들어갔지만 복구 JSON은 revision 0과 기존 두 칸을 보존했다. PNG 출력이 자료 저장을 대신하지 않는다는 의미가 실제로 유지됐다.

1600×660 PNG를 밝고 어두운 테마에서 직접 확인했다. 한글 수업 이름이 잘리지 않고 토요일 파랑·일요일 빨강을 유지했다. 800×600 창에서 출력 버튼은 줄바꿈되며 문서의 가로 넘침은 없었다. 이 검수는 Windows DPI·확장 모니터 검증을 대신하지 않는다.

역할 화면에서는 합성 네 명·세 역할을 적용하고 완료 확인창을 취소한 뒤 다시 열어 세 명을 기록했다. 세 결과의 완료 표시와 중복 완료 비활성화를 확인했다. 학교·역할 검수의 브라우저 경고/오류 수집 결과는 빈 배열이었다.

현재 승인 코드로 `office_synthetic --provider excel`을 빌드·실행했다. 설치된 Excel에서 합성 원본 변환·출력 재열기·내용 검증·원본 보존이 성공했다. 한글은 이번에 재실행하지 않았다. 실제 매크로 생성·실행, 사용자 문서, 네트워크 전환, 쿨메신저 등록·발송은 검수에 사용하지 않았다.

근거 파일은 로컬 `target/adversarial-review/approved-*`에 둔다. PNG는 `approved-timetable-light.png`, `approved-timetable-dark.png`, 역할 화면은 `approved-role-complete.png`, Excel 결과는 `approved-excel-native.log`다. 이 로컬 자료는 설치본에 포함하지 않는다.

## 최종 통합 검증

최종 `pnpm verify` **16단계가 모두 통과했다.** JavaScript **1,158개(115파일)**, Rust **223개(core 97·host 126)**가 통과했다. 출력 게시·큰 JSON 복구·이미지 디코드·호출 권한 회귀를 포함한다. Clippy가 지적한 인덱싱은 고정 크기 배열의 구조분해로 고쳤고 검사 억제를 추가하지 않았다. 최종 로그는 `target/adversarial-review/approved-verify-complete.log`다.

이전 0.3.1 원격 CI 실행 38108200774는 1,000석 자리 배치의 복합 테스트가 6,064ms 걸려 기본 5초 시간 제한으로 실패했다. 같은 복합 사례는 현재 단독 실행에서 2,988ms였다. 1,000석의 CSS 접근성 조회와 조건 검색이라는 독립 책임으로 테스트를 나눴다. 동일 합성 자료·실제 컴포넌트·원래 모든 단언과 각 5초 한도를 유지했으며 스타일 모의나 검사 생략을 추가하지 않았다. 지정 App 테스트 8개가 통과했고 대규모 두 사례는 1,979ms·868ms였다. 독립 리뷰에서도 분리 전후의 상태 연관성 단언이 동일함을 확인했다. 이는 테스트 구조 개선이며 제품 성능 향상이나 두 절차 합계 5초 이내의 보장이 아니다. 새 원격 CI 결과는 별도로 확인한다.
