# 개인정보 (privacy)

제품 약속: **모든 처리는 PC 안에서 하며, 파일과 개인정보는 외부로 나가지 않는다.** 교사가 다루는 파일에는 학생 이름, 성적, 연락처가 들어 있다고 가정한다([ADR-0007](../adr/0007-privacy.md)).

## 1. 원칙

1. **로컬 처리.** 모든 변환·분석은 PC 안에서 한다. 호스트 네트워크는 updater와 카탈로그 엔드포인트로만 나가며, 이 목록은 코드 상수다.
2. **수집 없음.** 텔레메트리, 사용 통계, 크래시 자동 전송이 없다.
3. **흔적 최소화.** 로그·에러·임시 파일에 사용자 데이터를 남기지 않는다.
4. **원본 보호.** 원본 파일을 덮어쓰거나 지우는 것은 사용자가 명시적으로 고른 경우에만 한다.
5. **모듈 간 격리.** 한 모듈의 저장 데이터를 다른 모듈이 읽을 수 없다.

## 2. 로그에 남겨도 되는 것

| 남겨도 됨 | 남기면 안 됨 |
|---|---|
| 핸들 id, 개수, 바이트 크기, 오류 코드, 캡·메서드 이름, 모듈 id, 소요 시간 | 경로, 파일명, 파일 내용, 사용자 입력, storage 값, OS 사용자명 |

호스트 로그는 `tracing` 구조화 필드로 id·코드·개수만 남긴다(`src-tauri/src/platform.rs` `init_logging`). 이 구분을 타입으로 강제하는 헬퍼는 아직 없어서 리뷰로 확인한다.

## 3. 테스트 데이터

- `fixtures/synthetic/`의 합성 데이터나 명백한 가상값만 쓴다. 예: `홍길동`, `○○초등학교`, `010-0000-0000`. 저자 표기(AUTHORS, 매니페스트 `authors`)는 이 규칙의 대상이 아니다.
- 합성 데이터 생성기: [fixtures/synthetic](../../fixtures/synthetic/README.md) (`pnpm synthetic`).

## 4. 규칙

- **PRV-001** [MUST NOT] 호스트 외에는 네트워크 통신을 하지 않는다. 호스트 네트워크는 updater·카탈로그 엔드포인트(상수 allowlist)로만 한정한다. — 강제: 셸·모듈 CSP, 코드 리뷰
- **PRV-002** [MUST NOT] 텔레메트리, 사용 통계, 크래시 자동 전송을 하지 않는다. — 강제: 의존성 리뷰, [manual]
- **PRV-003** [MUST NOT] 로그와 에러 메시지에 경로·파일명·파일 내용·사용자 입력·storage 값을 남기지 않는다. 핸들 id·개수·크기·오류 코드만 남긴다. — 강제: [manual] 리뷰(타입 강제 로깅 헬퍼는 미구현)
- **PRV-004** [MUST NOT] 테스트·문서·스크린샷·예제에 실존 인명·학교명·연락처를 쓰지 않는다. `fixtures/synthetic/`의 합성 데이터나 명백한 가상값만 쓴다. — 강제: [manual], 합성 데이터 생성기 제공
- **PRV-005** [MUST] 임시 파일은 앱 전용 temp 디렉터리에만 만들고, 작업 종료 시 삭제하며, 앱 시작 시 잔여물을 정리한다. — 강제: temp 헬퍼 API(`TempArea`)와 테스트
- **PRV-006** [MUST NOT] 원본 파일 덮어쓰기·삭제를 기본 동작으로 하지 않는다. 사용자의 명시적 선택이 있어야 한다. — 강제: [manual], GEN-005
- **PRV-007** [MUST] 모듈 데이터는 모듈 id로 격리한다. — 강제: storage 캡 테스트
