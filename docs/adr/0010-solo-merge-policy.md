# ADR-0010: main은 PR과 CI 통과만으로 머지한다(승인 필수 없음)

- 상태: 승인됨
- 날짜: 2026-10-10
- 결정자: 신민성, 정영주

## 맥락

원저작자는 두 명이고, 한 명이 혼자 기능을 개발해 올리는 경우가 많다. 다른 한 명의 승인을 필수로 두면 상대가 바쁠 때 작업이 멈춘다. 반면 main을 직접 바꾸거나 이력을 덮어쓰는 일은 막아야 하고, 모든 변경은 `pnpm verify`를 통과해야 한다.

## 결정

- main 변경은 PR로만 한다. 직접 push, 강제 push, 브랜치 삭제는 금지한다.
- 머지 조건은 CI `verify` 통과 하나다. 승인 인원은 0명이며 CODEOWNERS 리뷰도 필수가 아니다.
- 보호 경로(workflow, CODEOWNERS, Tauri ACL, 라이선스·저작자 표기)를 바꾸는 PR은 다른 원저작자의 리뷰를 **권장**한다. CODEOWNERS는 리뷰 요청을 자동으로 보내는 용도로 남긴다.
- GitHub org 2FA는 강제하지 않는다. 각자 계정에서 켜기를 권장한다.
- 릴리스 서명은 `release` environment의 필수 승인자 설정으로 보호한다(CI-004).

## 결과

- CI-006을 "PR + `verify` 필수, 보호 경로 리뷰 권장"으로 바꾼다([ci.md](../spec/ci.md#3-규칙)).
- 실수로 들어간 보호 경로 변경은 리뷰로 걸러지지 않을 수 있다. 1차 방어는 `check-security`, 훅(보호 경로), 정지 조건(GEN-005)이다.
- 강제: GitHub ruleset "main protection"(사람 설정).

## 대안

- **승인 1명 필수 + CODEOWNERS 리뷰**: 혼자 작업할 때 머지할 수 없다.
- **관리자 우회 허용**: 매번 우회 버튼을 눌러야 하고, 우회가 일상이 되면 규칙이 의미를 잃는다.
