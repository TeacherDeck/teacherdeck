# ADR-0007: 로컬 처리, 텔레메트리 없음, 로그에 사용자 데이터 금지

- 상태: 승인됨
- 날짜: 2026-10-08
- 결정자: 신민성, 정영주

## 맥락

교사가 다루는 파일에는 학생 이름, 성적, 연락처 같은 민감한 개인정보가 들어 있다. 학교는 개인정보 유출에 매우 민감하며, 외부 전송이 있는 도구는 도입하기 어렵다.

## 결정

- 제품 약속: **모든 처리는 PC 안에서 하며, 파일과 개인정보는 외부로 나가지 않는다.**
- 텔레메트리, 사용 통계, 크래시 자동 전송을 하지 않는다.
- 로그·에러 메시지에 경로·파일명·사용자 데이터를 남기지 않는다.

## 결과

- 규칙: [privacy.md](../spec/privacy.md) (PRV-001~007).
- 호스트 네트워크는 updater·카탈로그 엔드포인트 상수 allowlist로만 나간다. 모듈은 CSP로 외부 연결이 막힌다(MOD-008).
- 버그 신고는 사용자가 직접 내용을 확인하고 보내는 방식으로만 받는다.
- 사용 통계가 없으므로 어떤 도구가 많이 쓰이는지는 사용자 피드백으로만 안다.

## 대안

- **익명 사용 통계(옵트인)**: 개선에 도움이 되지만 "외부로 나가지 않는다"는 약속을 설명하기 어려워진다. 지금은 하지 않는다.
