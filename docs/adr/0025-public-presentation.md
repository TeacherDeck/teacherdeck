# ADR-0025: 교사용 창과 분리된 로컬 학생 화면

- 상태: 승인됨
- 날짜: 2026-10-11
- 결정자: 프로젝트 소유자

## 맥락

사용자는 복제 화면과 확장 모니터를 모두 요구했다. 현재 전체화면은 교사 창까지 차지하므로 확장 모니터에 결과만 표시할 수 없다. [구체 제안](../proposals/classroom-portability-presentation.md) 2번을 사용자가 명시 승인했다.

## 결정

window 1.1에 모니터 목록·공개 창 열기·명시적 결과 갱신·닫기를 추가한다. 모듈별 불투명 핸들을 쓰며 창과 모니터를 호스트가 관리한다. 모듈당 창 하나, 앱 전체 네 개이며 활성 창은 모듈 언로드 때 닫는다. 복제 전체화면 API는 유지한다.

공개 자료는 자리·발표·모둠·역할 enum과 제목/표시 이름/그룹/좌석 위치만 가진다. 임의 HTML·URL·스타일·연락처·조건·메모를 받지 않는다. 화면 공유는 로컬 모니터로만 이루어진다. 사용자가 결과를 바꾸더라도 명시적으로 갱신하기 전에는 공개한 결과를 유지한다.

presentation-* 창은 고정 /presentation 셸 문서만 로드한다. 별도 ACL에는 event listen/unlisten과 presentation_ui_state/close 네 권한만 둔다. 소유자와 window label/local origin을 매 호출 검증한다. 모니터 구성 변경은 공개 자료를 비워 재선택을 요구한다. 일반 host_invoke와 모듈 로드는 금지한다.

## 결과와 검증

새 런타임 의존성은 없다. Rust 원천 타입·SDK 생성물·권한 거부/수명/상한 테스트와 실제 렌더 검증을 함께 둔다. 실제 다중 모니터가 없는 환경의 검증은 그 한계를 기록한다. 학생 기기 접속·QR·서버 공유는 포함하지 않는다.
