# ADR-0021: 설치된 Office와 네트워크 루틴의 고정 작업자

- 상태: 승인됨 (기능·Windows 의존성 및 세 직접 FFI 경계)
- 결정일: 2026-10-11
- 관련 제안: [native-tools-next](../proposals/native-tools-next.md)

## 맥락

Office 문서는 설치된 프로그램의 실제 SaveAs로 변환해야 한다. COM 호출은 파일 잠금·보안 대화상자·손상 문서 때문에 멈출 수 있다. 네트워크 루틴은 메인 창을 닫거나 PC를 재시작해도 저장한 시간표와 Wi-Fi 조건을 평가해야 한다. 모듈이 실행파일·스크립트·COM ProgID·작업 XML을 선택하게 하지 않는다.

## 결정

호스트 실행파일은 GUI와 별도로 정해진 내부 작업자 모드를 제공한다. GUI/single-instance 초기화보다 먼저 모드를 분기한다. Office 작업자는 제한된 stdin 요청 하나를 읽고 고정 제공자만 새로 생성한다. 부모는 120초 한도와 소유 작업자 종료를 책임진다. 표준 출력에는 구조화 결과만 쓰며 로그에 복사하지 않는다. 모듈에 경로나 OS 프로세스 ID를 보내지 않는다.

Office 원본은 기존 읽기 세션으로 잠근 상태에서 앱 임시영역에 복사한다. 매크로 강제 비활성화·링크 갱신 금지·읽기 전용 열기 후 변환하고, 생성한 형식의 필수 ZIP 구성과 실제 재열기를 확인한다. 매크로를 발견하면 비매크로 형식으로 조용히 변환하지 않는다. Excel 4.0 매크로 시트는 자동 변환을 중단한다. 원본 SHA-256을 다시 비교한 뒤 기존 fs의 append-new 쓰기 계약으로 결과를 공개한다. 파일명 충돌 시 원본이나 기존 결과를 덮어쓰지 않는다.

네트워크는 구조화한 IPv4/DNS 패치와 고정 DHCP 복원만 제공한다. OS 어댑터 identity는 호스트에서 다시 대조한다. 일반 호스트 권한을 유지하고 실제 적용/자동 작업 등록은 명시적 UAC 작업자로 한정한다. 관리자 거부를 성공으로 기록하지 않는다. DNS만 입력한 내부 설정은 IP를 바꾸지 않는다.

자동 작업은 앱 소유 namespace 아래 부팅·로그온·잠금해제·콘솔복귀·WLAN 연결/해제·주간 경계의 여섯 레시피만 등록한다. 모듈이 이벤트 쿼리나 명령을 입력하지 않는다. 원본 독립 프로그램의 작업은 발견해 알림만 표시한다. 백그라운드 실행은 매번 소유 모듈 설치 상태·cap 선언/버전·설정 revision·runner 버전을 다시 검사하며 불일치하면 적용하지 않는다. 모드와 무관한 Wi-Fi/시간표 트리거는 등록하지 않는다. 업데이트 후 기존 task action의 실행파일과 버전을 재대조하고 사용자가 다시 등록할 때까지 불일치 상태를 보여준다.

프로필과 실행 상태는 모듈별 호스트 저장소에 원자적으로 기록한다. 설정이 판단에 영향을 주면 원본과 동일하게 수동 우선 및 이전 처리 구간을 초기화한다. 수동 전환은 성공 뒤 읽은 상태가 일치할 때만 현재 판단 구간에 묶는다. 구간이 바뀌면 수동 우선을 해제한다. 모호한 Wi-Fi 전용 판단은 현재 설정을 유지한다.

## 직접 FFI 경계

Windows API는 `native_automation.rs`(COM/VARIANT/SAFEARRAY), `network_native.rs`(WLAN/네트워크/TaskScheduler), `native_workers.rs`(고정 프로세스/UAC/소유 프로세스 정리)에만 둔다. 해당 파일의 `unsafe_code` 예외는 [추가 경계 승인](../proposals/windows-ffi-boundary.md)에 따라 suppressions allowlist에 등록한다. 전역 lint/CSP/ACL 완화는 없다. 각 unsafe 블록은 포인터 유효기간·할당 해제·COM apartment·소유권 근거를 SAFETY 주석으로 설명한다.

## 결과와 검증 한계

이 ADR은 Office·네트워크 작업자에 한정한다. 별도로 승인한 CoolReserve 관리 Python 실행기는 [관리 런타임 제안](../proposals/coolreserve-managed-runtime.md)과 ADR-0023의 정확한 파일·해시 경계를 따른다. 임의 Python 실행은 허용하지 않는다. 실제 쿨메신저 발송과 현재 PC의 네트워크 전환 검증은 하지 않는다. 네트워크 순수 정책은 원본 180개 차등 사례와 수동 우선 회귀를 검사한다. 실제 OS 적용·재부팅/UAC·기관 정책 검증은 허용된 별도 환경의 후속 검사로 남긴다. Office 합성 파일 변환은 설치된 제공자로 검증할 수 있으며 구조 검사 성공을 모든 서식의 동일성으로 표시하지 않는다.
