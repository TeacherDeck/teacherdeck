# ADR-0030: 도구별 오픈소스 라이선스 고지

- 상태: 승인됨
- 날짜: 2026-10-12
- 결정자: 프로젝트 관리자 (2026-10-12 사용자 명시 승인)
- 관련: [제안서](../proposals/module-license-notices.md), GEN-005, GEN-007, [ADR-0018](0018-pdf-resource-notices.md), [ADR-0023](0023-managed-messaging.md), [ADR-0028](0028-bounded-media-download.md)

## 맥락

About 화면은 GPLv3의 Appropriate Legal Notices를 겸한다. 서드파티 고지가 셸·호스트 표 하나와 쿨 예약실 전용 절로 나뉘어 있었다. 도구 번들과 도구 전용 실행 환경의 구성 요소는 화면에 없었다. 도구가 늘수록 어떤 구성 요소가 어느 도구에 딸렸는지 알기 어렵다.

## 결정

- `pnpm gen`이 동봉 도구별 고지를 `apps/desktop/src/generated/module-notices.json`으로 생성한다. 도구마다 구성 요소(이름·버전·라이선스·종류)를 담고, 원문은 한 번만 저장해 키로 참조한다.
- 라이브러리는 도구의 실행 의존성 닫힘에서 모은다(워크스페이스 패키지는 따라가되 목록에서 제외). 자산·실행 환경은 기존 해시 고정 원천(ADR-0018, ADR-0023, ADR-0028)의 원문을 그대로 쓴다.
- 쿨 예약실 전용 생성물 `messaging-notices.json`은 이 파일로 합친다. 원문 해시 검증은 유지한다.
- About 화면은 "앱 공통"과 도구별 묶음으로 보여 준다. 묶음마다 구성 요소 수와 라이선스 요약을 보여 주고, 원문은 구성 요소 이름으로 펼친다. 원문 묶음은 화면을 열 때 불러온다.

## 결과

- 새 도구를 추가하면 생성기가 자동으로 묶음을 만든다. 도구 전용 자산·실행 환경을 추가하면 생성기의 원천 목록에 함께 등록해야 한다.
- 고지는 설치본에 동봉한 도구 버전 기준이다. 원격 업데이트로 버전이 다르면 화면에 기준 버전을 밝힌다.
- GEN-007: 기존 고지를 하나도 빼지 않는다. 생성기 시험이 쿨 예약실 원문 전체와 자산·실행 환경 원문의 존재를 검사한다.

## 대안

- 셸이 실행 중에 도구 origin의 고지 파일 읽기: CSP·프로토콜 변경이 필요해 이번 범위에서 제외했다.
- 모든 npm 원문 포함: 셸 번들이 커진다. 셸 표와 같은 수준을 유지했다.
