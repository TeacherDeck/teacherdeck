# ADR-0029: 도구 식별과 공통 작업 화면의 밀도

- 상태: 승인됨
- 날짜: 2026-10-11
- 결정자: 프로젝트 소유자(디자인 개선안 전체 진행 지시)

## 맥락

홈에서 13개 도구가 템플릿과 같은 사각형 아이콘을 사용한다. 즐겨찾기와 전체 목록이 같은 크기로 반복되고, 셸의 도구 정보 행과 모듈 제목이 작업 공간 높이를 함께 차지한다. 개별 도구에는 실행 구역과 실제 실행 버튼의 위치 불일치, 모든 항목에 반복되는 관리 버튼이 있다.

## 결정

- Fluent v9·WinUI·Mica·기존 토큰을 유지한다. 전역 여백이나 글자 크기를 일괄 축소하지 않는다.
- 홈의 즐겨찾기는 아이콘·이름·별·상태를 갖는 짧은 실행 카드로, 전체 목록은 두 줄 설명을 유지한 작은 카드로 구분한다. 생략한 설명은 키보드 포커스에서도 툴팁과 접근성 설명으로 제공한다.
- 셸의 도구 정보는 작은 메타데이터 행으로 줄인다. 모듈의 `PageHeader`가 작업 제목(h1)을 맡는다. 버전·호환 상태·로드 오류는 유지하며 iframe 생명주기는 바꾸지 않는다.
- 각 기본 모듈의 `icon.svg`는 같은 48 단위 바탕·안쪽 여백·획 두께를 사용하고, 기능별 실루엣을 갖는다. 단순 색 차이로 도구를 구분하지 않는다. 모듈 패키지가 아이콘을 소유하며 셸에 도구 ID별 아이콘 표를 만들지 않는다.
- 파일 처리, 계속 실행하는 도구, 기록 작업, 배정 작업은 각 작업에 맞는 조합을 사용한다. 공통화하는 것은 제목·실행·상태·설정의 역할이며 모든 화면을 파일 처리 골격에 맞추지 않는다.
- 세부 구현과 수용 기준은 [공통 디자인 계획](../proposals/app-module-design-2026-10-11.md)과 [개별 화면 개선안](../proposals/design-improvements-2026-10-11.md)을 따른다.

## 영향과 대안

새 의존성·캡·권한·브리지·매니페스트 포맷·저장 데이터 변경이 없다. 변경 모듈은 patch 버전을 올린다. 실행 컨트롤·별·단축키·확인·복구는 보존한다. 카테고리별 무지개 타일은 기능보다 색을 외우게 하므로 채택하지 않는다. 셸 제목을 완전히 없애는 변경은 현재 범위에 넣지 않고 우선 메타데이터 행만 압축한다.
